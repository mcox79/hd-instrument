## (a) HEADLINE

The CA3 auto-associator anti-signal is a **known, expected class of failure** in attractor-network theory -- not a substrate-novel pathology -- and the literature (three external axes) plus the substrate's own prior-arc empirics (one internal axis, Cycle 178 + free-probability clustered-codebook drill) **converge on the same diagnosis**: a plain Hebbian outer-product auto-associator is a *structure-blind* decoder, and structure-blind decoders demonstrably DROP capacity under tight clustering while structure-aware decoders LIFT it. The dominant literature-favored fix is **upstream pattern-separation / competitive-Hebbian preprocessing before the associator** (Hypothesis C), not a change to CA3's own learning rule (B) or iteration count (A), and the failure is emphatically **not** shown to be an unfixable property of the Marr-1971 auto-associator class (D) -- three independent fix mechanisms exist in the literature (DG sparsification, competitive-learning front end, whitening/decorrelation), all operating upstream, none operating in CA3's own recurrent weights alone. The current CG_HN_ARCHITECTURAL claim, however, is **mis-scoped if generalized past cluster_cos ~= 0.9**: the substrate's own Cycle 178 result (`ρ=0.5 recall=0.93` vs `ρ=0.0 recall=0.80` vs `ρ=0.9 recall=0.33`) shows an **inverted-U**, not a monotonic decline from moderate correlation -- moderate correlation (~0.5) is a BONUS regime, not an anti-signal regime. This is a required self-correction: do not extrapolate the anti-signal claim below cluster_cos ~ 0.8.

**Capacity check (Skunkworks-corrected Tsodyks-Feigelman formula):** C_TF = dg_dim / (2*ln(1/p)) = 8192 / (2*ln(50)) = 8192 / 7.824 = **~1047**. K=500 stored patterns is **47.8% of C_TF** -- comfortably sub-capacity under the IID assumption. This confirms the anti-signal is a **correlation-structure effect, not a naive capacity-overload effect** (prediction #3 above already passes on arithmetic alone) -- consistent with Rolls' explicit statement that "correlations between patterns reduce memory capacity" independent of raw loading fraction, and with Amit's mixture-state mechanism which operates via crosstalk-term dominance, not via exceeding a raw pattern count.

## (d) Cross-thread synthesis (4 independent corroborating axes)

### Axis 1 -- Neuroscience (external, Sonnet lit-scan)

- **Marr 1971** ("Simple memory: a theory for archicortex"): assumed a "codon" preprocessing layer that decorrelates inputs *before* the auto-associator ever sees them. Correlated-input degradation is **outside Marr's modeled regime** -- his architecture presupposes the fix already exists upstream, so he neither predicted nor ruled out the anti-signal; the omission is structural, not an oversight.
- **Rolls 2013** (Front. Syst. Neurosci., PMC3812781) states explicitly: "correlations between patterns reduce the memory capacity" of CA3, and gives the Treves/Rolls sparse-capacity formula p_max ~ C_RC*[a*ln(1/a)]/k. Rolls does not model a regime where CA3 recurrence is *worse* than skipping recurrence -- his framing is capacity-shrinkage, not sign-flip -- but the mechanism (correlation -> capacity loss) is the right family.
- **Hopfield prototype-attractor literature** (arXiv:2407.03342 and related): patterns sharing a prototype generate large crosstalk terms that create a dominant "prototype attractor" swamping individually-stored patterns -- the closest direct mechanistic analog to "CA3 pulls retrieval toward a shared cluster attractor."
- **In-vivo prevention mechanisms found:** (i) dentate gyrus sparsification/orthogonalization gates correlated EC input before it reaches CA3; (ii) Hasselmo/Kunec cholinergic-gating + theta-phase-segregation theory -- high ACh during encoding suppresses CA3 recurrent-collateral transmission so correlated afferent input does not get Hebbian-bound into a dominant crosstalk attractor; low ACh during retrieval lets recurrence dominate for completion. **Both are upstream/gating mechanisms, not "compare-and-fallback" logic** -- reinforces Hypothesis C over A/B.
- Calibrated confidence (axis-internal): ~0.35 that the *specific* "worse than raw lookup" framing is a named result; ~0.80 that it is an unsurprising, structurally-expected consequence of well-known correlation -> crosstalk -> prototype-attractor-dominance principles that the literature simply never phrased this way (because the standard models always assume DG separation is already in place).

### Axis 2 -- Math / statistical-physics (external, Sonnet lit-scan)

- **Amit-Gutfreund-Sompolinsky 1985/1987 + Amit 1989**: classic alpha_c ~ 0.138N capacity for *random, uncorrelated* patterns. Mixture-state spurious attractors (symmetric combinations of stored patterns) are a KNOWN class even at sub-saturation for uncorrelated storage; correlated/clustered storage make mixture-state convergence the DOMINANT outcome instead of a rare spurious mode.
- **Tsodyks-Feigelman 1988** sparse-capacity formula assumes decorrelated patterns; no source found gives a published correlation-dependent correction -- **this is a genuine literature gap**, not a substrate-specific gap.
- **Storkey 1997**: adds a self-interaction-removal correction that specifically suppresses pairwise-correlation crosstalk and is the standard cited remedy -- but multiple sources note it "suffers significantly less" capacity loss under correlation, not "eliminates" it, and for TIGHT clustering (near-singular pattern Gram matrix) the fix is expected to be partial at best; full decorrelation (whitening/Gram-Schmidt) was cited as the fuller fix in one source.
- **Clustered/prototype regime**: explicitly under-characterized quantitatively in the literature -- one source states "for correlated data ... often results in one fixed point attracting the entire dataset into a single basin," matching our finding qualitatively, but no closed-form basin-merging phase boundary as a function of cluster tightness was located.
- Calibrated confidence: raw ~0.55, deflated per [[feedback-lit-scan-calibration-penalty]] to **0.35-0.40** that this exact regime (tight cluster + 75% corruption + worse-than-no-dynamics) is "already known/characterized" as opposed to a legitimate novel-regime quantification worth documenting as our own.

### Axis 3 -- ML / computational (external, Sonnet lit-scan)

- **Ramsauer et al. 2020** ("Hopfield Networks is All You Need"): the modern/continuous Hopfield energy landscape has three fixed-point classes -- single-pattern minima, global average, and **metastable states averaging over a cluster of patterns**. They state explicitly that clustered/insufficiently-separated patterns at low inverse-temperature beta converge to the cluster-averaging metastable state instead of the target -- this is the single most directly on-point theoretical match found across all three external axes, and it is **already published, not novel**.
- **Sarra et al. 2025** ("Daydreaming Hopfield Networks", arXiv:2405.08777): confirms standard Hebbian storage degrades badly on correlated data; proposed fix is an iterative reinforcement-plus-unlearning rule INSIDE the associator (a B-adjacent fix, not upstream preprocessing).
- **Foldiak 1990** ("Forming sparse representations by local anti-Hebbian learning"): explicitly frames the resulting sparse decorrelated code as favorable "if used as input to a subsequent supervised associative layer" -- the original sparsify-then-associate design rationale.
- **arXiv:2301.02196** ("Competitive learning to generate sparse representations for associative memory", Neural Networks 2023): **the single most load-bearing paper for Hypothesis C** -- builds a competitive-learning front end that sparsifies inputs *before* feeding a Palm-style binary associative memory, explicitly motivated by dense/correlated data breaking naive associative memory, and reports the competitive-learning-preprocessed code "beats sparse coding baselines" and approaches optimal random-code capacity. Same architecture shape as Probe 3 above (input-side competitive learning, separate from the associator's own recurrent weights).
- Calibrated confidence: ~0.85 that the cluster-merging/metastable-state degradation itself is an already-documented phenomenon (Ramsauer's own theory); the specific quantitative "worse than doing nothing" baseline comparison was not found explicitly run in any source, so the numeric framing is a legitimate original contribution even though the qualitative mechanism is not novel.
