## BRAIN ARCHITECTURE (situation model)
- SITUATION MODEL (Kintsch/van-Dijk + Zwaan event-indexing): a mental model of the STATE OF AFFAIRS, structured over 5 EVENT DIMENSIONS -- PROTAGONIST, TIME, SPACE, CAUSATION, INTENTIONALITY -- updated INCREMENTALLY per sentence; updates fire at EVENT BOUNDARIES when a dimension changes (ties to event-segmentation prediction-error).
- CONSTRUCTION-INTEGRATION (Kintsch 1988): CONSTRUCT (bind new propositions + retrieve relevant items from LTM -> broad activated network) -> INTEGRATE (SETTLE via constraint-satisfaction: relevant strengthen, irrelevant fade). = the substrate's VSA BIND + SETTLE. (CS is APPROPRIATE here -- integrating genuinely-multiple propositions/referents over time -- unlike the redundant single-sentence knowledge-cue combiner that HARD_FAILed 3x.)
- COREF = cue-based MEMORY RETRIEVAL of the antecedent (L-MTG retrieval + angular-gyrus integration = SAME temporo-parietal machinery as thematic-role assignment; syntactic + discourse cues, RECENCY-weighted). Refs: Zwaan&Radvansky event-indexing; Kintsch CI; PMC11305457 neural coref.
