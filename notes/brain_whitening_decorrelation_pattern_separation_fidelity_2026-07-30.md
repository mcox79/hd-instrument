## HEADLINE

Brain decorrelation is NOT one global linear whitening transform (no evidence of a covariance-inverse operation anywhere in the citations). It is always **local/online subtractive removal of an expected or mean component (adaptation, predictive coding, center-surround) PLUS divisive gain control (contrast/competitive normalization) PLUS sparse expansion recoding** — three separable primitives, composed differently at different stages. Dentate-gyrus/cerebellar "pattern separation" is the sparse-expansion-plus-post-projection-divisive-inhibition member of that family, not a re-derivation of PCA/ZCA whitening. The literature (Babadi & Sompolinsky 2014, CITED) explicitly shows expansion+kWTA's separation benefit is *limited* by dominant low-dimensional/shared structure in the input, while separately (Dasgupta/Stevens/Navlakha 2017 + Johnson-Lindenstrauss, CITED) shows expansion+hashing is designed to run directly on anisotropic/correlated input with NO whitening prerequisite. Reconciling those: the brain's fix for a dominant shared mode is **sparse (not dense) random fan-in** (prevents each expanded unit from resampling the shared mode) **+ divisive normalization applied AFTER projection, per-code** (Golgi-cell/basket-cell feedback holding total activity constant) — not an upstream PCA/ZCA whitening stage. Our current pipeline (PCA-whiten -> dense-ish random expand -> k-WTA) is a plausible SPLIT of what the brain does as one integrated step, and the split is in the wrong place: we whitened before expansion instead of normalizing after it.

## Cheap decisive test

On the SAME frozen-MLM role/filler reps already in the WM read-conditioning experiment (abd107fa lineage), build one additional variant and compare on the SAME held-out role pairs used for the 0.99->0.80 measurement:

- **Baseline (current):** raw -> PCA-whiten -> fixed random expand -> k-WTA -> hash. Known: pairwise cosine 0.99->0.80.
- **Variant A (brain-faithful reorder):** raw (NOT whitened) -> fixed **sparse** random expand (K=5-10 active inputs per expanded unit, not dense Gaussian) -> **per-code divisive normalization** (normalize each expanded code's activation mass, e.g. divide by running L1/L2 norm or local sum, BEFORE k-WTA) -> k-WTA -> hash.
- **Control B (cheap, near-free):** swap PCA-whiten for ZCA-whiten only, keep everything else identical — isolates whether basis-rotation choice matters at all.

Measure: (1) pairwise role-query cosine collapse (the existing metric), (2) held-out slot-decode accuracy (currently 1.0 per VET a1f31e21) as a signal-preservation guard, (3) a NEW control — correlation of the discarded/normalized-out "shared axis" activation with role identity label (checks Q4 below).

## Falsifiable predictions

**HARD-PASS (Variant A):** pairwise cosine collapse drops to <=0.60 (vs current 0.80) AND held-out slot-decode accuracy stays >=0.90 (vs current 1.0) AND the shared-axis-vs-role-identity correlation is <0.1 (confirms the shared component was nuisance, not signal). This would justify replacing PCA-whiten-then-dense-expand with sparse-expand-then-divisive-normalize as the addressing front-end.

**HARD-FAIL:** pairwise cosine stays >=0.80 (no improvement over current PCA-whiten baseline) OR slot-decode accuracy drops below 0.70 (repeats the dense-KV whitening HARD_FAIL pattern of destroying the signal that made keys meaningful) OR the shared-axis-vs-role-identity correlation is >=0.3 (the "shared component" is actually carrying real task signal — normalizing it away would be the same mistake PCA-whitening already made once).

**Control B (ZCA) prediction:** expect near-null effect on the residual-shared-component number specifically (ZCA and PCA differ in basis alignment/interpretability, not in how much correlation/variance they remove from a finite sample) — P(ZCA meaningfully beats PCA on this specific metric) = 0.20 (REASONED, deflated).

## Cross-thread synthesis — answers to the 4 questions

**Q1 — common principle.** Convergent across retina/LGN (Atick & Redlich efficient coding, REASONED extension of standard efficient-coding theory — not directly re-verified this cycle), cortex (Carandini & Heeger divisive normalization: response = drive / (sigma + pooled-activity), REASONED from established textbook formula, not re-fetched this cycle), and cerebellum/DG (Cayco-Gajic & Silver 2019, CITED): the brain's decorrelation is never a single global linear operation. It's **subtractive removal of an expected/mean/common-mode component (adaptation, predictive coding) that is LOCAL and ONLINE**, **combined with divisive/competitive gain control that is POST-hoc and PER-UNIT**, **combined with sparse dimensionality expansion**. No citation found (in either scan) describing anything resembling a batch covariance-inverse (PCA-style) computation anywhere in a real neural circuit — this is a meaningful negative result: PCA/ZCA-whitening is an ENGINEERING convenience, not a brain-faithful primitive, at best a coarse proxy for "subtractive+divisive" acting jointly.

**Q2 — unification (load-bearing).** Pattern separation and whitening are RELATED but NOT the same operation, and the relationship is directional, not symmetric. Babadi & Sompolinsky 2014 (CITED) show expansion's benefit is capped by low-dimensional/shared structure already present in the input — i.e., expansion alone does not automatically zero out a dominant shared axis. But Dasgupta/Stevens/Navlakha 2017 + the Johnson-Lindenstrauss guarantee (CITED, distribution-agnostic) show expansion+hashing is explicitly built and validated to run on anisotropic/correlated input directly, with no whitening precondition anywhere in the fly circuit model. The reconciling mechanism, per Litwin-Kumar et al. 2017 and Cayco-Gajic & Silver 2019 (both CITED): **sparse (K=4-10) fan-in, not dense connectivity**, is what prevents each expanded unit from resumming the shared mode, and **divisive/competitive inhibition computed AFTER projection** (Golgi/basket cells) is what suppresses a globally-elevated shared drive from dominating which units win — not an upstream whitening stage. So: **our whiten-then-expand pipeline is very likely a mis-ordered split of ONE integrated brain operation.** The correct integrated form is sparse-expand -> divisive-normalize-per-code -> kWTA, with no separate global whitening stage at all. Confidence: P=0.40 (REASONED synthesis across 3 papers that individually don't state this unification — capped per novel-synthesis discipline; this is the single most load-bearing and least directly-cited claim in this note, flag accordingly).

**Q3 — concrete ranked recommendations** (fidelity x effect-on-residual-shared-component x cheapness):

| Rank | Change | Brain fidelity | Expected effect on residual shared component | Cost | P (deflated) |
|---|---|---|---|---|---|

Predictive-coding subtraction of the shared/expected component (REASONED as theoretically closer to "true" brain whitening than any of the above, since it is subtractive + online + local — matches the Q1 principle better than PCA/ZCA) was NOT ranked in the top 3 for THIS decision because it requires an extra learned prediction head and target signal that doesn't exist yet in the WM read-conditioning pipeline — high fidelity, but not cheap, so deprioritized for the cheap decisive test window. Flag as the next-tier candidate if Rank 1+2 both HARD-FAIL.

**Q4 — is the shared component actually meaningful signal?** Genuine, non-trivial risk, and there is a DIRECT substrate precedent for it going wrong the other way: `exp_dense_KV_whitening_revival_v1_gpu` HARD_FAILED specifically because "whitening BURNS the neighborhood structure that made keys meaningful" (verified in `research_anisotropy_drill_2_solutions_brain_substrate_2026-06-25.md`, cell metrics directly cited there). That is the same class of failure this drill is trying to avoid one stage later. The literature gives no clean answer on whether OUR specific shared component is nuisance or signal — that has to be measured, not assumed, which is why the cheap decisive test above adds an explicit control: correlate the discarded/normalized shared axis against role-identity labels. If that correlation is non-trivial (>=0.3), destroying it via divisive normalization (or via more aggressive whitening) would be repeating the exact HARD_FAIL pattern already on file. This is the honest gate before declaring Rank 1 a win even if the cosine-collapse number improves.

## Substrate-product implications

This is a product-relevant fix, not a publication angle: the WM's ability to bind role->filler generalizably (the open gap per current focus) depends on the addressing stage not re-manufacturing the collapse the whitening stage only partially fixed. A HARD-PASS on Variant A would mean the DG-analog addressing pre-check can proceed with a cheaper, more brain-faithful front-end (drop the PCA-whitening step entirely, replace with sparse-expand + post-projection divisive-normalize), which is both more brain-faithful AND removes a covariance-estimation dependency (no batch statistics needed, works online/streaming) — directly useful for the "no bolt-on reader, own mechanism" discipline already in force. A HARD-FAIL on the shared-axis-signal control would be equally valuable: it would mean the residual shared component is NOT safe to discard, redirecting effort toward supervised/contrastive slot-address learning (already partially validated per VET a1f31e21) rather than any further decorrelation attempt.
