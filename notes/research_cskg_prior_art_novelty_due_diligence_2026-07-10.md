Solo research cycle (no sub-agent fan-out, per explicit task constraint). Method: own WebSearch/WebFetch + reasoning. Generic terms used; no substrate-novel mechanism names/configs sent off-platform. Field advisor run first (per contract) but its 22-field substrate-physics taxonomy does not cover KG/neuro-symbolic/cognitive-architecture topics — this drill sits outside that taxonomy entirely, same as today's sibling `research_generate_and_test_relational_inference_candidate_b_2026-07-10.md` already flagged (recommend adding `commonsense-KG` / `neuro-symbolic-reasoning` / `cognitive-architectures` as new fields at next meta-map refresh).

## HEADLINE (3-line)

1. **CSKG is exactly what it looks like: a passive, symbolic-only, identity-resolved MERGE of 7 existing commonsense sources (ConceptNet, ATOMIC, WordNet, Wikidata-CS, FrameNet, Roget, Visual Genome), built by Ilievski/Szekely/Zhang (USC-ISI, ESWC 2021) explicitly as a public RESOURCE for others to build on** — they published the graph + embeddings and analyzed connectivity/embedding quality; they did NOT build a reasoner on top of it. Reuse is fully justified — do not rebuild the entity-resolution layer (2.2M nodes, 6M edges, 251,517 identity links already computed).
2. **Our exact 5-way combination — self-contained (no external LLM) + glass-box + VSA/HD substrate + CSKG as knowledge base + measured-norm grounding from a spanning grounded core + generate-and-test with a hard exogenous verifier, applied to open commonsense relational inference — was NOT found built anywhere.** But nearly every individual ingredient already exists, separately, in the wild as of 2025-2026: an unpublished hobbyist VSA "neural-free" cognitive architecture over ConceptNet/WordNet (PRISM, self-contained + glass-box but text-embedding-only grounding, no generate-and-test), a working full-text-verified VSA propose+verify abductive reasoner (Rel-SAR, found in today's sibling drill — but for closed-vocabulary Raven's matrices, not open commonsense-KG relations), a grounded multimodal commonsense KG (MMCOMET, image-retrieval grounding on ATOMIC2020, passive resource, not CSKG, not measured-norm grounding), and a mainstream, active KG-rule-induction subfield (RNNLogic/AMIE/IterE/RulE) doing generate-and-test on conventional (non-grounded, non-VSA) KGs.
3. **The honest novelty gap is the CONJUNCTION and its specific operationalization, not any single piece: no one has (a) attached measured psycholinguistic-norm attribute vectors to CSKG nodes, (b) defined an explicit "spanning grounded core + grounding-reach" acceptance test as an engineering objective (though the underlying cognitive-science theory — Harnad's dual-code/MGS, Louwerse's Symbol Interdependency Hypothesis — is 15-35 years old and NOT ours to claim), or (c) run a hard-verifier generate-and-test loop for OPEN relational inference inside a self-contained VSA substrate.** Deflated P(the exact combination is genuinely unbuilt) = 0.35 — capped and further deflated because three independent partial-conjunctions (PRISM ~3/5 pieces, Rel-SAR ~2/5, MMCOMET ~2/5) surfaced within a few hours of searching, which raises real concern that convergent invention by others is close, not distant.

## Q1: CSKG provenance + purpose

**Authors/institution**: Filip Ilievski, Pedro Szekely, Bin Zhang — Information Sciences Institute (ISI), University of Southern California.

**Papers**:
- "CSKG: The CommonSense Knowledge Graph" — ESWC 2021 Resource Track (published as part of *The Semantic Web*, Springer LNCS; ACM/Springer DOI 10.1007/978-3-030-77385-4_41), also arXiv:2012.11490, submitted Dec 2020.
- Companion methodology paper: "Consolidating Commonsense Knowledge," arXiv:2006.06114 (Ilievski, Szekely, Cheng, Zhang, Qasemi) — defines the **five consolidation principles** CSKG applies (I could not pull a clean itemized list of all five principles this cycle past the abstract-level framing; flagging rather than fabricating the list).

**Sources merged (verified, 7 total)**: ConceptNet, ATOMIC, WordNet, Wikidata (the **Wikidata-CS subset**, not full Wikidata), FrameNet, Roget (thesaurus), Visual Genome.

**Scale (verified via GitHub README + corroborated search snippets)**: **2.2 million nodes, 6 million edges** after refinement/merge. Identity links: **251,517 `mw:SameAs` links** and **45,659 `fn:HasLexicalUnit` links** — this is the cross-source entity-resolution layer (linking e.g. a ConceptNet node, a WordNet synset, and a FrameNet lexical unit that denote "the same" concept). One secondary source cites an alternate/expanded release at 4.7M nodes/17.2M edges — I could not reconcile which release that figure belongs to this cycle; treat the 2.2M/6M figures as the primary-paper numbers and the larger figures as an unverified expanded variant, not silently picked.

**License**: CC BY 4.0.

**Data model**: KGTK (Knowledge Graph Toolkit) hyper-relational format, not RDF-only.

**What they evaluated on**: CSKG's own paper evaluates the GRAPH itself, not a downstream reasoner — text and graph embeddings (integrated into PyKeen, 25 embedding methods available), connectivity/well-connectedness analysis, and a demonstration that CSKG embeddings "provide evidence for generalizable downstream reasoning" and are useful "for pre-training of language models." Downstream consumers (not the CSKG authors themselves) have since used it for CommonsenseQA-style benchmarks and LM/GNN co-training (QA-GNN-style architectures). **Verdict: CSKG is a RESOURCE for external neural/symbolic consumers, not a reasoner built by its own authors.** This directly supports the "reuse the entity-resolution engine, do not rebuild it" plan already recorded in today's sibling note (`research_deliberate_ingest_spec_spanning_grounded_core_2026-07-10.md`).

## Q2: Did they ground it?

**No.** CSKG is symbolic-only — no measured perceptual/sensorimotor/numeric attribute vectors are attached to nodes in the base CSKG release; grounding is not mentioned as a design goal in either CSKG paper.

**Is there a grounded/multimodal variant?** Not of CSKG itself. The closest thing found is **MMCOMET** (arXiv:2603.01055, ~March 2026, targeting ACM SIGIR), which grounds **ATOMIC2020** (one of CSKG's 7 input sources, but not CSKG's merged graph) with visual evidence: a two-stage pipeline (CLIP-similarity matching for concrete phrases, concreteness-aware web image retrieval for abstract social/eventive concepts below a concreteness threshold), yielding 989K multimodal triples / 578K unique nodes / ~3.9M images across 19 relation types. Evaluated intrinsically (90.7% human-judged match) and extrinsically (VQAv2, Flickr30k captioning, visual storytelling). **Explicitly confirmed as a passive retrieval resource with no built-in reasoning mechanism** — it's auxiliary knowledge injected into other models, same positioning as CSKG itself.

**Gap**: nobody found grounds CSKG (or an equivalent consolidated commonsense KG) with **measured psycholinguistic-norm attribute vectors** (Lancaster sensorimotor norms, Brysbaert concreteness, Warriner VAD, Kuperman AoA) — MMCOMET's grounding is image-retrieval/CLIP-embedding-based, a different (and arguably "borrowed," per the substrate's own foundational discipline on borrowed-vs-measured grounding) kind of signal than direct human-normed measurement. This gap is real and matches exactly what today's sibling note already identified as the plan (ground CSKG's identity-resolved nodes with the 4-channel norm basis).

## Q3: Has anyone built our combination?

**(a) Glass-box / VSA-HDC / neuro-symbolic reasoning substrate over a consolidated commonsense KG.**
Closest hit: **PRISM** (github.com/Artaeon/prism) — self-described "neural-free cognitive architecture for knowledge reasoning based on Vector Symbolic Architectures." Uses the same operation family as our substrate (binding via circular convolution, unbinding via circular correlation, bundling, cosine similarity), integrates ConceptNet (600K+ assertions) + WordNet (117K synsets) + SimpleWiki via a "blackboard" multi-agent architecture with a "Contradiction Detector," and explicitly badges itself "No LLM required" (self-contained; output assembled via a template-free, vector-similarity-driven "Semantic Weaver," not an LLM). **How close**: very — self-contained + glass-box + VSA + commonsense-KG-adjacent, structurally the nearest thing to "our substrate" found anywhere. **Where it stops short**: (i) grounding is **spaCy word embeddings only** (300-d `en_core_web_md`) — text-distributional, not measured perceptual/sensorimotor norms, and no spanning-core/grounding-reach concept; (ii) reasoning is **explicit vector-algebra chaining** (analogy solving, multi-hop, `bind`/`unbind` composition) — not a generate-and-test loop with a rule generator and an independent hard verifier; (iii) uses ConceptNet+WordNet+SimpleWiki directly, **not CSKG's identity-resolved merge** (so no FrameNet/Roget/Visual Genome/Wikidata-CS layer, no `mw:SameAs`-style cross-source resolution); (iv) **maturity**: created 2026-02-08, 1 GitHub star, last substantive push 2026-02-10, **no paper, no peer review, no published benchmark numbers** — an unbenchmarked hobbyist prototype, not a validated system. This is simultaneously reassuring (nobody has built the full thing to a validated standard) and a warning sign (someone independently converged on 3 of our 5 defining pieces as a weekend project within the last 5 months — the idea is "in the air").

Also found: **VS-Graph** (arXiv:2512.03394) — HDC for general graph *classification*, not knowledge-graph reasoning, no grounding, not commonsense-specific. Not a close comparable. **"Encoder-Free Knowledge-Graph Reasoning with LLMs via Hyperdimensional Path Retrieval"** (arXiv:2512.09369) — uses HDC to replace the neural path-matcher inside an LLM-centric KG-reasoning pipeline over Freebase; the LLM still does query understanding AND final answer generation, so it is explicitly **not** self-contained or glass-box end-to-end, and has no grounding component. Useful as evidence that "HDC + large KG reasoning" is an active 2025-2026 research seam, but every published instance except the unpublished PRISM keeps an LLM in the loop.

**(b) Generate-and-test / rule-induction + exogenous-verifier inference mechanism over CSKG or similar.**
The mainstream version of this already exists and is a well-developed subfield: **AMIE** (support/confidence-scored rule mining), **RNNLogic** (arXiv:2010.04029 — RNN rule *generator* + EM-trained reasoning *predictor* that scores/selects generated rules — a textbook generate-and-test loop), **NBFNet**, **RulE** (arXiv:2210.14905), **IterE**, **GLIDR** (arXiv:2508.06716). These are neuro-symbolic (neural generator, symbolic rule output, verified against real graph support/confidence statistics) and are specifically credited in the literature with solving **inductive** relational inference where pure embedding methods fail — the identical fork this program's own sibling drill today (`research_generate_and_test_relational_inference_candidate_b_2026-07-10.md`) independently rediscovered from the KG-completion angle. **Where they stop short of our target**: evaluated on conventional KG-completion benchmarks (FB15k-237, WN18RR), not on CSKG/commonsense reasoning; not glass-box (rule *generator* is a trained neural net, only the rule *output* is symbolic); not grounded; not built on a VSA/HD substrate.

The closest VSA-native precedent for the generate-and-test SHAPE specifically (propose via unbind, verify via discrete consistency check) is **Rel-SAR** (arXiv:2501.11896 — "Systematic Abductive Reasoning via Diverse Relation Representations in Vector-symbolic Architecture"), already found and full-text-verified in today's sibling drill: propose candidate relation-operators by unbind-decomposition, verify by forward-applying the candidate across context and scoring consistency, select the best, apply its inverse to generate the answer. This is architecturally almost exactly our "propose (bind/unbind) + verify (hard consistency check)" design. **Where it stops short**: solves Raven's-matrices-style abstract visual reasoning over a small, closed, fixed relation vocabulary — not open-ended relational inference over a large, growing commonsense KG with an open/expanding relation set. **COMET** (arXiv:1906.05317) is the dominant "generate" baseline in the commonsense-KG world (GPT-based generation of new ConceptNet/ATOMIC triples, human-rated precision up to 77.5%/91.7%) but its "test" step is human judgment, not an algorithmic exogenous verifier, and it is explicitly LLM-based — the opposite of self-contained.

**(c) Grounding a KG from a spanning grounded core / grounding-kernel with grounding-reach as an objective.**
No hit found for this as a machine engineering objective (a "grounding-reach" metric or a formally-selected spanning grounded core used to bootstrap a KG's grounding). The genuine, decades-old theoretical precedent — already surfaced and cited in today's sibling note, not new to this drill — is **Harnad's dual-code account + the empirically-derived dictionary "grounding kernel"/"minimal grounding set" (MGS)** (Vincent-Lamarre/Blondin Massé et al., 2016, arXiv:1411.0129 and arXiv:0806.3710): a small core of words is directly sensorimotor-grounded, and everything else is grounded indirectly via symbolic recombination reducible to that core. **Louwerse's Symbol Interdependency Hypothesis** (*Topics in Cognitive Science* 2011; tested in PLOS ONE 2018 and Frontiers 2022 "test of indirect grounding of abstract concepts using multimodal distributional semantics," PMC9577286) is the closest existing *operationalization* of "grounding propagates from a core through language structure" — but it is a psycholinguistic theory tested via human behavioral/corpus correlational studies, not an engineering pipeline with a formal spanning-core selection + grounding-reach acceptance test for a machine reasoning substrate. **A closely-timed adjacent paper, "On Measuring Grounding and Generalizing Grounding Problems" (arXiv:2512.06205, ~Dec 2025), formalizes measurement of grounding across symbolic KGs/embeddings/LLMs** and is worth a direct, careful re-read (my WebFetch this cycle got PDF-parse-degraded output, not a clean read) — it is the single most likely paper to already contain something resembling a formal grounding-reach metric, given its recency and framing; I flag this as unresolved rather than claiming either way.

**Verdict for (c): the underlying THEORY (spanning grounded core -> propagation) is 15-35 years old and NOT ours to claim as novel. What appears (with moderate confidence, one paper unresolved) unbuilt is the OPERATIONALIZATION** — a measurable grounding-reach test used as a build/acceptance gate for a machine KG's ingest order, cross-walked through CSKG's identity-resolution layer.

**(d) Self-contained (no external LLM) grounded reasoner.**
No system found that is simultaneously self-contained AND measured-grounded. PRISM is self-contained but not measured-grounded (text-embedding only). MMCOMET is grounded but is a passive resource, not a reasoner, and its grounding is image-retrieval not measured-norm. This conjunction (self-contained + measured-grounded) appears to be a genuine, currently-empty cell in the landscape.

## Q4: The honest frontier — what's genuinely novel vs. already done

**Not novel, at all**:
- The generate-and-test PARADIGM NAME itself — this is literally Newell & Simon's Logic Theorist/GPS (1957-1961), the founding paradigm of symbolic AI. Zero novelty in the concept of "generate candidates, test them against a criterion."
- CSKG as a resource — already built, USC-ISI, 2020-21; correctly identified in today's sibling note as "adopt, don't rebuild."
- Rule-induction generate-and-test over KGs — mainstream, active subfield (RNNLogic/AMIE/IterE/RulE/GLIDR), 2018-2026.
- Glass-box symbolic cognitive architectures — Soar (Newell, 1980s-present), OpenCog/AtomSpace+PLN (Goertzel, 2008-present, now OpenCog Hyperon), NARS (Wang, 1990s-present) are all mature, decades-old, actively developed glass-box reasoning architectures.
- Sensorimotor/grounding hooks in a cognitive architecture — Soar's SVS (spatial-visual system) has existed for years specifically to bridge symbolic working memory and continuous perceptual representations.
- Spanning-grounded-core-propagates-to-abstract theory — Harnad/MGS (2016) and Louwerse (2007-2022), cognitive science, not new.

**Genuinely under-explored / plausibly novel (with the caveats above)**:
- The specific 5-way conjunction: self-contained + glass-box + VSA-HD (not AtomSpace/production-rules) + CSKG as the base substrate + measured-norm grounding + a hard-verifier generate-and-test loop for OPEN relational inference.
- Attaching Lancaster/Brysbaert/Warriner/Kuperman-style MEASURED norm vectors to CSKG's identity-resolved nodes specifically (as opposed to CLIP-image-retrieval grounding, which exists for ATOMIC2020 via MMCOMET).
- Using a formally-selected spanning grounded core (MGS + NSM primes) with an explicit, falsifiable "grounding-reach" acceptance test as a machine build objective, cross-walked through CSKG's existing identity layer.
- Running Rel-SAR-style propose(bind/unbind)+verify(consistency) generate-and-test on an OPEN, growing commonsense relation vocabulary rather than a small closed one (Rel-SAR's own scope).

**Strongest existing system(s) we'd be measured against**:
- For the "neuro-symbolic KG reasoner" axis: **RNNLogic/NBFNet/RulE-class rule-induction systems** — mechanism-adjacent (their generate-and-test shape is what we're borrowing), but built for different benchmarks (FB15k-237/WN18RR), not glass-box end-to-end (neural generator), not grounded, not VSA.
- For the "does a cognitive architecture already do this" axis: **Soar** is the most honest comparison — mature, glass-box, has a real perceptual-grounding subsystem (SVS) — but its own maintainers state explicitly: *"Soar agents have neither core knowledge systems nor large bodies of commonsense knowledge"* (per Laird's own "Introduction to the Soar Cognitive Architecture," arXiv:2205.03854, and corroborating overview sources) — i.e., the architecture that HAS the glass-box+grounding-hook pieces explicitly LACKS the commonsense-KG-scale integration piece. OpenCog/NARS are similar in spirit (glass-box, symbolic-probabilistic) but neither was found combined with CSKG or an equivalent consolidated commonsense KG at this scale, nor with VSA/HD as the representation substrate.
- For the "VSA reasoning that already works" axis: **PRISM** (closest overall conjunction, unpublished/unbenchmarked) and **Rel-SAR** (closest generate-and-test mechanism, published/verified, narrower scope).
- For "generate commonsense knowledge" specifically: **COMET** remains the dominant baseline, and it is exactly the kind of external-LLM-dependent system our self-contained framing is defined against.

## Q5: The "are we reinventing" verdict

**Partial reinvention risk, honestly stated**: the CORE MECHANISM SHAPE (propose via bind/unbind, verify via discrete consistency/support check) is not original — it is Rel-SAR's already-published, already-working design, applied to a narrower problem. The CORE ARCHITECTURE SHAPE (self-contained, glass-box, VSA, blackboard-style multi-source integration over ConceptNet/WordNet-class sources) is not original either — PRISM got there first as an unpublished prototype, with a similar operation set. **What is not reinvention**: using CSKG specifically (rather than a hand-rolled ConceptNet+WordNet merge like PRISM's) — CSKG's identity-resolution layer is a genuine, nontrivial, already-solved engineering problem worth adopting wholesale, and no VSA/cognitive-architecture system found uses it. Attaching measured psycholinguistic-norm grounding (rather than text embeddings or CLIP-image-retrieval) is not reinvention of anything found. The spanning-grounded-core-as-build-objective operationalization is not reinvention of an existing SYSTEM (though it does directly operationalize a 15-35-year-old THEORY that must be cited, not claimed as ours).

**Should we just USE or heavily borrow from an existing system?** Two clear "yes, borrow" answers: (1) **use CSKG itself as the base KG** — do not rebuild the ConceptNet/ATOMIC/WordNet/Wikidata-CS/FrameNet/Roget/Visual-Genome merge or its 251,517 identity links; this is settled and already the plan. (2) **borrow Rel-SAR's propose/verify mechanism shape** for the generate-and-test cell design — it is published, full-text-available, and mechanism-verified as working on a VSA substrate; re-deriving the same shape from scratch would be wasted effort when a working reference implementation exists (arXiv:2501.11896, code likely available — not checked for a public repo this cycle, worth a follow-up check). Everything else (grounding-from-spanning-core operationalization, the specific self-contained+glass-box+VSA+CSKG+grounded conjunction) does not have an existing system to adopt wholesale — PRISM is closest in spirit but is a 1-star, unbenchmarked, 5-month-old side project, not a system mature enough to build on top of (no public benchmark, no paper, thin test coverage by its own admission).

**Honest deflated-novelty P**: **P = 0.35** that the exact 5-way combination (self-contained + glass-box + VSA + CSKG-as-substrate + measured-spanning-core grounding + open-relation generate-and-test with hard verifier) is genuinely unbuilt anywhere as of this search. Per calibration discipline this is already capped at the 0.50 novel-synthesis ceiling and further deflated below it (not just to the cap) because three independent, partial conjunctions (PRISM, Rel-SAR, MMCOMET) surfaced within a few hours of ordinary search effort — a base rate that says "people are actively assembling pieces of this in 2025-2026," which should worry us about a near-term independent full assembly by someone else, not reassure us that the space is empty. **NOVELTY VERDICT, bluntly: we are not reinventing CSKG (correctly reusing it), we are not reinventing the generate-and-test paradigm (correctly borrowing Rel-SAR's mechanism shape), and no cognitive architecture (NARS/OpenCog/Soar) already does this — but a solo unpublished hobbyist got roughly 60% of the way to our architecture shape five months ago, which is a genuine signal to move with urgency, not a reason to feel first-mover-safe.**

## Falsifiable predictions (HARD-PASS / HARD-FAIL)

- **HARD-PASS (novelty holds)**: a direct search of PRISM's actual source code (not just README) and any Rel-SAR follow-on repo shows neither has (a) CSKG-specific identity-layer usage, (b) any measured-norm grounding channel, or (c) an open-relation-vocabulary generate-and-test loop with a hard support/confidence verifier. If all three hold, our combination remains a clean, uncontested gap.
- **HARD-FAIL (novelty collapses further)**: PRISM's source (unreviewed this cycle beyond README) turns out to already implement a rule-generation/verification loop beyond "explicit vector-algebra chaining" (i.e., the README undersold it), OR a 2026 paper surfaces combining CSKG + any norm-grounding channel + any VSA reasoning mechanism. Either would move P below 0.35 immediately and should trigger a same-day re-drill, not a wait-for-cadence re-check.
- **HARD-FAIL, informational (about the theory precedent, not the system)**: if a direct read of "On Measuring Grounding and Generalizing Grounding Problems" (arXiv:2512.06205) turns out to already define a formal grounding-reach-equivalent metric, the spanning-core operationalization gap in Q3(c) closes partially — cite it, do not re-derive independently, and adjust the ingest-spec note's framing to credit prior formalization rather than presenting the metric as newly operationalized here.
