## (a) HEADLINE

**The concrete risk is real and worse-understood than it looks: every published VSA/HRR capacity theorem I could verify (Frady-Sommer 2018, Kent-Frady-Olshausen-Sommer Resonator Networks 2020, Schlegel-Neubert-Protzel 2020, Generalized HRR 2024, Ganesan et al.'s learned-HRR 2021) is derived strictly under an i.i.d.-independent-components codebook assumption, and every one of them either states this as a hard precondition or explicitly flags correlated/structured/learned codebooks as unanalyzed future work — there is NO published closed-form formula predicting how much unbind fidelity degrades as a function of codebook coherence.** This is a genuine literature gap, not something this lit-scan failed to find (the Resonator Networks paper flags it twice as an open problem). What DOES transfer cleanly, because it is architecture-agnostic detection theory, is the generic result that a correlation-detector cleanup step (which is exactly what FHRR's "unbind + nearest-neighbor against the lexicon" is) suffers interference proportional to the pairwise inner product between the true filler and every other item sharing the same superposition — the identical math structure as CDMA matched-filter near-far interference and classical correlated-pattern Hopfield capacity (Löwe 1998 proves capacity degrades monotonically with pattern correlation). Crucially, **this exact risk has already materialized and been formally landed on THIS substrate, in a sibling mechanism**: the 2026-06-25 anisotropy drills and the `effective_rank_svd` cert chain both found real learned embeddings here sit at effective rank far below nominal dimension (d_eff/D as low as 0.09–0.24 across tested encoders), and a from-scratch attempt to fix this with whitening HARD_FAILED (+0.020 recovery only) precisely because whitening is a rotation that cannot add rank — only mechanisms that ADD independent directions (sparse expansion, cerebellar/fly-LSH-style pattern separation) or DECOMPOSE the problem (partition routing) actually rescued retrieval, both already chain-grade-validated elsewhere in this codebase. Additive_map's own X matrix (k=24, real-valued, TransE-fit) is a DIFFERENT vector — never measured for anisotropy — but the mechanism-class risk is not hypothetical here; it is a repeat of a problem this substrate has already diagnosed and partially solved once, in code that is directly reusable.

## (b) Cheap decisive test

Isolate the GEOMETRY question from the LEXICON-LEARNING-RULE question (the grounding note's Prediction 2/3 concern) by testing with an ORACLE lexicon (perfect ground-truth word-to-concept mapping, no learning involved) before ever touching the learned lookup table:

1. **Pre-flight (near-zero cost, no bind/unbind run at all):** compute the three diagnostics in section (c) directly on additive_map's `X` (or on `compose_entity()` outputs for the specific entities that will serve as fillers). This can run before any FHRR mechanism executes.
2. **Isolated geometry probe:** take the existing `exp_nativelang_svo_vsa_probe_v1.py` scaffold unmodified (bind/unbind/cleanup/bundle primitives, roles, SVO grammar) and swap ONLY the lexicon: instead of `make_phasors()` random unit-phasors, supply real concept vectors (however exp_dev's lift/expansion from `X`'s k=24 real coordinates into N-dim unit-modulus phasors is constructed — not prescribed here) for a SMALL set of entities that also have degree/coherence diagnostics computed. Run the SAME held-out compositional-generalization sweep already built into that script (including its `--stress` mode), with an ORACLE lexicon (the true word->concept mapping is known, not learned) so any degradation is attributable ONLY to filler geometry, not to a lexicon-learning failure.
3. Compare `mech_heldout` accuracy at matched (N, n_slots/vocab) between the RANDOM-phasor baseline (already run, existing negative-result-free data) and the REAL-concept-filler arm.

**HARD-PASS (geometry is NOT the bottleneck):** real-filler oracle-lexicon `mech_heldout` is within 5 points absolute of the matched random-phasor baseline, at every (N, vocab) cell already characterized in the existing stress sweep.

**HARD-FAIL (geometry IS a load-bearing bottleneck):** real-filler oracle-lexicon accuracy drops ≥15 points absolute below the matched random-phasor baseline AND at least one of the three geometry diagnostics (section c) reads elevated relative to an i.i.d.-control codebook of the same size/dimension — this combination is what licenses attributing a downstream HARD-FAIL to geometry rather than to the lexicon-learning rule.

**MIDDLE:** degradation in the 5–15 point band, OR degradation without diagnostic attribution (this second case would implicate something else entirely — most likely a modulus-deviation artifact from the real-to-phase lift itself, not codebook coherence; flag and re-test the lift's unit-modulus fidelity directly before concluding anything about coherence).

## (c) Cheap diagnostic — computable before any bind/unbind sweep runs

All three are computable directly from `additive_map`'s `X` matrix (or `compose_entity()` outputs) plus the KG triples' degree counts — no FHRR mechanism needs to run first.

1. **Mutual coherence excess over the Welch floor.** Compute `mu = max_{i != j} |cos(c_i, c_j)|` over the concept codebook that will serve as fillers (chunked Gram matrix, or a random-pair sample if M is large). The Welch bound gives the geometric floor any M-vector, N-dim codebook must sit at or above: `mu >= sqrt((M-N)/(N(M-1)))` for M>N. Report `mu_measured - mu_Welch_floor` — real learned embeddings are known (Ethayarajh 2019; Gao et al. 2019; Mu & Viswanath 2018) to sit far above this floor because their effective rank is far below nominal dimension; this substrate's own `effective_rank_svd` cert already confirms that pattern for other encoders (d_eff/D as low as 0.09–0.24).
2. **Effective rank / participation ratio.** `PR = (sum(lambda_i))^2 / sum(lambda_i^2)` on the concept covariance (or Gram-matrix eigenvalues) — this is the EXACT diagnostic already chain-grade-validated on this substrate for the sibling encoder-anisotropy problem (`exp_r3_encoder_anisotropy_diagnostic_v1`, `effective_rank_svd_v1`/`_multi_encoder_v1`). Reusing it here costs nothing new to implement. Because `X` is already low nominal dimension (k=24, not 384–2560 like the previously-tested encoders), this measures a related but distinct question: not "is a big space secretly small" but "is this already-small k=24 space further concentrated by relation/degree clustering into an even smaller effective sub-cone."
3. **Degree-cosine correlation.** Spearman correlation between each entity's KG in/out-degree (in the training triples) and its average pairwise cosine similarity to all other candidate fillers (or distance-to-centroid). This directly operationalizes the degree-bias/hubness literature found this cycle (KG-Mixup's documented TransE-family degree bias; entity-alignment hubness-correction literature) and predicts a SPECIFIC, checkable failure signature distinct from generic noise: high-degree entities becoming false nearest-neighbor cleanup targets for queries meant for their low-degree neighbors, not just uniformly worse accuracy.

**Attribution rule:** if a downstream bind/unbind HARD-FAIL occurs WITHOUT any of these three tripping (relative to an i.i.d.-random control codebook of matched size/dimension computed alongside), the failure is NOT geometry — it localizes to the lexicon-learning rule or to the real-to-phase lift's modulus fidelity, and should be debugged there instead.

## (d) Glass-box fix menu — ranked by cost, complementary to (not prescriptive of) exp_dev's vector construction

Ranked cheapest-to-try first, but flagged where substrate's OWN prior evidence (not just generic literature) predicts a fix will underperform.

1. **Per-role subspace isolation (already implicit in the existing scaffold's design).** Cost: free — the scaffold already draws roles as separate ideal random phasors. This isolates ROLE-axis crosstalk from FILLER-axis crosstalk so the diagnostic in (c) cleanly attributes any failure to the CONCEPT codebook, not confounded by role-vector quality. Breaks nothing; doesn't fix the actual concept-geometry problem, only prevents it from being mis-attributed.
2. **Unit-modulus renormalization of the real-to-phase lift.** Cost: near-zero (elementwise phase-map or L2 renormalize). Fixes the "modulus deviation" axis — necessary for FHRR's conjugate-multiply self-inverse guarantee to hold algebraically at all — but does NOT address codebook coherence/anisotropy. Necessary, not sufficient; do this regardless of what else is chosen.
3. **Whitening/ZCA of the concept space before lift.** Cost: cheap (k=24-dim covariance, trivial O(k^3) eigendecomposition). **Flagged LOW-EXPECTED-VALUE specifically because this substrate already ran this exact fix on a sibling anisotropy problem and it HARD_FAILED** (`exp_dense_KV_whitening_revival_v1_gpu`: +0.020 recovery only) — whitening is a linear rotation, cannot add effective rank, and the substrate's own prior evidence says the bottleneck here is rank, not rotation. Additional risk specific to this task: whitening must be applied to a language-module-PRIVATE projected copy, never to the canonical `X`, or it will disturb additive_map's own Euclidean TransE scoring geometry that the grounding note's substrate-product-implication #4 explicitly wants to keep shared and untranslated.
4. **Random expansion/lift from k=24 into N-dim space (JL-style).** Cost: cheap, one fixed seeded matrix, O(k·N) matmul. Preserves relative angles (Johnson-Lindenstrauss) but does NOT by itself decorrelate concepts that are genuinely close in the k=24 TransE space — it changes ambient dimension without changing the underlying manifold's effective rank, so it likely under-fixes real degree/relation clustering on its own. Best understood as a necessary but insufficient precursor to (5).
5. **Sparse-expansion + WTA-style decorrelation pre-lift.** Cost: MEDIUM — reuses this substrate's OWN chain-grade-validated cerebellar/fly-LSH-style pattern separator (already HARD_PASS on the sibling dense-KV anisotropy problem: `exp_substrate_anisotropy_rescue_4arm_sweep_v2_calibrated_meter_full`, fly-LSH arm 0.997 at M=10k vs raw 0.018), repurposed as the concept-to-phasor lift instead of a naive linear/phase map. **This is the HIGHEST-EXPECTED-VALUE fix given this substrate's own prior evidence** — but it is an adaptation, not a drop-in: the existing mechanism produces sparse-binary/WTA codes, not FHRR unit-phasors, so translating the winning mechanism CLASS into phase representation is itself a small design step that hasn't been done for FHRR specifically, only for the bipolar/HRR sibling. Flag honestly as adaptation-required.
6. **Two-tier indirection (escape hatch, most expensive, most robust).** Decouple "the vector used AS a VSA filler" from "the vector used for TransE Euclidean scoring" entirely: give each concept a genuinely-random FHRR handle (ideal geometry by construction, exactly matching the validated SVO-probe baseline), and reach the concept's actual content via a SEPARATE hop through additive_map's own `compose_entity()`/scoring machinery. Cost: HIGH — reintroduces a translation layer the grounding note's substrate-product-implication #4 explicitly wanted to avoid ("use the SAME vectors as both fillers ... no translation layer needed"), and adds an indirection hop to every parse/generate call. Benefit: sidesteps the entire geometry-degradation risk by construction, since bind/unbind then always operates on ideal phasors exactly as already validated. Worth keeping in reserve if ranks 2–5 all fail the diagnostic in (c).

## Falsifiable predictions (HARD-PASS / HARD-FAIL)

**Prediction 1 — real concept-filler geometry measurably degrades oracle-lexicon unbind fidelity relative to the matched random-phasor baseline, before any lexicon-learning-rule effects are introduced.**
HARD-FAIL (risk materializes): ≥15-point absolute drop in `mech_heldout` at matched (N, vocab), with at least one geometry diagnostic elevated vs an i.i.d. control. HARD-PASS (risk does not materialize): within 5 points, regardless of diagnostic readings.
P estimate: **P=0.55** (deflated from a raw ~0.75; raised by strong, well-verified generic-detection-theory transfer — matched-filter interference and Löwe's rigorous correlated-Hopfield capacity degradation are both solid, directly-transferable results — and by this substrate's own directly analogous prior negative result on a sibling mechanism; deflated because no VSA-specific paper measures this for FHRR bind specifically, and one primary source found this cycle, Kent et al.'s Resonator Networks 2, explicitly notes correlated codevectors can sometimes RAISE capacity under a least-squares/OLS decode rule rather than lower it — our decode rule, plain conjugate-multiply + nearest-neighbor cleanup, is the matched-filter-style rule more likely to be the vulnerable one per that same source, but this is one paper's aside, not a proven law).

**Prediction 2 — the three cheap pre-flight diagnostics (coherence excess over Welch floor, effective rank/participation ratio, degree-cosine correlation) correctly predict which configurations will show the Prediction-1 degradation, enabling clean geometry-vs-lexicon-rule attribution.**
HARD-PASS: diagnostic elevation (relative to i.i.d. control) correctly flags every cell where the isolated geometry probe shows ≥15-point degradation, and does NOT flag cells that pass within 5 points. HARD-FAIL: diagnostics are elevated in passing cells, or fail to flag degrading cells (false negative on the very case this exists to catch).
P estimate: **P=0.35** (novel-synthesis capped at 0.50 per contract, deflated further — each individual diagnostic component is well-precedented in isolation, but this exact composite has never been validated as a joint predictor of FHRR unbind failure specifically; effective-rank and coherence are known to be correlated with each other, which could make the composite redundant rather than more informative than any one alone — untested).

**Prediction 3 — IF the cell reaches HARD-PASS on Prediction 1 (geometry doesn't materially degrade unbind), the real-filler headroom (max fillers/slots before crosstalk breaks it) will still be materially lower than the already-measured random-phasor ceiling, by roughly an order of magnitude.**
HARD-PASS(of this prediction, i.e. confirms lower headroom): real-filler crosstalk frontier (from re-running the existing `--stress` sweep with real fillers) sits at 4-10x fewer usable fillers/slots than the random-phasor frontier at matched N. HARD-FAIL: real-filler headroom is statistically indistinguishable from the random-phasor ceiling (would mean the concept geometry, despite being non-ideal by the diagnostics, doesn't actually cost capacity in practice — a genuinely informative negative, per Kent et al.'s aside above).
P estimate: **P=0.35** (deflated; the DIRECTION (some capacity discount) is reasonably well-grounded by analogy to this substrate's own d_eff/D~0.1–0.25 prior on a different mechanism, but the MAGNITUDE transfer from a totally different mechanism class (dense-KV superposition vs FHRR role-filler bind) and a totally different vector source (frozen sentence/LM encoders vs a k=24 TransE fit) is weak evidence — capped low; no published or substrate-measured formula exists to derive this number analytically, per the confirmed literature gap in section (a)).

## Substrate-product implications

1. **Run the pre-flight diagnostics in (c) before writing a single line of the bind/unbind sweep.** They are cheap (reuse the already chain-grade-validated `effective_rank_svd` diagnostic code, add a Gram-matrix coherence pass and a degree-Spearman pass), and they turn any later HARD-FAIL from an ambiguous "something broke" into an immediately attributable "geometry" vs "lexicon-rule" result — directly what the Director asked this drill to produce.
2. **Do not reach for whitening as the first fix.** This substrate already spent a full cell proving that class of fix underperforms on a directly analogous problem; re-litigating it here without first checking the diagnostics would waste a cycle re-deriving an already-landed negative result.
3. **The highest-expected-value fix (rank 5, sparse-expansion pattern-separator) is a transplant, not an invention** — the mechanism is chain-grade-validated elsewhere in this codebase; the work is adapting its output format (sparse-binary/WTA) into FHRR's unit-modulus phase representation, a bounded, well-scoped engineering task.
4. **Keep the two-tier indirection (rank 6) explicitly in reserve, not adopted by default** — it would trade away the grounding note's stated goal of a translation-layer-free shared vector space between the language scaffold and additive_map's own reasoning readout, so it should only be reached for if the cheap diagnostics in (c) actually trip and ranks 2–5 are tried first.
5. **Headroom claims (Prediction 3) should not be extrapolated from the sibling dense-KV mechanism's numbers directly** — the mechanism class, decode rule, and vector source all differ enough that only a first-party stress-sweep re-run with real fillers (reusing the existing `--stress` mode already built into the SVO probe) should be trusted for a headroom number; treat any pre-measurement estimate (including this note's own order-of-magnitude guess) as a placeholder, not a design constraint.
