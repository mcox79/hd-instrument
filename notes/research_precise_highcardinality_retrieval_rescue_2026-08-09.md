# Research: precise high-cardinality associative/causal retrieval — the rescue for the anticipated Stage-2 scale wall

**Filed-by:** research sub-agent, 2026-08-09. 4 parallel Sonnet lit-scan lanes (topdowngating, sparsepatternsep, resonatorcapacity, evtstats) + owned-substrate recon (situation_focus.py, cleanup_family.py, kg_traversal.py, exp_resonator_* family, exp_focus_pullin_causal_stage1_micro_world_v1.py, capability_registry.jsonl).

**Trigger:** director task — the Cowan-4 focus (`hdlab/situation_focus.py`) pulls in "close" content from a large activated-LTM field (~1.24M-edge CSKG causal store) via a salience-gated `iterative_attractor` (`hdlab/situation_focus.py` + `experiments/exp_focus_pullin_causal_stage1_micro_world_v1.py`), validated HARD-PASS at toy scale (30 events, 0.0 false-pull-in). The anticipated wall: at high cardinality the flat salience gate over-pulls, the same failure class that collapsed MCScript2.0 clustering (195 scenarios -> 35 buckets, purity 0.20, k-WTA DG-separation failed on a weak raw cosine-0.18 signal). This drill finds the rescue in parallel with Stage-2 sub-test B measuring the failure directly.

## HEADLINE

The wall is real and has a name: **extreme-value inflation of the max-over-M null-similarity score.** A fixed admission threshold (`GATE_THRESH=0.28`) calibrated against M=30 distractors implicitly relies on `E[max of 29 noise-cosine draws]`; at M~1.24M that same expectation grows by a **~2x factor in standardized (z-score) units** (`sqrt(2*ln(1.24e6)) / sqrt(2*ln(29)) ~ 2.03`, classic Gaussian-order-statistics scaling — Gumbel 1958; textbook EVT), purely from taking a max over far more draws, with no change to the substrate's per-item discrimination quality. This is a generic mathematical certainty, not a substrate-specific defect, and it is the SAME crosstalk-capacity math family (Willshaw/Buneman/Longuet-Higgins 1969; Hopfield 1982; Tsodyks & Feigelman 1988; Thomas/Dasgupta/Rosing JAIR 2021) already used in-house to diagnose the resonator's K5/K6 crosstalk cliff (`exp_resonator_dg_crosstalk_disentangler_v1.py`).

The brain's answer is convergent across four independent literatures (fan-effect/ACT-R, biased competition, PFC context-gating, predictive-coding precision) and one structural literature (hippocampal indexing/DG pattern separation): **never search flat over everything and threshold after the fact — narrow the effective candidate set BEFORE similarity scoring, via a context/goal-conditioned gate, THEN clean up within the narrowed set.** The critical diagnostic finding (lane sparsepatternsep, converging on Cayco-Gajic/Clopath/Silver 2017 *Nat Commun* + O'Reilly & McClelland 1994): **competitive/WTA sharpening cannot manufacture separation from a weak signal — it can only sharpen a signal that an upstream expansion/decorrelation step already made separable.** This precisely diagnoses why MCScript2.0's k-WTA failed (applied directly to a weak, low-effective-dimensionality raw-cosine-0.18 signal, with no expansion-recoding stage first) — and it is a DIFFERENT failure mechanism than the one Stage-2-B is anticipated to hit (EVT max-growth on an otherwise-healthy signal, not a fundamentally weak one — Stage-1's clean 0.0 false-pull-in on role-bound `EventBundleCodec` vectors is evidence the per-item signal here is NOT MCScript2-weak). Conflating the two would misdiagnose the fix; they need different rescues (see below).

**The recommended rescue is not hypothetical — it is already built and already validated three orders of magnitude beyond Stage-1's toy scale.** `hdlab/kg_traversal.py::KGStore` is a chain-grade-certified (CERT 585, n8 ConceptNet ingest_eval_v1, `data/capability_registry.jsonl` status WIRED) relation/context-conditioned retrieval primitive: its `key(s, p) = E[s]*R[p]*sqrt(N)` binds the probe with a TYPE/CONTEXT before scoring — exactly the brain-faithful "narrow-then-score" operation — and it is independently validated at `setrecall@M=100000 = 1.000` with `refuse_OOD = 0.999` across 3 seeds. It also already ships `refuse_gate_calibrate()`, a calibrated (in-KB-vs-OOD split) threshold selector — precisely the fix the EVT diagnosis calls for in place of a hand-set constant like `GATE_THRESH=0.28`. The gap is wiring this into `situation_focus.pull_in()`, not inventing new mechanism.

## Cheap decisive test

**"Stage 1.5: salted-cardinality micro-world."** Reuse Stage-1's exact 5-cluster x 6-event micro-world (`build_microworld`, `build_causal_facts`, `BipolarCausalRegister`) unmodified — same planted long-distance relations, same `EventBundleCodec`. SALT the codebook with `N_DISTRACTOR` synthetic unrelated distractor events (same `EventBundleCodec` construction, disjoint symbol namespace, no causal/associative relation to the 5 real clusters or each other), at three cardinality rungs: M~1,000 / M~10,000 / M~100,000 (CPU-cheap — no real CSKG needed to run this gate; it isolates the cardinality variable alone). Three arms per rung:

1. **FLAT (current `pull_in()`, unmodified):** `iterative_attractor` over the full salted codebook, fixed `GATE_THRESH=0.28`. Predicted: `false_pull_in_rate` rises with M (confirmatory replication of the EVT-predicted wall).
2. **CONTEXT-CONDITIONED (Rank-1 rescue):** bind the probe with the current `ChunkedFocus`'s own active-context key (a `KGStore`-style `E[context]*R[relation]`-style pre-bind, restricting the candidate pool to a coarse-index shortlist) BEFORE running `iterative_attractor` cleanup within that shortlist; threshold set via `refuse_gate_calibrate()`-style in-set/out-of-set calibration instead of a fixed constant. Predicted: `false_pull_in_rate` stays within ~1.5x of the Stage-1 M=30 baseline (~0.0) across all three rungs.
3. **DISTRACTOR-ONLY NULL SWEEP:** query every distractor against the full salted codebook (no real relation exists) and record the empirical max-cosine distribution at each M rung. This directly measures whether the EVT `sqrt(2*ln M)` scaling actually appears in this substrate's specific codebook geometry (structured bipolar role-bound vectors, which have shared-role correlations unlike idealized iid Gaussians) rather than assuming the idealized curve transfers unmodified.

## Falsifiable predictions

**HARD-PASS (rescue confirmed):**
- FLAT arm `false_pull_in_rate` at M=100,000 is >= 2x its M=1,000 value (wall is real, EVT-shaped, reproduces at scale) AND

**HARD-FAIL (rescue does not work / wrong diagnosis):**
- CONTEXT-CONDITIONED arm ALSO rises >= 2x by M=100,000 (context-conditioning insufficient; the coarse index itself is not discriminating — likely needs the resonator/expansion lever, see Rank-2/3 below) OR

**MIDDLE_BAND:** partial rescue (context-conditioning slows but does not bound the rise) — informative; would motivate layering Rank-3 (expansion+sparsify) under Rank-1 rather than treating Rank-1 as sufficient alone.

## Cross-thread synthesis

### Brain mechanisms for precise retrieval at scale (why fan-out doesn't explode)

**A. Top-down context/goal-gating (narrows BEFORE scoring, not after):**
- ACT-R fan effect / source activation (Anderson & Reder 1999; Danker, Fincham & Anderson 2011, *Neuropsychologia* 49:2427-2438) — activation is a FIXED total budget divided among all associates sharing a cue feature (inversely proportional to fan); a converging second cue multiplies activation onto only the INTERSECTION. Fan-out doesn't explode because activation is conserved, not additive-without-bound.
- Biased competition (Desimone & Duncan 1995, *Annu Rev Neurosci*) + normalization model of attention (Reynolds & Heeger 2009, *Neuron* 61:168-185) — top-down bias is a multiplicative gain field applied BEFORE competition resolves; divisive normalization caps total activity regardless of candidate count.
- PFC context-gating (Cohen & Servan-Schreiber 1992, *Psychol Rev*; O'Reilly & Frank 2006, *Neural Computation*, "Making Working Memory Work" / PBWM) — a maintained context representation acts as a binary/selective admission gate UPSTREAM of retrieval; non-matching candidates never enter the competition.
- Predictive-coding precision-weighting (Feldman & Friston 2010, *Front Psychol*) — attention = precision-gain on prediction-error units; low-precision (contextually-irrelevant) channels are suppressed during inference itself, not filtered post-hoc.
- Direct answer to "narrow-then-score vs score-then-filter": all four literatures converge on narrow-then-score as the brain-faithful order. None describes flat similarity-then-threshold.

**B. Sparse/expansion coding + pattern separation (why WTA alone cannot rescue a weak signal — the MCScript2 diagnosis):**
- Kanerva Sparse Distributed Memory (1988 book; Kanerva 2009, *Cognitive Computation* 1(2):139-159) — near-orthogonality in high dimensions gives reliable separation at large item counts; the number of quasi-orthogonal directions grows exponentially with dimensionality.
- Dentate gyrus expansion recoding (Marr 1971, *Phil Trans R Soc B*; Leutgeb, Leutgeb, Moser & Moser 2007, *Science* 315:961-966; Yassa & Stark 2011, *Trends Neurosci* 34:515-525): EC layer II -> DG is a ~10x expansion in rat (~112,000 EC-II cells -> ~1.2M granule cells; ~15M in human), THEN strong local inhibition/competition. O'Reilly & McClelland 1994 (*Hippocampus* 4:661-682) and Treves & Rolls 1994 (*Hippocampus* 4:374-391): separation quality is gated by the VARIANCE/SIGNAL reaching DG via few-but-strong mossy "detonator" synapses; CA3 attractor dynamics (the substrate's `iterative_attractor` analog) complete/clean up an ALREADY-separated pattern, they do not create separation.
- **The decisive citation for the MCScript2 diagnosis:** Cayco-Gajic, Clopath & Silver 2017, *Nat Commun* 8:1116 — pattern separation is "restricted to networks with few synaptic connections per neuron"; sparse CONNECTIVITY (the expansion+sparsification of the feedforward projection) is REQUIRED to decorrelate correlated inputs — dense/unsparsified projections cannot be separated downstream regardless of competitive sharpening. Marr/Albus 50-years-later review (2020, *Progr Neurobiol*): expansion into high-D space is what MAKES patterns linearly separable for a later WTA/readout stage to exploit; the readout does not manufacture separability.
- Retrieval-induced forgetting (Anderson, Bjork & Bjork 1994, *JEP:LMC* 20(5); M.C. Anderson 2003, *J Mem Lang* 49:415-445) — actively retrieving one memory suppresses competing associates for 20+ minutes, sharpening FUTURE retrieval precision (a post-hoc competitor-inhibition mechanism, distinct from upstream expansion).
- Hippocampal indexing theory (Teyler & Rudy 2007, *Hippocampus* 17:1158-1169) — hippocampus stores an INDEX, not content; retrieval is address-then-content. McClelland & Rogers 2003 (*Nat Rev Neurosci* 4:310-322) — graded hierarchical/hub-like semantic organization from PDP learning, not flat search.
- **Diagnosis of MCScript2.0's k-WTA failure:** the greedy scenario-keying collapse (195 -> 35 buckets, purity 0.20) applied k-WTA competition DIRECTLY to a weak, low-effective-dimensionality raw signal (cosine ~0.18, likely from shallow/pooled sentence embeddings) with NO prior expansion-recoding stage. Per Cayco-Gajic/Clopath/Silver and O'Reilly/McClelland, this is precisely the predicted failure mode: WTA sharpens, it does not create, separability. **What is different in the focus-pullin case:** `EventBundleCodec`'s role-slot binding is itself closer to an expansion/decorrelation step (structured, high-dimensional bipolar encoding, not a pooled low-D sentence embedding) and Stage-1's clean 0.0 false-pull-in at M=30 is direct evidence the per-item signal here is NOT MCScript2-weak by construction. The anticipated Stage-2 wall is therefore hypothesized to be the EVT-cardinality mechanism (a healthy signal overwhelmed by a fixed threshold at large M), not the MCScript2 weak-signal mechanism — a testable, falsifiable distinction (see cheap decisive test arm 3, the null-sweep).

### FHRR/VSA substrate options, ranked

**Rank 1 (RECOMMENDED) — context-conditioned pre-filter + calibrated threshold, reusing `KGStore`.**
Brain mapping: PFC context-gating + hippocampal indexing (address-then-content) + biased-competition's pre-resolution gain field. Owned organs: `hdlab/kg_traversal.py::KGStore.key(s,p)` (relation/context-conditioned bind, chain-grade CERT 585, `setrecall@M=100000=1.000`, `refuse_OOD=0.999`, registry WIRED) + `KGStore.refuse_gate_calibrate()` (in-KB-vs-OOD calibrated threshold, replaces the fixed `GATE_THRESH` constant) + `hdlab/cleanup_family.py::iterative_attractor` (existing `pull_in()` core, now scoped to the narrowed candidate pool instead of the full codebook). This is a two-stage coarse-then-fine pattern matching the standard large-scale ANN literature (Jegou/Douze/Schmid 2011 Product Quantization; Johnson/Douze/Jegou 2019 FAISS/IVF, validated to 2 billion vectors) — a well-understood, generic way to hold precision as database size grows. Lowest structural risk: reuses an already-3-orders-of-magnitude-validated primitive; the open question is translating it from KG-completion (predict object given subject+relation) to pull-in admission (accept/reject a retrieved candidate into focus), which the cheap decisive test isolates directly.

**Rank 2 — resonator factorized retrieval.**
Brain mapping: sparse/near-orthogonal coding (Kanerva) + the KG's natural (s,p,o)-factored structure. Owned organs: `experiments/exp_resonator_factorization_v1.py` (true iterative alternating-projection joint-factor resonator), `experiments/exp_substrate_resonator_focus_lever_v1.py` (hierarchical 2-group decomposition, F=6/8), `experiments/exp_resonator_dg_crosstalk_disentangler_v1.py` (already diagnoses the M^K vs N^2 crosstalk-capacity-cliff math for exactly this problem class, with a validated dimensional-expansion rescue). Literature: Frady, Kent, Olshausen & Sommer, "Resonator Networks, 1," *Neural Computation* 32(12):2311-2331, 2020; Kent, Frady, Sommer & Olshausen, "Resonator Networks, 2," *Neural Computation* 32(12):2332-2388, 2020 (companion papers, verified) — factor a bound composite into K constituents each drawn from its own size-M codebook, implicit search space M^K, cost linear in K*M, NOT M^K; Part 2's empirical capacity law: max sustainable per-factor codebook size scales quadratically with dimensionality (M_max ~ N^2). Instead of one flat M~1.24M-item lookup, decompose the causal-fact space into K factors (e.g. predicate-type x subject-entity x object-entity) each with a far smaller per-factor codebook — well within N^2 capacity at the substrate's existing N=1024-16384 range. Bigger structural lift than Rank 1 (requires re-designing the causal-fact representation as a clean K-factor bound product); more novel-synthesis risk in THIS specific application even though the resonator machinery itself is substrate-validated elsewhere.

**Rank 3 — DG-style expansion + sparsify (a complementary lever, not a standalone rescue).**
Brain mapping: dentate gyrus expansion recoding (Marr 1971; Leutgeb et al 2007; Cayco-Gajic/Clopath/Silver 2017). Owned organ: `exp_resonator_dg_crosstalk_disentangler_v1.py`'s Check A/B/C (dimensional expansion `r*N` raises crosstalk SNR ~1/sqrt(N_eff); Check C's sparsify-viability test). Already validated to rescue the RESONATOR's K5/K6 crosstalk cliff specifically; extension to the FLAT `iterative_attractor` cleanup context (a different mechanism) is untested — this is a lever to LAYER under Rank 1 or Rank 2 if the coarse candidate pool itself is still too large for reliable fine-cleanup, not a first-line fix.

**Rank 4 — post-retrieval inhibition/competition among near-threshold candidates.**
Brain mapping: retrieval-induced forgetting (Anderson, Bjork & Bjork 1994) — actively suppress runner-up candidates after initial retrieval, sharpening the final decision. Owned organ: `hdlab/cleanup_family.py::peel_sic_readout` (successive-interference-cancellation / matching-pursuit deflation, CERT-validated to beat flat top-J at high bundle load: `exp_encoder_peel_sic_readout_realcodes_v1` commit 916e6f7cb). Useful REFINEMENT layered on top of Rank 1/2 when a query returns several near-threshold candidates and a single raw-cosine gate score is ambiguous — does not by itself reduce the fundamental EVT-driven false-positive growth (it operates AFTER a shortlist already exists), so it complements rather than substitutes for Rank 1.

### Quantitative grounding for the EVT diagnosis

- Classic Gaussian order-statistics: for M iid standard-normal draws, `E[max] ~ sqrt(2*ln M)` (Gumbel 1958, *Statistics of Extremes*; standard EVT). `sqrt(2*ln(1,240,000)) / sqrt(2*ln(29)) ~ 2.03` — a ~2x standardized-score inflation from Stage-1's M=29-per-probe distractor count to CSKG's ~1.24M edges, with no per-item change.
- Willshaw, Buneman & Longuet-Higgins 1969, *Nature* 222:960-962 — correlation-matrix-memory false-recall ("ghost" outputs) is a function of items-stored vs. matrix dimension, not items-stored alone.
- Hopfield 1982, *PNAS* 79 — capacity ~0.14N; past this load spurious mixture-state attractors proliferate abruptly (a capacity CLIFF, matching the K5/K6 resonator crater's own character).
- Tsodyks & Feigelman 1988, *Europhys Lett* 6:101-105 — explicit crosstalk-capacity law for sparse-activity networks, `alpha_c(p) ~ 1/(p*|ln p|)`; already the exact mechanism cited in `exp_resonator_dg_crosstalk_disentangler_v1.py`'s own docstring for the M^K vs N^2 wall — i.e. this drill's diagnosis and the in-flight resonator work are independently converging on the same underlying crosstalk-capacity mathematics from two different entry points.
- Thomas, Dasgupta & Rosing 2021, *JAIR* 72 — explicit VSA-specific statement: holding false-positive probability at delta requires dimension `d = O(s * ln(1/delta))` where s = number of superposed/candidate items — dimensionality must scale with (at least) the candidate-set size to hold a fixed false-positive rate, directly supporting "a fixed threshold calibrated at small M does not remain valid at large M."

## Substrate-product implications

1. **This is a wiring task, not a research gap, for the Rank-1 rescue.** `KGStore` is already CERT'd chain-grade and registered WIRED at `data/capability_registry.jsonl`; the fastest path to de-risking the CSKG-scale pull-in is composing it with `pull_in()`, not inventing new mechanism. This matches the standing discipline (route errors by flavor: "missing-LEARNING -> REUSE/EXPAND," and more generally "for every mechanism ask: does it share an already-developed process").
2. **The MCScript2 clustering failure and the anticipated Stage-2-B failure are DIFFERENT mechanisms wearing the same symptom (over-merge at scale).** Treating them as one problem risks applying the wrong fix (e.g. adding an expansion-recoding stage, Rank 3, when the actual driver is EVT cardinality inflation, Rank 1) or declaring a false victory (fixing EVT inflation while a genuinely weak signal elsewhere still needs expansion recoding). The cheap decisive test's null-sweep arm is designed specifically to keep these separated empirically rather than by assumption.
3. **Every rescue candidate maps to an already-owned organ.** No new mechanism class needs to be invented; the program is sequencing + wiring + one new calibration step (adapting `refuse_gate_calibrate()`'s in/out-of-set split to the pull-in admission task shape), consistent with "do the hard blocking thing" while staying inside "reuse before build."
4. **This closes the loop with the in-flight resonator crosstalk work.** `exp_resonator_dg_crosstalk_disentangler_v1.py` already contains the Tsodyks-Feigelman crosstalk math this drill arrived at independently via EVT/order-statistics — recommend the Stage-2 sub-test B design explicitly reuses that cell's oracle-unbind-margin methodology as the measurement instrument for Rank 2/3, rather than building a second parallel measurement harness.
