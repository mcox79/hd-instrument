# Research: real curriculum/prerequisite datasets to ground the synthetic ingestion-ORDER test

**Date:** 2026-07-16. **Filed by:** research (Sonnet lit-scan synthesis this cycle). **Trigger:** scoping drill — find the best real dataset of facts/concepts with a prescribed learning order (foundational -> advanced, prerequisite structure) to ground the ingestion-order ablation already designed in `research_developmental_trajectory_curriculum_order_2026-07-09.md` (Test (b), Arm BIO-ORDER/SCRAMBLED/GRAMMAR-FIRST) and extended by `research_developmental_curriculum_permissive_to_selective_gate_schedule_2026-07-16.md` (Prediction 1: curriculum order beats scrambled order at matched budget; schema-fit premature-rejection rate as a second outcome metric).

**Method:** 3 parallel Sonnet lit-scan sub-agents dispatched (concept-prerequisite-relation datasets; educational knowledge graphs/curricula/textbook orderings; knowledge-tracing datasets with skill dependencies), each doing live WebSearch+WebFetch against public dataset pages, GitHub repos, and papers. All three returned live-verified reports. Some sources were unverifiable live (TLS cert failures on moocdata.cn/aminer.cn hosting, dead links on some university pages) — flagged explicitly below rather than smoothed over, per calibration discipline.

---

## (a) HEADLINE

**No single public dataset ships BOTH a genuine, labeled prerequisite structure AND rich attached factual content in one obtainable package — every candidate trades off one against the other.** The clearest split: datasets built for prerequisite-relation-prediction research (LectureBank, AL-CPL, Khan/Junyi skill graphs) ship real order (pairwise judgments or an expert-labeled DAG) but bare concept/exercise LABELS with no attached facts; datasets built for textbook-QA or item-response research (TQA, Eedi) ship real attached content (actual textbook sentences, or question-image text) but only a linear chapter/topic sequence or a non-directional subject taxonomy, not a validated prerequisite DAG. **MOOCCube (Tsinghua, ACL 2020) is the one candidate that plausibly clears both bars at once** (manually-labeled prerequisite pairs over 114K+ concepts, each concept carrying a real Baidu-Baike/Wikipedia description, videos carrying real subtitle text) — but this rests partly on secondary/search-snippet corroboration since the primary hosting page (moocdata.cn / aminer.cn) returned a TLS certificate mismatch in live fetch and could not be directly confirmed this cycle. **Junyi Academy's exercise-relationship data is the single most solidly CONFIRMED real prerequisite graph found** (837 exercises, 1,131 expert/crowd-labeled prerequisite-vs-similarity-vs-difficulty pairs, freely downloadable, no application gate) but ships names/IDs only, no problem text. **TQA (Kembhavi et al., CVPR 2017, AI2) is the single most solidly CONFIRMED real-content dataset** (real CK-12 middle-school textbook sentences + diagrams per lesson, CC BY-SA 4.0, public AWS S3 bucket, zero access friction) with an implicit (not formally DAG-labeled) foundational-to-advanced order inherited from the textbook's own chapter/lesson sequence.

## (b) Cheap decisive test

Reuses the exact Test (b) design already specified in `research_developmental_trajectory_curriculum_order_2026-07-09.md` and the schedule/gate-signal instrumentation from `research_developmental_curriculum_permissive_to_selective_gate_schedule_2026-07-16.md` — only the DATA SOURCE changes, no new architecture:

- **Arm REAL-ORDER:** ingest TQA lesson content (real textbook sentences) in the CK-12 textbook's own chapter/lesson sequence (Life Science -> Earth Science -> Physical Science progression, or whichever single-subject strand is used, each internally ordered by its native chapter numbering).
- **Arm SCRAMBLED:** identical TQA lesson content, randomized ingest order, matched total data budget.
- **(Optional stretch arm) REAL-DAG:** ingest Junyi-exercise-name-keyed content (bridged — see gap below) in true prerequisite-DAG topological order, to test whether a validated DAG beats a merely-linear textbook sequence.

Measure at matched checkpoints: (i) foundation quality (the existing schema-fit / additive_map.score_all signals), (ii) schema-fit premature-rejection rate (the specific metric this drill was requested to rescue), (iii) final held-out accuracy on TQA's own QA task as an external sanity check that the ingested content is usable at all.

**HARD-PASS:** REAL-ORDER beats SCRAMBLED by >=10 points on (i) and/or reduces premature-rejection rate by >=10 percentage points, at matched data budget.
**HARD-FAIL:** REAL-ORDER and SCRAMBLED are statistically indistinguishable (within ~3 points) on both metrics — would indicate either (a) textbook chapter order is too weak a proxy for genuine prerequisite structure to move the needle, or (b) the schema-fit gate's premature-rejection problem is not actually order-sensitive on real (vs. synthetic) content, a materially different and more important negative than a synthetic-only null.

## (c) Falsifiable predictions (HARD-PASS / HARD-FAIL)

**Prediction 1 — TQA's real curriculum order (textbook chapter/lesson sequence) reproduces the synthetic-curriculum-order advantage already predicted in the 07-09 and 07-16 notes, on REAL content instead of synthetic.** This is the direct real-data replication of `research_developmental_trajectory_curriculum_order_2026-07-09.md` Prediction 1 (P=0.28 there) and `research_developmental_curriculum_permissive_to_selective_gate_schedule_2026-07-16.md` Prediction 1 (P=0.28, carried forward). **P estimate: P=0.30** (deflated per lit-scan calibration; capped 0.50; marginally above the synthetic-only estimate because real textbook content has genuine semantic dependency structure a careful synthetic corpus can only approximate, but deflated because textbook chapter order is a WEAKER signal than a validated prerequisite DAG — CK-12 lesson sequence is authored for pedagogical pacing/narrative flow, not a strictly validated dependency graph, so some fraction of "order" may be non-load-bearing narrative convention rather than genuine prerequisite structure).

**Prediction 2 — the schema-fit premature-rejection rate (the specific signal this drill was dispatched to rescue) drops measurably more on REAL-ORDER than on SCRAMBLED, specifically because TQA sentences reference genuinely prior-established terms (e.g. a "cellular respiration" lesson presupposes "cell" and "energy" vocabulary introduced in earlier CK-12 chapters) in a way synthetic curricula may not naturalistically reproduce.** HARD-PASS: premature-rejection rate (candidates correctly extending the foundation that get rejected for low apparent schema-fit merely because their prerequisite concepts haven't been ingested yet) is >=15 percentage points lower under REAL-ORDER than SCRAMBLED. HARD-FAIL: no measurable difference, or SCRAMBLED shows an equal or lower rejection rate (would mean the premature-rejection problem is not primarily an ordering artifact at all, at least not one real textbook sequencing fixes). **P estimate: P=0.32** (deflated; this is the most directly USER-relevant prediction for the stated goal — "rescue the schema-fit signal" — but is a step further from anything directly measured in the literature survey itself, which established dataset properties, not this specific mechanism).

**Prediction 3 — a genuine prerequisite DAG (Junyi-derived, bridged to content) outperforms a merely-linear textbook sequence (TQA) on the same two metrics, at matched data budget, isolating whether DAG-fidelity (branching/multiple-prerequisite structure) matters beyond simple linear ordering.** This requires the Junyi content-bridging step (see gap below) and is therefore a second-stage test, not the first cheap one. **P estimate: P=0.25** (deflated; depends on successfully executing a nontrivial content-bridging step that was NOT confirmed to exist off-the-shelf by any sub-agent this cycle).

## (e) Substrate-product implications

1. **Immediate, near-zero-friction pilot: TQA.** CC BY-SA 4.0, public AWS S3 bucket (`ai2-public-datasets`), no login/registration, real textbook sentences + diagrams per lesson, natural foundational-to-advanced CK-12 middle-school science sequence already built in via chapter/lesson numbering. This is directly substitutable into Test (b) above with no new architecture, replacing "synthetic candidate batches" with "real TQA lesson sentences in native order vs. scrambled" for the ORDER-only slice of the existing gate-schedule test design.
2. **Second-stage, higher-fidelity option: Junyi Academy prerequisite graph + a content-bridging step.** Junyi's 837-exercise, 1,131-pair expert/crowd-labeled prerequisite graph is the most rigorously validated real DAG surveyed and is freely downloadable (Kaggle, PSLC DataShop), but its exercise nodes are internal Khan-Academy-derived exercise NAMES, not problem text. Bridging options, none confirmed off-the-shelf: (i) match exercise names to still-existing Khan Academy exercise/hint text (friction: Khan Academy content licensing is typically CC BY-NC-SA — noncommercial only, a real constraint if any output touches a commercial product surface); (ii) match exercise/topic names to Wikipedia or OpenStax textbook sections covering the same topic (more license-permissive, more engineering effort, no existing name-to-source crosswalk was found this cycle); (iii) treat Junyi's graph purely as a STRUCTURE oracle (validate whether the substrate's own already-ingested content, once topically tagged, respects the SAME edge directions Junyi's human annotators assigned) rather than as a content source at all — cheapest bridging option, avoids the licensing question entirely, but tests structural-consistency rather than driving an actual ingestion-order experiment.
3. **MOOCCube is the highest-ceiling but highest-friction option** — worth a follow-up direct-access check (the primary hosting page could not be fetched live this cycle due to a TLS certificate mismatch; a follow-up should try the GitHub-listed Google Drive mirror directly rather than the aminer.cn/moocdata.cn primary host) before committing engineering time, since its content is also partly Chinese-language (Baidu Baike descriptions), a translation/mixed-corpus consideration for an English-centric substrate.
4. **Honest recommendation for THIS cycle's cheapest actionable step:** pilot Prediction 1/2 on TQA alone first (zero bridging cost, real content, real if implicit order) before investing in the Junyi content-bridge or the MOOCCube access-verification follow-up — this directly matches the "cheap decisive test before big new construction" house discipline.

## Honest gap (stated directly, per the drill's explicit request)

**Most candidates give concept/exercise ORDER but not attached FACTS, or the reverse — a real dataset shipping both simultaneously, confirmed and immediately obtainable, was NOT found this cycle.** The two live-confirmed extremes are TQA (real content, implicit linear order only, zero access friction) and Junyi (real validated DAG order, no content, zero access friction, but a real license/bridging question stands between it and content). MOOCCube is the one candidate that claims both properties simultaneously but rests on secondary corroboration only (live-fetch failure on its primary host); it should be treated as unconfirmed-but-promising, not relied upon, until an actual file is successfully pulled from a mirror. No sub-agent found any existing published research that has run an ingestion/training-order ablation experiment on ANY of these datasets specifically to test "does prerequisite/curriculum order beat scrambled order" — this specific experiment, on real data, appears to be a genuinely open gap in the literature, not something to look up a prior answer for.
