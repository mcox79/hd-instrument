# Drill: does the brain recognize events/predicates via POS, or via frame/argument-structure? (2026-08-05)

**Filed by:** research (Sonnet, orchestrator-dispatched exhaustive brain-foundational drill on a negative)
**Trigger:** event extractor recall 0.32 (F1 0.23) — misses events because POS tagger (hdlab/pos_tagger.py, an averaged structured perceptron, UPOS-only) mistags participials/non-finite verbs as nouns/adjectives, and downstream event extraction appears gated on a `VERB` tag.
**Method:** 2 parallel Sonnet lit-scan sub-agents (breadth) + this synthesis (depth). LIVE WebSearch/WebFetch against pubmed/PMC, arxiv, SEP, ScienceDirect, Springer. Per lit-scan-calibration-penalty: P estimates deflated 0.15-0.25, novel-synthesis capped at 0.50.

---

## HEADLINE

**The brain does NOT gate event/predicate recognition on part-of-speech.** Event-hood is computed from **argument/thematic-role structure (a frame)**, activated by the verb's (or nominalization's) lexical-semantic identity, largely independent of — and in several documented cases (agrammatism, alternating-transitivity fMRI) dissociable from — surface morphosyntactic category. Our POS-tag-gated pipeline is a **surface proxy for a frame/argument-based mechanism**, and this is very likely the direct cause of the recall gap: a mistagged participle (VERB->NOUN) silently fails a downstream `if tag == "VERB"` gate that the brain does not use. We already own the correct-shape mechanism (Component-3: `hdlab/thematic_role_labeler.VERB_FRAMES` + `hdlab/frame_induction.frame_primary_role`) but it is (per the pipeline reading) invoked only *after* POS confirms VERB — i.e., wired downstream of the surface proxy instead of replacing it as the primary event trigger.

## Cheap decisive test

1. Take the current recall-0.32 eval set. For every FN (missed event) where the POS tagger mistagged the predicate token as NOUN/ADJ/other, check whether `lemma_verb(token) in VERB_FRAMES` (Component-3's known-frame dict) or would trigger `frame_induction.is_oov` -> frame-primary bootstrap.
   - **HARD-PASS threshold:** if >=50% of POS-caused FNs have a token whose lemma IS a known-frame verb (i.e., frame lookup would have fired even though POS tagging failed) -> the fix is "trigger frame lookup independent of POS tag," cheap and immediately actionable. Predicted recall gain proportional to the FN-recovery fraction; target recall >= 0.55 (vs 0.32) on this same eval set with zero retraining of the tagger.
   - **HARD-FAIL threshold:** if <15% of POS-caused FNs have a lemma in `VERB_FRAMES` (i.e., the missed predicates are morphologically exotic — heavy nominalizations like "destruction," true deverbal nouns with no verb-frame entry) -> the fix is NOT "just skip the POS gate," and the gap is instead a **frame-induction coverage gap** (OOV nominalization handling), which routes to frame_induction's OOV bootstrap path (already partially built per Component-3b), not a quick rewire.
2. Secondary falsifier: rerun event extraction with the POS gate REPLACED by "attempt frame lookup on every content token (lemma match against VERB_FRAMES ∪ OOV-bootstrap), regardless of POS tag" and measure recall/precision on the same set.
   - **HARD-PASS:** recall improves by >=0.15 absolute with precision loss <0.05 absolute (frame lookup on non-predicate nouns should mostly fail cleanly since non-predicate nouns won't match a verb-frame lemma or won't pass the OOV verb-frame heuristic).
   - **HARD-FAIL:** precision collapses (>0.10 absolute drop) because frame lookup fires on genuine nouns that happen to share a lemma with a verb-frame entry (e.g., "the fear" vs "to fear") — in that case the fix needs an argument-structure sanity check (does the candidate token actually have a plausible AGENT/EXPERIENCER slot filled nearby?) layered on top of the lemma-frame lookup, not lemma-frame lookup alone.

## Falsifiable predictions

- **P1 (HARD-PASS if confirmed):** Majority of current FNs are known-verb lemmas mistagged by POS -> frame-gate reroute recovers them without new frame data. Deflated P = 0.42 (uncharted regime for this specific pipeline; no direct precedent measuring this exact recall breakdown).
- **P2 (HARD-FAIL if confirmed):** Majority of current FNs are novel/heavy nominalizations with no verb-frame entry (destruction, resentment, arrival as unanalyzed nouns) -> the fix is OOV frame-induction coverage (Component-3b), a bigger lift, not a quick regate. Deflated P = 0.33.
- **P3 (novel-synthesis, capped 0.50):** A frame-first (not POS-first) event trigger, reusing Component-3 exactly as it already exists, is the single most brain-faithful and lowest-engineering-cost fix, because it does not require improving the POS tagger's participial-morphology accuracy at all — it routes around the weak component instead of hardening it. Capped P = 0.50 (novel synthesis of the pipeline architecture change, not yet tested).
- **HARD-FAIL for P3 specifically:** if precision drops >0.10 absolute when the POS gate is removed (see decisive test #2 hard-fail), P3 is falsified as stated and needs the argument-structure sanity-check layer.

## Cross-thread synthesis with brain evidence

### 1. Argument-structure representation is a fronto-temporo-parietal network effect, dissociable from POS
[VERIFIED-this-pass, Shetreet et al., PMC2632636] Two-stage system: left inferior temporal/fusiform (BA37) tracks argument-count complexity at the lexical/isolated-verb level; left IFG (BA47) engages once syntactic integration is required. [VERIFIED-this-pass, PMC4485426] Alternating-transitivity verbs (break/open — multiple thematic-role frames for one surface form) recruit bilateral angular/supramarginal gyri (BA39/40) + posterior STG/MTG more than simple intransitives, plus bilateral BA8/9 for ambiguity management. These effects track **argument count and frame-alternation type**, not noun-vs-verb category. This is a direct existence proof that the brain has a dedicated argument-structure computation that is a different signal from POS classification — exactly the SHAPE of Component-3 (frame lookup keyed on lemma, producing role assignments), not the SHAPE of `hdlab/pos_tagger.py` (a sequence tagger over UPOS tags).

### 2. Verb-frame activation is immediate and precedes/independent of full parse — thematic-fit / expectation generation
[VERIFIED-this-pass, McRae et al. thematic-fit literature via secondary sources, aclanthology.org/W16-2518.pdf, springer 3758/BF03193221] On encountering a verb, comprehenders immediately activate expectations over typical role-fillers for each argument slot (agent="cop", patient="thief" for "arrest") — a **structured multi-slot template fires from the lexical item**, before the arguments themselves are even read. This is frame-driven prediction, matching Component-3's `VERB_FRAMES` dict lookup mechanism structurally (lemma -> frame -> expected roles), and is the opposite shape of "tag every token, then look at ones tagged VERB."

### 3. Event-hood is a logical/semantic property of argument structure (neo-Davidsonian), attaches independent of surface category
[VERIFIED-this-pass, SEP "The Logic of Action" plato.stanford.edu/entries/logic-action/; Landman event-semantics notes tau.ac.il/~landman; Carlson "Thematic Roles and the Individuation of Events"] Davidson (1967) / Parsons (1990) neo-Davidsonian semantics: a predicate denotes by existentially quantifying an event variable `e`, with thematic roles attached as separate predicates `Agent(e,x)`, `Theme(e,y)`. The SEP and Landman sources both note the event-variable move is now standardly extended across morphosyntactic categories — nominalizations and participles introduce event variables the same way finite verbs do. **This is the formal-semantics confirmation that our target representation (an event = a role-slot-bound bundle, exactly what `hdlab/event_bundle.py`'s `EventBundleCodec` already implements: `event_vec = quantize(sum_r bind(role_key[r], filler_vec[r]))`) is the right SHAPE.** The bug is upstream of the codec — in *deciding whether a token denotes an event at all*, which is being decided by POS instead of by "does this lemma have (or bootstrap to) a frame."

### 4. Situation models bundle events on goal/causal/protagonist dimensions, not morphological category
[VERIFIED-this-pass, Zwaan, Langston & Graesser 1995, Psychological Science 6(5):292-297] The event-indexing model: readers track situation-model continuity along five dimensions — time, space, protagonist, causality, intentionality/goal — updating on discontinuity in any dimension. This is a dimensional/frame-content representation, not POS-keyed. [TRAINED-ONLY, UNVERIFIED this pass] whether nominalization-triggered situation-model updates have been directly tested — plausible given the dimensional representation but not confirmed by a live-fetched source this cycle; flag for a future drill if it becomes decision-relevant.

### 5. Event recognition is predictive (event segmentation theory), not derived from a completed POS sequence
[VERIFIED-this-pass, Kurby & Zacks 2008; eLife 2025 "Multiple event segmentation mechanisms in the human brain," elifesciences.org/articles/107955] Event Segmentation Theory: the brain continuously generates top-down predictions of upcoming event structure via active event models; prediction error at failure points drives event-model updating at boundaries. Two complementary networks track prediction error and prediction uncertainty respectively, integrating top-down conceptual/schema knowledge with bottom-up cues. **Inference (hypothesis-pending-VET, my synthesis not a directly-tested claim):** because event recognition draws on frame-level/schema-level expectation rather than a single-token classification, a locally mistagged token would often still be recoverable from surrounding frame/argument context — the brain's mechanism is inherently more robust to a single-token surface error than a hard POS-gate pipeline stage is. This directly predicts that OUR recall failure mode (one bad POS tag -> total miss) is an architectural fragility that the brain's frame-predictive mechanism does not share.

### 6. Argument-structure access survives grammatical/POS-level impairment (agrammatism)
[VERIFIED-this-pass, Thompson & Lee 2009, PMC2824436, "Psych verb production and comprehension in agrammatic Broca's aphasia"] Agrammatic patients preserve lexical/argument-structure knowledge (correct argument count, thematic-role identity at the lemma level) even when syntactic mapping/movement (the POS/syntax-adjacent operations) is impaired — errors cluster in mapping arguments onto surface word order, not in knowing the verb's frame. This is a direct **double-dissociation-adjacent** finding: argument-structure/frame access is a separable process from grammatical(POS-level) processing, and can survive independently of it. This is the strongest single piece of evidence that gating event detection on POS accuracy is the wrong dependency direction — the brain's frame access does not depend on intact POS/syntactic tagging.

### 7. Construction/frame-level semantic integration is a distinct neural signature from lexical/POS-level processing
[VERIFIED-this-pass, ERP N400 study, pubmed.ncbi.nlm.nih.gov/17303093, sciencedirect S0006899307000819] Construction-based semantic violations produce a distinct (posterior, weaker) N400 compared to lexical-item-based semantic violations — real human ERP evidence for a dissociable constructional/frame-level integration process. [VERIFIED-this-pass but NOTE CAVEAT: arxiv.org/abs/2202.12246 "Neural reality of argument structure constructions" is an artificial-Transformer-LM study, NOT human-brain evidence — cited only as converging computational-linguistics support, not neuroscience] Transformer LMs cluster sentences by construction type over verb identity and show construction-level meaning survives Jabberwocky (nonsense-lexical-item) priming, structurally analogous to what frame_induction's OOV path already does (bootstrap a frame for an unseen lemma from context).

## Substrate-product implications

1. **Component involved:** the event extractor's predicate-detection GATE should be a frame-lookup (`lemma in VERB_FRAMES`, OR `frame_induction.is_oov` -> bootstrap-frame-attempt) fired on every content-bearing token, not a `pos_tag == VERB` conditional. This reuses Component-3 (`hdlab/thematic_role_labeler.py`, `hdlab/frame_induction.py`) exactly as it already exists — per the standing discipline "for every mechanism ask which brain structure + does it share an existing process," this is REUSE not new-build. `hdlab/event_bundle.py`'s `EventBundleCodec` (role-slot-bound event vector) is already the correct brain-faithful representation target (matches neo-Davidsonian event-variable + role-predicate structure) — it is downstream of the bug, not implicated.
2. **POS tagger's role should be demoted**, not eliminated: still useful as a feature/prior for the frame-primary decision (e.g., disambiguating true nouns from frame-bearing nominalizations when lemma is ambiguous), but should not be a hard gate that a miss silently kills.
3. **If P2 (OOV-nominalization gap) turns out dominant** (per the decisive test), the fix is not a pipeline rewire but expanding frame_induction's OOV-bootstrap path to cover deverbal-noun morphology (destruction/resentment/arrival-class), which is a natural extension of the already-in-flight Component-3b (OOV frame-induction, Gleitman-bootstrapping) work — same component, wider coverage, not a new build.
4. **Recommended next step (single most brain-faithful fix, confidence deflated):** rewire the event-trigger condition from POS-gated to frame-lookup-gated (reusing Component-3), run the cheap decisive test above on the existing recall-0.32 eval set before any new build. Confidence in "this alone recovers most of the recall gap": **P=0.42 (deflated)**, contingent on FN composition (test #1) — if OOV-nominalization-dominated instead, confidence in "rewire alone suffices" drops to **P=0.20 (deflated)** and the real fix becomes frame_induction OOV coverage expansion.

## Verdict

(a) **YES** — POS-tag-based event detection is the wrong SHAPE. Verified brain evidence (argument-structure fMRI dissociable from POS, thematic-fit immediate frame activation, neo-Davidsonian event-variable semantics extending across morphosyntactic category, agrammatism dissociation, event-segmentation predictive coding, construction-level ERP dissociation) converges on: event/predicate recognition is **frame/argument-structure-based**, with POS/morphology as at most a weak prior, never a hard gate.

(b) The recall fix should be a **frame/argument-based event recognizer reusing Component-3** (`VERB_FRAMES` lemma lookup + `frame_induction.frame_primary_role`/OOV bootstrap), triggered independent of the POS tag — NOT a better tagger. A better tagger treats the symptom (participial mistagging); a frame-first gate treats the cause (wrong dependency direction: event-detection should not depend on POS-tagging succeeding first, matching the agrammatism dissociation finding directly). Predictive-parsing/event-segmentation-style robustness (recovering from local surface errors via schema-level expectation) is a secondary, longer-lead enhancement, not the first fix.

(c) **Single most brain-faithful fix:** replace the POS-VERB gate with a Component-3 frame-lookup gate (lemma-in-VERB_FRAMES or OOV-bootstrap-attempt) as the event trigger, keeping POS as a soft disambiguation feature only. **Confidence: P=0.42 (deflated, contingent on decisive-test FN composition; ceiling 0.50 per novel-synthesis cap).**
