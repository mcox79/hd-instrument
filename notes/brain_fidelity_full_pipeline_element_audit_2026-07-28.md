## TOP-5 PRIORITIZED — biggest brain-fidelity gaps, cheapest brain-faithful fix each

1. **Encoder objective (MLM cloze vs hierarchical predictive-coding).** Severity 5, THE named ceiling, IN FLIGHT tonight (breadth pull + R3/R4 relational self-teacher). Cheapest incremental lever: add an explicit forward/next-token prediction loss term now, before the breadth run finishes, so breadth data trains against a more brain-faithful (directional) objective from the start.

2. **Readout + binding-key scheme (order-blind mean-pool → wrong-invariant absolute-position bind → confounded role-slot head).** Severity 5, IN FLIGHT but genuinely stuck — three iterations (v4/v5/v6) without a clean answer, and the blocker is a broken EVAL not a broken mechanism. Cheapest lever: redesign the v6 eval task (multi-role-swap disambiguation between two known concepts) so concept-identity alone cannot solve it, THEN re-judge v6's role-slot head before any further architecture change.

3. **Multi-timescale context / working-memory hierarchy.** Severity 4, UNTOUCHED. Cheapest lever: wire the already-built fast_episodic DG-analog store as a persistent cross-window memory feeding back INTO the encoder (Transformer-XL-style), reusing existing infra instead of building a new mechanism class.

4. **Consolidation (flat averaging vs schema-gated SWR replay).** Severity 4, self-flagged as under-developed, a DEEP SIBLING DRILL IS RUNNING ON THIS TONIGHT — kept in the top tier so it isn't lost, but detail deferred to that drill.

5. **Eval metric (compressed relational-AUC; cloze fell into the Peng-2020 identity-memorization trap).** Severity 3 but GATING all of the above — if the metric can't separate comprehension from memorization, none of rows 1-3's fixes can be credited even if they work. Cheapest lever: identity-ablate the B0 baseline (strip concept-identity signal, force role/relation-only prediction) as the precondition for validating everything else.

**Honorable mentions (real gaps, lower urgency):** memory-store CA3-completion is entirely absent (row 7, cheap diagnostic = DG hyperparameter sweep against the pattern-sep-ratio target); grounding is a late-fusion bolt-on rather than a constitutive training signal (row 6, medium-cost auxiliary loss, highest leverage AFTER row 1 lands). Reasoning (row 10) is a confirmation that the plan already correctly triaged reasoning-mechanism work away in favor of upstream representation fixes — not a fresh gap.

**What's UNTOUCHED vs IN-FLIGHT tonight, explicitly:**
- IN FLIGHT: encoder objective (#1, breadth+relational-self-teacher), readout/binding-key (#2, v5/v6), consolidation (#4, sibling drill), eval metric (#5, v6 cloze — but broken).
- UNTOUCHED: context/multi-timescale (#3), memory-store CA3-completion (row 7), grounding-as-training-signal (row 6), tokenization (row 1, low priority), retrieval-under-degraded-cues (row 9, low priority).
