## 1. THE PROBLEM IN PLAIN LANGUAGE

When you read a story you feel WITH the characters even when the text never says how they feel. If a girl has been trying all week to win the race and she wins, you know she is thrilled -- the story never had to write "she was happy". If a man is desperate to catch the last train and the doors close as he arrives, you know he is crushed. If someone dreads a phone call and it comes, you know the feeling is fear. We infer the unstated emotion by comparing what HAPPENED against what the character WANTED: goal met -> good feeling, goal blocked -> bad feeling, a dreaded thing arriving -> fear. That comparison is a core part of following a story -- it is how we sympathise, how we sense a turning point, how we understand why a character then acts the way they do.

Our reader already reads the emotions the text states outright ("she was afraid", "he felt joy") and ties each to the right character. It also already tracks what each character is trying to achieve, and whether each of those goals ends up met or blocked. But it never puts the two together to work out the feeling the text leaves UNSAID. Build that step -- read a character's likely emotion off an event weighed against that character's goals -- and prove, on modern test stories, that it names the right unstated feeling (at least positive vs negative, and ideally the specific kind: satisfaction / disappointment / fear) where a reader who just guessed the most common emotion, or read the last emotion word, would get it wrong.

## 3. HOW THE BRAIN DOES THIS (the opening move -- PINNED vs OUR-INVENTION)

- **PINNED -- emotion is APPRAISAL of an event with respect to the agent's GOALS (the OCC model; Ortony, Clore & Collins 1988).** The valence AND type of an emotion are computed structurally: an event desirable for the agent's goals -> joy/satisfaction, undesirable -> distress/disappointment; the PROSPECT branch (a not-yet-actual desirable/undesirable event) gives hope/fear, and its CONFIRMATION/DISCONFIRMATION gives satisfaction/fears-confirmed vs relief/disappointment; agency + deservingness give the SOCIAL emotions (anger/gratitude/pity, another's undeserved gain -> resentment). The load-bearing move is that the OCC TYPE is a decision over three structural variables -- (a) desirability of the event for the agent's goal, (b) prospect: is the event actual or still prospective, and did it confirm/disconfirm an expectation, (c) agency/deservingness for social types -- NOT a lexical lookup on an emotion word.
- **PINNED -- Scherer's component-process appraisal (goal-conduciveness, novelty, agency, coping) converges** on the same primitives: the FIRST and most load-bearing appraisal check a reader runs is goal-conduciveness (does this help or thwart what the agent wants). Start there; the other checks (novelty, agency) are refinements the gold may or may not demand.
- **PINNED (neural) -- appraisal is a valuation-over-goals computation in vmPFC/OFC (goal value; Rangel/Padoa-Schioppa) bound with amygdala appraisal (Phelps), and Barrett's constructed-emotion account: an emotion is core affect (valence + arousal) CONSTRUCTED with conceptual/situational knowledge into a specific category.** This maps cleanly onto our substrate: core affect = the valence the affect register already carries; the "conceptual/situational knowledge" that turns valence into satisfaction-vs-relief is exactly the goal STATUS + prospect the goal register + causal network already track. So the appraisal system is a DISTINCT dimension (Campanella et al. 2022 triple dissociation, already PINNED for the affect register), and this problem builds the computation that CONSUMES the goal/causal representation to produce it.
- **THE MECHANISM TO BUILD (the composition):** a transparent forward appraisal rule. For a character A and a recent event E (from the reader's event stream / causal network) that bears on one of A's active goals G (`sm.wants(A)` / `sm.goal_register`, with `g.status` in {active, satisfied, failed}), compute:
  (1) DESIRABILITY = does E advance or thwart G (goal satisfied/enabled -> +, goal failed/blocked -> -); the causal network (`sm.causal_links`) says which event caused the goal outcome.
  (2) PROSPECT = was G/E prospective (a hoped-for or FEARED future event) vs actual, and did the outcome confirm or disconfirm it -- this is what separates satisfaction (actual good) from relief (feared bad that did not happen) and disappointment (hoped good that failed) from fears-confirmed.
  (3) The inferred emotion = valence from (1) + OCC TYPE from (1)x(2) [+ agency/deservingness from the causal network's agent for the social types, if the gold demands them]. Output where the affect register found NO stated emotion for A -- i.e. the appraisal FILLS the gap, it does not overwrite a stated feeling.
  Keep the rule glass-box and hand-auditable (a named table over goal-status x prospect -> OCC type), NOT a learned model.
- **OUR-INVENTION-UNDER-TEST (sweep, do NOT adopt as truth):** which event "bears on" a goal (goal-head/object match vs causal-link match vs meaning-hub relatedness via `hdlab/bridging_inference.py`), how prospect is detected on real prose (future/modal marking, a feared-event cue, the goal register's own negation/thwart signal), the granularity of the OCC type set actually scored (valence-only vs a small type set satisfaction/disappointment/fear/anger), tie-breaking when A holds multiple active goals a single event bears on, and whether desirability is a hard sign or a graded value. These are parameters/architecture choices -- sweep them, name each PINNED-vs-INVENTED.
