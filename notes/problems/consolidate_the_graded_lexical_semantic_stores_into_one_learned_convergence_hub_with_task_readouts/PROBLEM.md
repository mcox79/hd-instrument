## 1. THE PROBLEM IN PLAIN LANGUAGE
The system keeps six different "what does this word mean" tables, each built a different way and used by a different part of the reader. When one of them gets smarter (for example, the one that grows by reading), the others do not. The brain keeps ONE shared meaning store that every task reads, built by letting all the senses and language feed into the same place. This problem builds that one shared store from the six tables, checks with a strict pre-registered test that it is at least as good as the best of them on every job, and then makes every part of the reader use it.

## 2. WHY THIS ONE — the deep root, under the HARD 100%-BF gate
The owner's concern is exactly this: islanded copies of one brain structure with varying capability. Semantic memory is the most-copied structure in the substrate (≥6 graded representations, 2 of them islands with zero importers), and the research now pins that the brain has one hub read by every task, built by convergence, not by a hand-set fusion rule. Today's landed fusion is measured net-positive but its integration rule is an imported analogy (OPEN); this problem is the brain-exact version that can settle it — and it is the consolidation audit's action #2.

## 3. MEASURED vs INFERRED
- **MEASURED (on disk):** ≥6 graded representations (see the 2026-09-11 §2b RESEARCH FOLD entry for the list + importers); `meaning_fusion` and `composed_hub_predictor` have 0 importers; linear one-pool SVD latent 0.715 vs separate-pool fusion 0.723 on MEN (pri-5 W40, not a hub win); the landed `FusedSenseRanker` scores 0.382 vs grounded-only 0.159 vs incumbent 0.027 on the live coverage-quality instrument (n=247); grown SEQ adds +0.20 over grounded.
- **INFERRED (to prove or refute WITH A NUMBER):** that a NON-LINEAR learned convergence hub over the spokes beats each store on its own task and ties/beats the precision fusion on the live instrument. Do NOT assume it — the linear version did not; the decision is the pre-registered test.
