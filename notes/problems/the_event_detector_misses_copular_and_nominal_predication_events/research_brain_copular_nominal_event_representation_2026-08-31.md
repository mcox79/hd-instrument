## Q1 — COPULAR / STATIVE PREDICATION: neural + representational

### Q1a — Same predicate-argument machinery as a dynamic verbal event, or property-attribution?
**VERDICT: SPECULATIVE-INFERRED (converging) — a copular state is best modelled as PROPERTY-ATTRIBUTION (holder + property + time), NOT agent/patient event role-binding.**

- **PINNED (verbal-event side):** who-did-what-to-whom for *dynamic verbal events* is carried by agent/patient role-binding in left mid-superior temporal cortex (lmSTC); medial subregion ≈ agent/stimulus, lateral ≈ patient/experiencer (Frankland & Greene 2015, PNAS; Frankland & Greene 2020 "Two Ways to Build a Thought", Cerebral Cortex — the 2020 paper contrasts **narrow verb-specific vs broad verb-invariant roles**, both *relational*; amPFC/BA10 for narrow conjunctions, lmSTC for broad agent/patient).
- **PINNED (property-composition side):** basic property+entity composition (adjective–noun, "red boat") recruits **left anterior temporal lobe (LATL)** with an early (~200–250 ms) amplitude increase when composition is semantically "simple", plus left angular gyrus / vmPFC (Bemis & Pylkkänen 2011 J Neurosci; 2013). This is a *conjunctive property-attribution* format, distinct from the *relational* agent/patient buffer.
- **GAP / honesty flag:** I found **no study that directly contrasts copular predication ("X is cold / is a doctor") against a transitive verbal event isolating whether lmSTC's agent/patient role-binding fires.** The 2020 "Two Ways" paper does NOT license a conjunctive-vs-relational claim (both its formats are relational). So mapping copular predication onto property-attribution rather than event-role-binding is an INFERENCE, not a measured contrast.
- **Why the inference is well-motivated:** it converges with the semantics (Q1b): a Kimian state = "exemplification of property P of holder x at time t" — a property-of-entity structure with **no agent/patient event participants**. Property-attribution (LATL basic composition) is the computational match; the full lmSTC agent/patient buffer is the wrong shape (a stative predication has no patient/theme being acted upon).
- **Implication for detector:** a copular/stative detection is a **(holder, property, time) attribution node**, not a two-participant event with agent/patient roles. Do NOT try to fill agent/patient slots for "is cold". Fill (entity, predicated-property/type).

### Q1b — Is a copular STATE the same node kind as an EVENT, or a distinct representational type?
**VERDICT: PINNED — a copular state is an ONTOLOGICALLY DISTINCT sort from a dynamic event (a sister under "eventuality", not a degenerate event). Route/tag it as a first-class STATE sort, not merely an event node with a stative flag.**

- **PINNED (semantics):** Maienborn (2005 *Theoretical Linguistics*; 2007/2011 "On Davidsonian and Kimian States") — copula+predicate and stative verbs (know, weigh, own) denote **Kimian states**: abstract objects (property exemplifications), **no Davidsonian event variable**, inaccessible to direct perception, excluded as bare infinitival complements of perception verbs ("*I saw Sarah be a doctor"). This is a "fundamental typological chasm" from Davidsonian eventualities. Kimian states are also distinct from Davidsonian states (sit/stand/sleep, which DO have an event variable).
- **PINNED (situation-model / eventuality typology):** Bach 1986 (inherited) — states are a distinct subtype of eventuality (states vs processes vs events). Event-Indexing Model (Zwaan & Radvansky 1998; Zwaan 2016 event-horizon; From Words to Worlds, Zwaan 2025) — the situation model indexes **events** across 5 dimensions (time, space, entity, causation, intention); entity **properties/states** are tracked as part of the *entity* dimension and form the **background** against which bounded events are foregrounded and segmented. A static property is not itself an event-segment.
- **Implication for detector:** fire on the predicate (recover the state), but emit it as a **STATE-sort node** (Kimian: holder + property + time-interval), distinct from a Davidsonian event node. "Event node tagged stative" is acceptable **only if the sort tag is load-bearing** (routes differently downstream: states are background/entity-attribute, events are foregrounded/segmentable). A shared eventuality buffer with a real state-vs-event sort feature is the brain-faithful design; a degenerate "event with stative=true" that is treated identically to events downstream is NOT.

### Q1c — Is the copula (be/seem/become) processed as a functional element separably from predicate content?
**VERDICT: PINNED — YES. The copula is a functional/grammatical carrier dissociable from predicate content; key the detector on the PREDICATE, not the copula token.**

- **PINNED (aphasia dissociation):** In non-fluent/Broca's (agrammatic) aphasia, copula omission is **selective and grammatically conditioned** — confined to aspectual / stage-level predicates; "the grammatical property of aspect is a much stronger predictor of copula omission than predicate length or utterance length" (Glossa 2023, "'To be' or not 'to be'"; replicating Becker 2002 for child English; Brunetto et al. 2023). The functional copula can drop while the predicate content survives → dissociation.
- **PINNED (lesion double dissociation):** agrammatism (functional/syntactic deficit) follows **inferior frontal** damage; paragrammatism follows **posterior temporal** damage (Matchin & Hickok; *Neurobiology of Language* 2020, MIT Press, lesion-symptom mapping). Supports a grammatical/functional route (LIFG) separable from lexical-semantic content retrieval (posterior temporal / ATL / pMTG).
- **Implication for detector:** the copula (be/seem/become) is a functional element that carries tense/agreement and can even be OMITTED; **it is not where the state lives.** Detect the state by targeting the **predicate complement** (AdjP / predicative NP / PP) that the copula links to the subject. Fire-on-predicate, treat the copula only as a *cue that a predication frame is present*. This also generalizes past copula-drop and non-be copulas (seem/become/remain).

## Q2 — NOMINAL EVENT SENSE DISAMBIGUATION (the precision wall)

### Q2a — What drives event-vs-result sense selection, and in what time-course?
**VERDICT: PINNED — a COMBINATION: bottom-up local argument-structure (default) + top-down discourse/selectional context (coercion), resolved INCREMENTALLY online. Not frequency alone.**

- **PINNED (bottom-up argument structure):** complex-event (event-reading) nominals obligatorily take internal arguments; the **of-argument + by-phrase + aspectual modifiers ("frequent/constant/deliberate")** are Grimshaw's (1990) diagnostics; result nominals do not select arguments (Grimshaw 1990; Sleeman & Brito; Melloni 2011). This is a **local, syntactic, bottom-up** signal available without full discourse.
- **PINNED (top-down context / selectional restrictions):** the event/result reading is also imposed by the **governing predicate and adjectival modifiers** in context — sortal readings are "triggered by selectional restrictions of adjectival modifiers and governing predicates" and "the ambiguity ... may be simply due to the overall discourse context, rather than to an inherent [lexical] ambiguity" (Brandtner & von Heusinger 2010, "Nominalization in Context — Conflicting Readings and Predicate Transfer"; Grimm & McNally "No ordered arguments needed for nouns").
- **PINNED (time-course / online coercion):** type-shifting an entity to an event is an **online, cost-bearing composition operation**: complement coercion "the author began the book" elicits the Anterior Midline Field ~400 ms (Pylkkänen & McElree 2007; Pylkkänen et al. 2008); aspectual coercion (telic/atelic mismatch) elicits ~340–380 ms right frontal/anterior-temporal + ~440–460 ms anterior-midline effects and slower reading (Brennan & Pylkkänen 2008). The predicate context can **coerce** the eventive reading in real time.
- **Implication for detector:** don't rely on a single cue. Add **local argument-structure diagnostics** (of-PP complement, by-phrase, "frequent/constant" modifiers, singular-mass vs count/plural) as bottom-up features NOW; the residual is resolved by the governing predicate / running situation model (top-down coercion) — which the context-free detector cannot see.

### Q2b — Is the event reading intrinsically underdetermined without discourse context?
**VERDICT: PINNED-PARTIAL — YES for the genuinely polysemous/bare cases (intrinsic fidelity gap requiring the running situation model), but NO for the subset carrying LOCAL syntactic argument-structure cues (recoverable now without a full parser).**

- **PINNED (underdetermination):** many deverbal nominals are **underspecified** context-free; the reading is "imposed by different elements in the same context," and the ambiguity is context-driven rather than an inherent lexical split (Brandtner & von Heusinger 2010; Grimm & McNally). Processing evidence: readers maintain an **underspecified** representation and commit only when context forces it (underspecification accounts — Frazier; Frisson & Pickering; "Underspecification and Aspectual Coercion"). The brain does NOT eagerly resolve the reading from the lexeme alone.
- **PINNED (partial local recoverability):** Grimshaw's obligatory-argument complex-event nominals ("the destruction **of the city** **by the army** **in 1204**"), gerundive -ing nominals, and aspectual/frequency modifiers ARE disambiguated by **local syntax** without full discourse.
- **Implication for detector (this is the strategic verdict):** the precision wall is **BOTH a lexicon-sharpening opportunity AND a genuine fidelity gap.**
  1. NOW (no parser): sharpen by adding **local argument-structure diagnostics** (of-PP, by-phrase, event-modifier adjectives, determiner/number blocking) — recovers the syntactically-marked event fraction and should raise precision on the diagnosable cases.
  2. RESIDUAL (bare "the destruction was total" vs "the destruction happened"): **intrinsically context-bound** — a context-free detector CANNOT match the brain here, because the brain itself defers to the governing predicate / incremental situation model (predicate-transfer / coercion). Crossing this residual requires wiring the detector to the **running situation model / incremental predictive context** (the governing predicate's selectional type), not a bigger lexicon. This is a real fidelity gap to BUILD across, not an impl bug.

### Q2c — Is aspect/boundedness the feature that makes a nominal a situation-model EVENT?
**VERDICT: PINNED — YES. Boundedness / telicity (a bounded, temporally-locatable realis occurrence) is the discriminating event-hood feature; it connects directly to the transitivity/foregrounding signal already in use.**

- **PINNED (aspect drives segmentation):** grammatical aspect / boundedness governs narrative **event segmentation** — bounded/perfective descriptions trigger a segment boundary (a discrete event), imperfective/unbounded do not ("Aspect and Narrative Event Segmentation", Collabra: Psychology 2019; Event-Indexing / event-horizon, Zwaan). A bounded occurrence = a segmentable situation-model event; an unbounded state = background.
- **PINNED (transitivity / foregrounding):** Hopper & Thompson 1980 ("Transitivity in Grammar and Discourse", *Language* 56:251–299) — high transitivity is a cluster whose parameters include **telic (bounded) aspect, punctuality, realis mode, individuation of the object**; high-transitivity clauses are **foregrounded** (the sequential, individuated events that carry the narrative). Low-transitivity / atelic / irrealis / generic clauses are backgrounded.
- **Discriminates the failure cases:** dispositional/abstract nouns (habit, care, attention) and result readings denote **unbounded generic states / objects** → NOT situation-model events. A bounded realis deverbal occurrence ("the explosion", "the destruction [that happened]") IS one.
- **Implication for detector:** add a **boundedness/realis feature** as the event-hood gate for nominals — does the nominal denote a bounded, temporally-locatable occurrence (event) vs an unbounded generic/dispositional state (not an event)? Reuse the existing Hopper–Thompson transitivity/foreground signal: high-transitivity/telic/individuated context → fire as event; generic/dispositional/atelic → suppress. This is the same lever already used elsewhere, applied to nominal event-hood.

## TLDR (plain English)
- **"Sarah is a doctor / the room was cold" is a STATE, not an action.** The brain treats a described state as a fundamentally different kind of thing from a happening — a property pinned to a person/thing at a time, sitting in the background — not as an action with a doer and a done-to. So our detector should record it, but stamp it as a "state," and fill in *what is true of whom*, not *who did what to whom*.
- **The little word "is/seems/becomes" is not where the meaning lives** — brain-damage evidence shows people drop "is" while keeping the description, and that dropping is driven by the grammar of what follows. So we should look at the *description* ("a doctor", "cold"), not the linking word, and this also handles cases where "is" is left out.
- **The hard case — words like "the destruction" that can mean either the happening or its aftermath — is genuinely undecidable from the word alone.** The brain waits for the surrounding sentence to decide. So part of our accuracy problem we CAN fix now with local grammar clues (e.g. "destruction *of the city by the army*" = the event reading), but a stubborn remainder can only be fixed by hooking the detector up to the running story context. That remainder is a real capability gap to build across, not a bug.
- **The clean signal for "is this noun a real event?" is boundedness** — did something bounded actually occur (an explosion) versus a vague ongoing tendency (a habit, care)? That is the same "foregrounding" signal we already use, reused here.
