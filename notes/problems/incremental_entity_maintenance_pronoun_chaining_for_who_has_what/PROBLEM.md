## 1. THE PROBLEM IN PLAIN LANGUAGE
As you read a story you keep track of who currently has what. Our tracker was just taught to follow "he" and "she" to the right person, which helped. But a careful breakdown showed where it is still stuck: the hard part is not deciding, for one "she," which woman it means — the tracker is already almost as good at that single decision as it can be. The hard part is keeping a steady, growing memory of a character across a long run of pronouns ("she... she... her..."), so that later mentions still point back to the same person. A character becomes easy to find precisely BECAUSE many of her mentions have piled up and reinforced her in memory; when that memory is not maintained, the trail goes cold. This is how the brain does it — it holds a running, self-reinforcing representation of each discourse entity in working memory, and each new mention it resolves feeds back to keep that entity active. So the job is to build that running memory: chain each resolved pronoun into a persistent, accumulating entity history, and show it lifts "who has what" — with the improvement coming from the maintained memory, not from a better single-decision.

## 3. HOW THE BRAIN DOES THIS (the opening move)
PINNED: comprehension maintains INCREMENTAL discourse-entity representations in working memory — a running model of the entities under discussion, updated mention-by-mention (Centering theory, Grosz-Joshi-Weinstein 1995; discourse entities / structure-building, Gernsbacher 1990). An entity's retrievability grows with its accrued mentions (ACT-R base-level activation, Anderson; the retrieval-cue model of Lewis & Vasishth 2005). The re-instatement of an entity from a partial cue (a bare pronoun) is pattern COMPLETION — a recurrent attractor settling to the stored entity (Hopfield attractor dynamics; CA3 hippocampal pattern completion, which THIS substrate already models). The chaining is RECURRENT: each resolution feeds the next mention's salience, so the process is a loop, not a feed-forward pick — which is precisely why single-pick optimization plateaus.
