## 1. THE PROBLEM IN PLAIN LANGUAGE
When a person reads "no one left the room", they do not come away believing someone left -- they represent that the leaving did NOT happen. When they read "she didn't take the key", they hold that the key was NOT taken; when they read "everyone but Mary agreed" or "none of the guards moved", they represent WHO and HOW MANY the statement covers. These little words -- not, no, never, none, some, all, each, every, "everyone but" -- do not add a fact; they change whether the fact is TRUE and over WHOM it ranges. Our reader ignores them. It reads "she didn't take the key" and files "she took the key" as a thing that happened; it reads "no one left" and files "someone left". So when a question later asks "did she take the key?" or "who agreed?", the reader answers from a record whose truth value is simply wrong. This is a case humans find EASY and machines find HARD, and it quietly poisons the facts the whole story-model is built on. Build the step that carries polarity and quantity through to the stored fact: mark a negated proposition as NOT holding, and scope a quantified one over the right set and count -- so that a later question is answered against what the text actually asserted.

## 2. WHY THIS ONE
Every downstream organ -- coref, who-did-what, the state register, the goal register, the causal network, the QA capstone -- consumes the reader's extracted propositions as GROUND TRUTH. If the truth value of a proposition is flipped at extraction, every inference over it inherits the error, silently. The reader ALREADY carries propositional polarity for one narrow construction (copular STATE predication -- "X is / is not ill" -- via the live `state_register`, `qa_state` dim 0.712 CI-sep), which proves the primitive is buildable and useful; what is missing is (a) polarity on EVENT / action propositions ("she didn't take the key", "no one left") and (b) quantifier SCOPE / cardinality over argument sets ("none / all / each / everyone but X"). This is the correctness complement of the whole situation-model program: the program spent its length making the reader NOTICE facts; this makes the facts it notices TRUE. It REUSES the state register's polarity + antonym/contradiction machinery, the extracted event stream, and the coref-resolved argument set, and ATTACHES an operator -- it does not re-extract, re-type, or re-parse anything.

## 3. HOW THE BRAIN DOES THIS (frame -- PINNED vs OUR-INVENTION)
- **PINNED (the computation) -- a reader represents the ACTUAL state of affairs, including what is NOT the case and HOW MANY (Johnson-Laird mental models; Johnson-Laird & Byrne 1991).** A mental model encodes the situation the text asserts; negation is represented by holding the negated state as NOT obtaining (not by omitting it), and a quantified assertion is represented by the CARDINALITY of individuals/tokens in the model ("some" = at least one token, "all/every/each" = every token of the set, "none/no" = zero tokens, "everyone but X" = every token except the X token). Salience of the actual vs the negated state is a representational fact, not a lexical one.
- **PINNED (the process) -- negation-as-simulation is a TWO-STEP (Kaup & Zwaan 2005; Kaup, Ludtke & Zwaan 2006).** The reader first transiently represents the to-be-negated state (the key BEING taken), then represents the ACTUAL state (the key NOT taken); comprehension ends on the actual state. A polarity-blind extractor performs only the FIRST step -- it captures the embedded positive content and never applies the operator, which is EXACTLY the bug this problem targets. Converging neuroscience: negating an action sentence SUPPRESSES / reduces activation of the negated content (Tettamanti et al. 2008; Tomasino et al. 2010) -- negation is an inhibitory operation OVER a represented proposition, not a separate lexeme; logical/scopal composition recruits left inferior frontal cortex.
- **OUR-INVENTION-UNDER-TEST (sweep, do NOT adopt):** the cue -> operator mapping (the `neg` dependency; not / n't / no / never / none / nobody / no-one / nothing / without / fail-to / refuse-to / deny / hardly; morphological un- / in- / non- -- note `state_register.incompatible` already handles morphological negation, REUSE it), the SCOPE resolution (what the negation ranges over -- the predicate, an argument, or the whole clause), the quantifier -> cardinality table and its scope over the coref-resolved argument set, tie-breaking when multiple operators co-occur, and the abstain threshold. COPY the computation (represent polarity + cardinality of the ACTUAL state); SWEEP these parameters; LABEL the operator<->representation composition OUR-SYNTHESIS.
- **NOT brain-faithful:** a learned NLI / entailment black box that outputs a label without a glass-box polarity/cardinality representation; an external LLM at inference; naive "not"-spotting with NO scope (flip the clause whenever "not" appears) -- that is a strawman arm, not the operator, and it fails on "not only", "no matter", double negation; treating the copular state register as if it already covered event/action negation (it does not).
