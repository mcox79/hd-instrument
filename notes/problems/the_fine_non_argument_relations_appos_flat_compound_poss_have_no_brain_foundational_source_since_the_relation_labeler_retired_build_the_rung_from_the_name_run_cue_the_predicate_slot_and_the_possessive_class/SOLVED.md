## 2. WHAT WAS BUILT -- the brain's mechanism, per relation, and why it is an ARM and not a new organ

None of these four relations needs a classifier, and none of them is a new computation for this substrate.

* **A NAME RUN ("Mary Smith") is not a relation at all.** It is ONE referring expression stored and retrieved
  as a unit -- Kripke 1980 rigid designation; Semenza 2006/2009 proper-name anomia localises multi-word proper
  names to the LEFT TEMPORAL POLE, a level ABOVE and fed by the category level. The UD `flat` arc is the
  residue of that chunking. Our organ for it is pri 118's span-level NAME-RUN cue
  (`hdlab.coref.span_caps_symbol`, learned online from the reader's own confident typings).
* **An APPOSITION ("Elizabeth, the doctor") is a REDUCED PREDICATION** -- the same construction as "Elizabeth
  is the doctor" with the copula absent (Pustet 2003 on copula optionality; Maienborn 2005 Kimian states;
  Bemis & Pylkkanen 2011 LATL property attribution). The organ that detects a predication is pri 110/117's
  PREDICATE SLOT. The comma is surface: pri 129 counted the gold and only 24 of 105 appositions carry one.
* **A POSSESSIVE ("her brother", "Mary's dog") is CASE MARKING** -- the Competition Model's strongest
  morphological cue (Bates & MacWhinney 1989; MacWhinney 1987). English marks it overtly and this organ has
  read it since pri 108's cue set v4 (`genitive_value`: `gen_pron` / `gen_clitic`).
* **A COPULA is the TENSE CARRIER of a non-verbal predication** -- the reason English inserts it (Pustet 2003;
  Bybee 1994 auxiliation), already stated by pri 113. `attachment_arm.cop_complement` says which token it
  carries tense FOR, with no labeler.
* **The CONVENTION LAYER (det / case / cc / mark / amod / nummod / punct / aux) is not a computation the brain
  performs.** It is the distributional residue of the category rung, so it is learned as counts like the rest.

Every one of those is a CONSTRUCTION -- a form/GOVERNOR pairing recognised by CUES whose VALIDITY is accrued
from usage (Goldberg 1995 construction grammar; MacWhinney's Competition Model for the decision rule). So the
build is the NON-ARGUMENT ARM of the ONE labels rung, not a sixth relation organ: **the same strength math
(`strengths_from_counts`, asserted identical in self-test S7), the same additive activation
(`graded_competition.net_activation`), a counts asset, and an online `observe_fine_relation_outcome`.**

**THE DIVISION OF LABOUR THAT KEEPS THE TWO ARMS DISJOINT.** `coarse_roles` decides ARGUMENT-vs-NOT; where it
says OTHER (`dep`) or NMOD (`nmod`) -- *"a nominal licensed by a nominal is a PROPERTY of a thing, not an
oblique participant of an event"*, its own pri-108 words -- this arm refines. `all_relations` never rewrites a
core argument label except for one deliberate, measured case (§5, RUN_MEMBERS).

**THE CUES, all from organs the reader already runs.** `config` (head category x order), `dcat` (the
dependent's category), `gen` (the genitive case value), `run` + `runsym` (the name-run chunk and pri 118's
span-level capitalisation symbol), `gap` (the intervening material), `pslot` / `hps` (the predicate-slot
strength at the dependent and at its governor), `crs` (the ARGUMENT arm's own read -- the graded hand-off
between the two arms), `dist`. **`run`, `runsym`, `gen` and `pslot` are read ARC-INDEPENDENTLY** (key
`GLOBAL|value`), applying this organ's own pri-108 lesson verbatim: *a cue whose whole purpose is to survive a
WRONG arc must not be looked up INSIDE the arc's configuration.* Self-test S5 is the demonstration: with the
run member mis-attached to the verb, the configuration-conditioned read called it `punct` and the GLOBAL read
calls it `flat`.

**AND THE CONSTRUCTION NAMES ITS OWN GOVERNOR.** A construction is a form/GOVERNOR pairing, so
`fine_relations(..., with_heads=True)` returns `(relation, head)`: a name run's `flat` points at the run's

### 5.2 THE HUB TYPE CUE (an apposition is a TYPE ATTRIBUTION) -- a CI-separated negative, fully understood

An appositive PREDICATES a type of the referent to its left, so the natural cue is the pair of anterior-temporal
hub TYPES (Rogers & McClelland 2004; Patterson, Nestor & Rogers 2007) rather than the punctuation between them
-- read from the frozen offline supersense asset, no nltk at inference. Built, accrued and evaluated on the
DEV split; **DEV rejected it, and adding it back on test is -0.0030 CI95 [-0.0055, -0.0008], CI-SEPARATED DOWN**
(appos P 0.2262 -> 0.2170, R 0.3851 -> 0.3446).

**WHY, counted rather than narrated.** The cue has **654 distinct values, 71% of them with n < 20, median n
8.6**, and a count-weighted reliability of **0.213** against a top base rate of 0.154. Its most
appos-favouring value reaches only **P(appos | value) = 0.186**, and the SAME value carries 22 compound, 30
conj and 15 flat. **An appositive, a compound, a conjunct and a name run all pair two nominals of related
types** -- `person|PROPN|diff` is "Elizabeth, the doctor" and "President Obama" and "Mary and John" alike. The
hub type is real knowledge and it is not the DISCRIMINATIVE knowledge for this decision; the distinction is
PREDICATE-vs-CO-ARGUMENT, not type-vs-type. That is what pointed at 5.3.

### 5.3 THE ZERO-COPULA PREDICATE SLOT -- the brief's own item 4, built, and a CI-separated negative I can explain
