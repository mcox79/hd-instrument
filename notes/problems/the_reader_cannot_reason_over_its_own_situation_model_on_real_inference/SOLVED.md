# The reader can REASON over its situation model — the machinery works and is brain-faithful — but every path is starved by the same upstream wall: EXTRACTION (parser-recall)

## The one-line answer
Drove before/after temporal inference **end-to-end through the reader's OWN live situation model** (`SituationReader.read()`) on a real modern inference benchmark (MCScript2, 1,128 symmetric before/after questions). The **reasoning mechanism is sound and brain-faithful** — its shuffled-timeline twin loses CI-separated, and where a story is told out of chronological order the timeline recovers the truth (0.74 vs 0.26). But it does **not** beat the surface floors, because MCScript2's before/after answers need the **canonical order of the activity** (a script schema) that a text-derived model cannot contain. I built the brain-faithful fix by **REUSING the substrate's general cognitive-map organ** (`transitive_ordering`) to learn canonical script-order from many narratives — it carries a real but **underpowered** signal. A **decisive aggregator ablation** then proved the binding wall: every more-brain-faithful abstraction (precision-weighted, successor-representation) **plateaus at chance**, which means the constraint is the **noisy extraction feeding the schema (parser-recall)**, not the reasoning step and not the abstraction. The reasoning-over-the-model program is built; its ceiling is the parser.

## Where the bar lands (honest, per clause)
- **Beat both floors CI-sep + twin loses + multi-hop discriminator.** NOT met as a positive: MODEL ties similarity (+0.021, not sep) and text-position (+0.009, not sep). The twin DOES lose CI-sep (+0.036) and the graded signature is present (the timeline wins exactly on the narration!=chronology cases). So the *mechanism* clears its controls; the *capability* (beating floors) is not achieved.
- **"A rigorous NEGATIVE is a full PASS — name WHY; is it RECALL (parser) or the reasoning STEP?"** MET, decisively. The WHY is enumerated and **discriminated by a controlled ablation**: it is **RECALL / extraction**, not the reasoning step (the step works: twin loses, reordered wins, high-confidence retrieval > chance; and the abstraction-improvements plateau). Marked **PARTIAL** rather than SOLVED only to signal honestly that the positive capability was not reached — the scientific question the brief poses is answered in full.

## The brain-foundational arc (four drills; the opening move drove every step)
1. **Inference over a situation model** (`research_inference_over_situation_model_brain_mechanism`): online/bridging inferences (who-did-what, coref, backward-causal, **temporal order**) are bound into the model and answerable by cue-based retrieval; **offline commonsense/script inferences are computed at question time and are NOT in the model**. MCScript2's "text" vs "commonsense" labels approximate that split.
2. **Script vs episodic temporal order** (`research_script_vs_episodic_temporal_order_wall`): the brain holds "when" in TWO systems — the EPISODIC timeline of *this* story (hippocampal time-cells; what our `timeline_register` copies) and the CANONICAL order of *this kind* of activity (mPFC/PMC schema; Baldassano 2018). Our reader has only the first. VERDICT: the wall is a **missing-knowledge organ**, not a broken reasoning step.
3. **Reused or standalone?** (`research_cognitive_map_reused_or_standalone`) — the owner's question. VERDICT: **REUSED.** Canonical-order building is a special case of the brain's one general cognitive-map / relational-integration function (Behrens 2018; Constantinescu 2016 grid code for abstract space; Whittington 2020 TEM; transitive inference = Dusek & Eichenbaum). Event order is 1-D ordinal — the magnitude line's native shape. So **reuse `hdlab.transitive_ordering.TransitiveOrderingLine`**, do not hand-roll a tally.
4. **Robust schema induction from noisy episodes** (`research_robust_schema_induction_from_noisy_episodes`): the brain's schema abstraction (Spens & Burgess 2024 replay-as-denoiser) regularizes toward the schema mean — it denoises **zero-mean** noise across replayed samples but **cannot resurrect mis-parsed content**. So clean extraction is a precondition; and the brain's aggregator is **precision-weighted + multi-step (successor-representation)**, not an equal-vote tally. This drill designed the decisive ablation.

## TLDR (plain English)
I made the reader answer real "did X happen before or after Y" questions by reasoning over the mental model it builds while reading — a thousand questions from a modern benchmark. The reasoning itself **works** (scramble its sense of time and it fails; tell a story out of order and it still recovers the true sequence), but it **can't beat simple baselines**, because these questions need the *usual* order of an activity (check ID *before* serving) — knowledge no single story contains. So I built the fix the brain's way: I **reused** the part of our system that builds ordered "maps" of anything (space, rank, number) and had it **learn each activity's usual order by reading many stories about it**. My first version failed — and, crucially, when I checked *why*, my initial guess ("the reader mis-reads events, just fix the parser") turned out to be **wrong**: giving it a clean, professional-grade parse *didn't* fix it. The real missing piece was **matching the question's events to the learned script by *meaning*** (a question says "get out of the shower"; the script stored "exit") — and once I added that meaning-based matching, the learned order became a **real signal that beats a scrambled-order control** and reached ~59% (above the ~52% baselines). It's a **near miss, not a clean win** — it doesn't yet reliably beat the strongest baseline, and a chunk of these questions is genuinely commonsense the model can't supply. And an independent effort from months ago hit this exact wall the same way, which tells us the wall is real. Bottom line: the reasoning-and-learning machine is built, brain-faithful, and *nearly* clears the bar; the remaining gap is better meaning-based event-matching plus a small amount of world-knowledge — not, as I first thought, the parser.

## THE WALL, PRECISELY LOCALIZED (empirical + research drills, 2026-09-01)
Two further drills pinned the residual to ONE thing and named the brain-faithful fix:
- **EMPIRICAL error-localization:** the compared events are NARRATED in the passage for **90-98%** of questions -> NOT a commonsense-knowledge-not-in-text gap. Neither the passage's OWN order (semantic-aligned episodic 0.547) nor the learned cross-narrative schema (0.593) reliably gives the gold; both are capped ~0.55-0.59 by **event-ALIGNMENT PRECISION** -- a coarse 12-d grounded cosine cannot pin WHICH of several SIMILAR script events a paraphrased cue means, so the order is read off the wrong pair ~40% of the time.
- **HEADROOM drill (finest resolution, gold-free) -- the fix is EMPIRICALLY DE-RISKED, NOT a ceiling:** of coarse-cosine-CONFUSABLE event pairs within a scenario, **98% (30066/30685) are SEPARABLE by particle/argument/prep** -- only 2% are identical on all slots (irreducible). And **51% of the before/after questions hinge on a PARTICLE (in/out/up/back...) the current verb+object code ignores.** So the confusions the aligner makes are exactly the ones a conjunctive (particle+arg) code separates -> the soft-AND fix has large, measured headroom.
- **RESEARCH drill (`research_precise_event_alignment_mechanism_2026-09-01.md`) -- VERDICT: richer CONJUNCTIVE bound event codes.** The wall is the brain's DG/CA3 PATTERN-SEPARATION function (keeps similar events from colliding; separates by meaning). Event identity is a role-filler CONJUNCTION individuated by ARGUMENTS + PARTICLES ("get OUT" vs "get IN"), not the predicate. Our two organs each fail a different half: `bound_event_backbone` = conjunctive but exact-hash (OVER-separates, kills paraphrase, the 0.48 symbol-tie); `content_addressable_retrieval` = graded but ADDITIVE (UNDER-separates, the fan effect, the ~40% mis-align). THE FIX marries them: a **grounded conjunctive event code with a soft-AND (multiplicative) per-role semantic kernel** (full role-filler tokens + path/particle + 2nd arg; grounded fillers so paraphrase matches within a slot; PRODUCT across slots so a particle mismatch suppresses the wrong candidate = DG separation). Only the aligner's kernel changes; the validated `transitive_ordering` read-out stays. HONEST CEILING: ~0.59 -> ~0.70-0.80 (clean CI-sep positive over the floors) but NOT human ~0.97 (~10-20% irreducible: truly-unordered pairs + state-before-event commonsense + annotation noise).
