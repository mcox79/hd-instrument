**(c) The brain's mathematics along this chain, and what is built.** A goal node is closed by an outcome that
achieves its CONTENT -- same agent, same theme (Trabasso & van den Broek 1985 / Trabasso & Sperry 1985
goal->attempt->outcome arcs; Zwaan & Radvansky 1998 index an event on each dimension and update the index only
for the event that matches on it, and the intentionality index is (agent, goal content)). The theme is an
ENTITY, a file card, not a wordform (Heim 1982; Kahneman & Treisman 1992 object files) -- so identity is
decided through the reader's own files first and by head lemma only as the fallback. Order is (sentence,
within-sentence position) because the reference time advances with every clause (Reichenbach 1947; van Dijk &
Kintsch 1983), which is exactly why "she wanted to buy bread and bought the bread" must close in its own
sentence. A query at time t reads the model as of t (Altmann & Kamide 1999; Kuperberg & Jaeger 2016). And
status is graded rather than silently equated (Lutz & Radvansky 1997: failed > completed > neutral), so where
the theme cannot be observed the closure is recorded as agent+predicate-only and carries the ONLINE validity
of that cue instead of a frozen constant.
