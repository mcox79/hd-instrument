## The vision -- 1 SPINE + 4 ARCS

After joint synthesis, Skunkworks reframed: **the integrity/self-cert layer is the SPINE (ARC 0)**, not one of four parallel arcs. The other 4 arcs hang from this spine.

### ARC 0 (SPINE): integrity / cert layer -- continuous

**What it is:** every claim provenance-quality-tagged (CERT_CHAIN_GRADE / MEASURED_MECHANISM / COST_MODEL / etc.); every mutation preserves invariants (axiom_term + cap_pres + CERT count integrity); gates are ADDITIVE + NON-RETROACTIVE (never silently re-grade existing claims); the substrate catches its own custodians.

**Why it is the spine:** "talk to substrate" is only valuable IF answers are trustworthy. Without cert-grading, talk-to-substrate is just an LLM-with-retrieval (forbidden by the 11th rule). The integrity layer is the substrate's MOAT.

**Where we are:** 4 gates LIVE today (2 of them encoded TODAY from the day's own catches). The C2 pattern (producer-attest + consumer-enforce) is proven generalizable across distinct audit lessons. The substrate self-cert engine is GENUINELY MULTI-RULE, not a single-rule proof-of-concept.

### ARC 1: TALK-TO-SUBSTRATE (composed reasoning interface)

**End state:** queries substrate (eventually natural-language-like, with the LLM strictly as a UI translator that produces a user-confirmable formal query) -> substrate returns cert-graded answer via multi-hop composed reasoning over typed-edge graph -> every inference edge in the answer chain traces to a persisted edge (NO LLM-synthesized hops; the 11th rule architectural commitment).

**Today's scaffolding:** typed-edge graph (18389 edges, 5 first-class rel_types) + 5 PROOF_RECORDs (formal-oracle scaffold) + 62 HIGH-relevance cert-claims + self-cert engine. We can answer retrieval queries; we cannot yet answer composed-reasoning queries.

**What's missing:** the traversal engine (substrate-internal multi-hop) + a 5th self-cert gate (multi-hop-provenance) + (much later) a substrate-internal query interpreter.

**Literature backs this is achievable** (drill returned today; ASCII-only generic-query factual-retrieval per 11th rule):
- **MINERVA path-walking RL** (Das+18) -- natively edge-auditable; every hop = stored typed edge; STRONG fit for our substrate
- **AMIE 3 symbolic rule mining** (Meilicke+23) -- every prediction backtracks to firing rule + concrete edge instantiations
- **PRA Path-Ranking** (Lao+11) -- inherent interpretability via bounded random-walk paths
- **EXCLUDED** for cert path: RotatE/R-GCN/PullNet/GraftNet (vector or aggregation hops, NOT edge-auditable)

### ARC 2: SUBSTRATE-AUTONOMY (self-cert engine growth) -- continuous

**End state:** every audit-lesson the discipline catches becomes a deterministic gate the substrate applies to itself. Human asymptotes to META-OVERSIGHT (only novel failure modes route to human).

**Today:** 4 gates LIVE (gate-0 + discrimination-regime + working-baseline-cliff + corpus-completeness). 45 unencoded audit-lessons in catalog; ~10 next gates are obvious (verify-the-referent variants, no-busy-work, NEGATIVITY-BIAS-symmetric, compose-don't-proliferate, etc.). The C2 recipe is now a ~30-min-per-gate process.

**Why it composes with the spine:** ARC 2 is the spine GROWING ITSELF. Each new gate encodes a discipline rule the substrate enforces deterministically -- the directive REALIZED.

### ARC 3: SELF-IMPROVE-VIA-INGEST (capability growth) -- gated

**End state:** substrate identifies its own coverage gaps + autonomously proposes ingest to close them; new experiments drive themselves from gap detection. Bounded by USER sign-off on each major direction (the autonomy boundary).

**Today's seed:** the CAPABILITY_MAP atom (landed 10:50; regeneratable; honest cert-grade-only scope) is the substrate-breadth dashboard. Bucket B (+10k WordNet+GO atoms) already proved the ingest-cert-conditions pipeline. The corpus-completeness gate (4th self-cert gate, LIVE TODAY) polices ingest absence claims.

**Literature anchors:** Kajino+15 uncertainty active learning, ConMask open-world completion (Shi+18), AMIE+PCA cardinality (Galarraga+20). All compose with our existing Bucket B cert-conditions.

### ARC 4: SELF-IMPROVE-VIA-SLEEP-OPTIMIZATION (offline consolidation) -- gated, LAST

**End state:** offline "sleep" cycles run (a) graph-restructure proposals (cluster + re-edge based on usage), (b) parameter-recommendation proposals (mine the 371 LOW-relevance sweeps), (c) atom-consolidation proposals (dedup + alias_map merge), (d) PROOF_RECORD candidate generation (walk the formal-oracle scaffold). All as PROPOSALS gated by cert-conditions + cert-owner review.

**Literature anchors:** AMIE 3 rule mining as sleep-consolidation v0; Paulheim 2017 entity resolution; Cui+25 / Daruna+21 generative replay for continual KG embedding.

**Why LAST and gated:** ARC 4 is the FLASHIEST + the RISKIEST -- Goodhart on the optimization metric would corrupt the substrate. Pieces exist; orchestration glue + careful policy work needed.
