## (a) HEADLINE

The literature does **not** support a clean "perception is required" story for the reader's who-is-affected bound. Categorical and much of graded thematic-fit/event-plausibility knowledge is demonstrably learnable from text distribution alone (blind-acquisition studies, distributional models, near-ceiling LLM thematic-fit scores). But there is a *specific, replicated* residual gap concentrated exactly where the reader is stuck: graded, animate-animate patient/affectedness discrimination deployed under real-time compositional pressure (Kauf et al. 2023; a 2026 plausibility-under-pressure paper). The best-supported explanation for that gap in the literature is **reporting bias / under-representation of explicit outcome language in typical corpora** (PIQA's stated diagnosis), not an architectural need for embodiment. That reframes the strategic fork: the first move should be a capacity-controlled event-density corpus probe, not a jump to perception. P(corpus-route-is-sufficient-with-the-right-content-mix) = 0.40 (deflated; capped below 0.50 as novel synthesis over multiple threads, no direct precedent tests this exact ablation).

## (b) Cheap decisive test

**Capacity-controlled event-density ablation** (full recipe in Cross-thread synthesis below): build two token-matched, vocabulary-matched, perplexity-matched training pools that differ ONLY in density of explicit change-of-state / outcome language (verbs like broke, gave, killed, filled, opened, with an annotated patient/theme). Train at a FIXED representational capacity across both arms. Score on three frozen probes never touched by any arm: (i) McRae/Ferretti thematic-fit correlation, (ii) pseudo-disambiguation accuracy on held-out (agent,verb,patient) triples, (iii) a forced-choice "who is affected" task built from held-out event sentences with two plausible fillers.

This is cheap because none of it requires new grounding infrastructure -- it is a corpus-composition sweep at fixed capacity, reusing existing frozen human-rated norms as the yardstick (no new annotation needed beyond a verb-class filter to build the two pools).

## (c) Falsifiable predictions

**HARD-PASS** (event-density is a real, separable lever): the high-event-density arm beats the token/vocab/perplexity-matched control on the forced-choice "who is affected" probe by a margin that (i) holds at every tested capacity level (no density x capacity interaction), (ii) survives regressing out corpus perplexity/entropy as a nuisance covariate, and (iii) is concentrated on the affectedness/thematic-fit metrics specifically, not on general syntax/perplexity probes (e.g. BLiMP-style). This would mean: the reader's bound is a curatable content problem, corpus route is viable, perception is not required for this specific capability.

**HARD-FAIL** (event-density is not the lever, or is capacity-confounded): gains disappear once perplexity/entropy is controlled, OR gains appear only at one capacity tier and vanish/reverse at others, OR gains are undifferentiated across affectedness probes and general syntax probes (suggesting "denser text = easier text" not "denser text = more event content"). This would mean: the corpus-density lever is not the fix, and the strategic fork tilts toward either (i) a genuinely different curation axis (not density but structure/explicitness of outcome-marking), or (ii) perception/grounding as a harder requirement -- but note per (b) below even a HARD-FAIL here does not yet prove perception is *necessary*, only that this particular content lever failed.

## (d) Cross-thread synthesis

### 1. How the brain builds event knowledge (sub-agent 1)

Two genuinely separate mechanisms get conflated in casual usage of "event schema," and keeping them apart matters for the design:

- **Domain-general segmentation machinery** (Zacks & Tversky 2001; Zacks, Speer, Swallow, Braver & Reynolds 2007, *Event Segmentation Theory*): a predictive-coding process that continuously forecasts near-future input and opens a new "event model" when prediction error spikes. This is *how* the stream gets chunked into discrete events at all -- content-free, domain-general, tied to hippocampal binding (Radvansky & Zacks' Event Horizon Model). This is analogous to (and a candidate brain-check reference for) any coherence-gate / chunking machinery already in the substrate's reading loop -- it is NOT the source of "who gets affected" content.
- **Content-bearing event knowledge**: Schank & Abelson's scripts (1977) and later Memory Organization Packets (Schank 1982) are stored, reusable slot-filler structures learned from repeated exposure to a situation type (direct experience OR narrated accounts -- Schank never restricted scripts to perceptually-witnessed events). McRae/Ferretti/Hatherell's **generalized event knowledge (GEK)** is the modern, empirically-grounded descendant: verbs carry graded, verb-specific expectations about typical agents/patients/instruments, measured via priming and N400 amplitude (smaller N400 for plausible role-fillers). Elman's connectionist work (SRNs trained purely on next-word prediction over sentence streams, no perception, no embodiment) shows this GEK-like structure is inducible from **pure text-distributional exposure** -- the mechanistic proof that language-scale statistics alone can produce verb-argument/event expectations resembling human priming data.

Verdict on source: preverbal infant work (Michotte's launching effect; Leslie & Keeble 1987; Spelke's core-knowledge principles) shows a skeletal agent-causes-change-in-patient template is present before language -- so *some* causal/affectedness scaffold looks innate/perceptual and prior to any text exposure. But the *verb-specific, graded content* of event knowledge (which participant is the goal vs the theme, exactly how "typical" a given filler is) is empirically shown to be acquirable from language/distributional exposure alone -- this is not speculative, it is the direct finding of the blind-acquisition literature (next section) and the Elman/McRae distributional modeling literature.

### 2. The two routes, head-to-head (sub-agent 2)

Grounded/embodied accounts (Barsalou's perceptual symbol systems; Zwaan's Immersed Experiencer Framework with real behavioral shape-match effects; Glenberg's Indexical Hypothesis; Talmy's force-dynamics account of causative verbs) establish that *sighted* comprehenders recruit perceptual/motor simulation during sentence processing. This is real and replicated -- but it is evidence of *engagement*, not evidence of *necessity*. The literature is close to silent on whether simulation is required versus a rich optional elaboration on top of a distributional core.

Distributional accounts (Resnik's selectional preference; Padó & Erk; Baroni & Lenci's Distributional Memory) recover substantial graded thematic-fit structure from corpus statistics alone, correlating with human plausibility norms. Frontier LLMs (2410.15173, "Uncovering Autoregressive LLM Knowledge of Thematic Fit") now approach the human inter-annotator ceiling on standard McRae/Ferretti thematic-fit norms using text-only training -- i.e. the "easy" / central cases of thematic fit are solved by distribution alone at sufficient scale.

**The boundary, where it actually sits:** Kauf et al. 2023 (*Cognitive Science*, "Event Knowledge in LLMs: The Gap Between the Impossible and the Unlikely") is the single most load-bearing citation for this drill. It shows LLMs reliably separate *possible* from *impossible* role assignments (categorical: "the laptop bought the teacher" = impossible) but are markedly weaker, sometimes near-chance, at *likely-vs-unlikely* animate-animate role-reversal plausibility ("the nanny tutored the boy" vs. reversed) -- i.e. exactly graded who-is-affected discrimination among plausible-sounding fillers. A 2026 follow-on ("Plausibility as Commonsense Reasoning: Humans Succeed, LLMs Do Not") shows this gap persists under real-time compositional/attachment pressure -- humans shift interpretation by ~39 points under a graded plausibility manipulation, several LLMs show near-zero or reversed shifts, meaning the knowledge may exist in the weights but fails to *deploy* under compositional load. This maps with uncomfortable precision onto the substrate reader's own stuck point (patient-selection / who-is-affected resolution) -- it is independent confirmation from a completely different research community that this exact sub-capability is where text-only systems break, not a substrate-specific artifact.

Blind-acquisition evidence (Landau & Gleitman 1985; Bedny et al.'s neural-representation work on blind adults) undercuts the strongest version of "perception is necessary": blind individuals acquire normal semantics for *perception* verbs (look/see) via syntactic bootstrapping alone. Important caveat surfaced by the sub-agent: this evidence base concentrates on perception verbs, not on physical change-of-state verbs (shatter/spill/fade) specifically -- so it is suggestive but not a direct test of the affectedness-core question. Flag this as an evidence gap, not a resolved point.

PIQA's own diagnosis of the LLM physical-commonsense gap (Bisk et al. 2020) attributes it substantially to **reporting bias**: physical facts and outcomes are rarely stated explicitly in ordinary text (nobody writes "and then the glass, being made of a brittle solid, fragmented into pieces upon impact" -- they write "she dropped the glass"). This is the key move for the strategic fork: the gap looks less like "text cannot in principle carry this information" and more like "ordinary corpora under-sample the explicit-outcome sentences that would carry it," which is a *fixable content-composition* problem, testable cheaply (see cheap decisive test above) before concluding perception is structurally required.

### 3. Design -- avoiding the capacity-artifact trap (sub-agent 3)

BabyLM Challenge infrastructure already normalizes "fixed token budget + fixed model size, vary source composition" as a design pattern, though no existing BabyLM ablation isolates event/outcome density specifically -- this is a genuine, cheap, un-run experiment, not a re-tread. Racz et al.'s "Scalable Data Ablation Approximations" (EMNLP 2024) gives a cost-saving trick (train small disjoint shards, compose/merge to approximate a full ablation grid) directly reusable to make the sweep cheap. Chambers & Jurafsky-style pseudo-disambiguation gives a label-free plausibility probe (score true (agent,verb,patient) triples against corrupted ones) that needs no new human annotation and can be reused unchanged as the frozen yardstick across every arm.

The design-gate discipline already standing in this project (design-gate-before-full-run: real baseline, can-fail discriminator, difficulty actually on, one variable differs) maps directly onto the recipe in (b): the "one variable differs" is event-outcome density; the "can-fail discriminator" is the forced-choice affectedness probe (chance = 50%, not saturated); the capacity-artifact control (regressing out perplexity, sweeping across capacity tiers) is exactly the must-fail-control this project's discipline requires before trusting a positive.

## (e) Substrate-product implications

- This drill does **not** conclude "go build perception." It concludes: the specific sub-capability the reader is missing (graded who-is-affected discrimination) is the *same* sub-capability the broader field has independently identified as the sharpest LLM weak point, and the field's own leading diagnosis for that weak point is a fixable content/curation problem (reporting bias in ordinary corpora), not an architectural embodiment requirement. That is good news for cost: a capacity-controlled event-density corpus probe is far cheaper than any perception/grounding build-out, and the literature gives no basis yet for skipping straight to perception.
- This is also a genuine caution against the "more corpus" REFUTATION already on the books (per current MEMORY state: "more corpus" was refuted as a scapegoat). That refutation was almost certainly testing corpus *size*, not corpus *event-outcome density* at matched capacity/size -- those are different variables and the prior refutation does not pre-empt this test. Recommend explicitly checking the prior "more corpus" experiment's design against the capacity-artifact trap described in (b)/(c): if it varied size/scale without controlling for event-density composition, it tested a different hypothesis than this one, and the refutation should not be read as covering this fork.
- If the HARD-PASS band fires: the fix is a curation task (build/filter a higher-event-outcome-density text pool), squarely inside the existing "adopt from prior art, recombine, don't invent" build program -- no new grounding modality needed, just better-composed text.
- If the HARD-FAIL band fires: this still does not prove perception is *necessary* (it only rules out the density lever) -- the next fork would be explicitness/structure of outcome-marking (e.g. explicit change-of-state predicates vs. implicit) before escalating to perception, per the reporting-bias diagnosis. Perception should be treated as the last resort, not the second move.
- Cross-thread relevance: the segmentation-vs-content distinction (Zacks EST = domain-general chunking machinery; Schank/McRae = content) is a useful brain-check reference for anything in the current build program that conflates "the coherence gate that decides when to chunk" with "the knowledge of what typically happens to whom" -- these should probably remain architecturally separate components (a generic predictive-error chunker feeding a learned, content-bearing thematic-fit store), matching the project's existing metacognition/codebook-gate separation.
