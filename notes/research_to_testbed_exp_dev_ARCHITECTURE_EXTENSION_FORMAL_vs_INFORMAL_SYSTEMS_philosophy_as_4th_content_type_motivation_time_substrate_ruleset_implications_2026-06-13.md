### MOTIVATION ruleset (philosophy of action / agency / intentionality)

Substrate currently has NO explicit goal/intent system. KP operator promotes by frequency + geometry + bisimulation + Curry-Howard derivability -- but these are PASSIVE structural mechanisms, not intentional / goal-directed.

Philosophical informal-system primitives substrate may need:
- **Intentionality** (Brentano + Husserl + Searle): substrate's atoms can be ABOUT other atoms; reference relation explicit
- **Goal-directedness** (Aristotle telos + Davidson 1963 "Actions Reasons and Causes"): substrate operators have goals (improve macro F1 + maintain capability coverage)
- **Practical reason** (Anscombe 1957 + Bratman planning theory): substrate makes decisions about what to ingest next + what to promote
- **Agency** (Frankfurt 1971 "Freedom of Will and Concept of Person" hierarchy of desires): substrate's recursive self-improvement loop = higher-order desire to improve lower-order capabilities
- **Sub-goal hierarchies** (Newell + Simon 1972 Means-Ends analysis): substrate's MASTER PLAN Phase 1-4 = goal-decomposition

### TIME-BASED ruleset (philosophy of time / diachronic identity / causation)

Substrate's temporal reasoning is currently shallow:
- Memory entries have timestamps
- Atoms have ingestion order
- BUT no explicit temporal-reasoning ruleset over substrate state

Philosophical informal-system primitives:
- **A-series vs B-series** (McTaggart 1908): A = past/present/future indexical; B = earlier-than/later-than relational. Substrate currently uses B-series implicitly (commit timestamps); A-series (NOW pointer) needed for agent-style reasoning
- **Eternalism vs presentism**: do all times exist (eternalism; substrate's commit history is permanent) or only NOW exists (presentism; substrate's working state)? Substrate needs to handle both
- **Diachronic identity** (Parfit 1984): is the substrate-at-cycle-51 the SAME substrate as substrate-at-cycle-1? Connected via causal chain + memory + axiom-preservation
- **Causation** (Lewis counterfactual + Pearl interventional): substrate's recursive self-improvement loop has Stage 4 verify (intervention) + Stage 6 regression check (counterfactual); explicit causal structure
- **Temporal logic** (Prior + Kamp + linear-temporal-logic LTL + computation tree logic CTL): substrate's promotion / regression sequences

**Atoms substrate may need**:
- a_series_indexical_temporal_concept (NOW pointer)
- b_series_relational_temporal_concept (earlier-than/later-than)
- diachronic_identity_persistence_concept
- causal_intervention_concept (Pearl)
- counterfactual_dependence_concept (Lewis)
- linear_temporal_logic_LTL_axioms
- computation_tree_logic_CTL_axioms
