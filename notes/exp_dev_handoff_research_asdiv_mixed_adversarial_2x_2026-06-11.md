## Anchor candidates (rank-ordered)

### Anchor 1: K-way problem-type gate (substrate-native)
- Pointer: stage-1 of the 3-stage cascade in source research note,
  section (b) Cheap decisive test and section (c) Prediction 1.
- Substrate-product reading: single linear discriminative head over the
  bundle vector, supervision = problem-family label. Family taxonomy
  ~8-12 entries (percent, ratio, algebra-1var, geometry-area,
  geometry-perimeter, comparison, time-rate, multi-step, counting,
  fraction-mixed, work-rate, unit-conversion).
- Tier hint: Tier-A (cheap; single head; standard discriminative
  perceptron training; pre-existing MWP datasets usually have family
  tags).
- HARD-PASS / HARD-FAIL: see source note Prediction 1
  (HARD-PASS >= 0.75 macro-F1; HARD-FAIL <= 0.45 macro-F1).
- Why now: this is the dominant single lever per cognitive-science
  evidence (Chi/Reed: categorization-before-schema). Cheap.
  Decisive within one cell.

### Anchor 2: Per-family discriminative heads with routing
- Pointer: stage-2 of cascade; source note section (b) and Prediction 2.
- Substrate-product reading: K separate linear heads on the same bundle
  vector, each trained only on within-family problems; inference routes
  by argmax of Anchor-1 gate.
- Tier hint: Tier-A but gated on Anchor 1 HARD-PASS.
- HARD-PASS / HARD-FAIL: source note Prediction 2 (mixed-regime
  accuracy crosses from shallow-adversarial band into multi-step
  composition band; HARD-FAIL if lift <= 25% of that gap).
- Why now: per-family separation is the second-largest lever and
  mechanically follows Anchor 1.

### Anchor 3: Verifier head on (problem, candidate-answer) pairs
- Pointer: stage-3 of cascade; source note section (b) and Prediction 3.
- Substrate-product reading: binary head over (problem-bundle,
  candidate-answer-bundle); positives = (problem, correct), negatives
  generated by routing same problem to a nearby family's head and
  using that wrong answer.
- Tier hint: Tier-A; small additional head; synthetic negatives are
  cheap.
- HARD-PASS / HARD-FAIL: source note Prediction 3 (verifier delta on
  mixed-regime >= half the gap between post-stage-2 mixed accuracy
  and clean single-op accuracy; HARD-FAIL if delta within noise).
- Why now: literature precedent (verifier-style reward models) is
  unusually strong; the substrate version is a single discriminative
  head, no LLM.

### Anchor 4: Extractive pre-bundling sentence-importance head
- Pointer: source note section (e) Risk register "bundle interference"
  and the rank-summary list item 4.
- Substrate-product reading: substrate-native sentence-importance
  classifier head that scores each sentence in a long-text problem;
  only top-K sentences enter the role-filler bundling step. Specifically
  attacks the comprehension-heavy / distractor band.
- Tier hint: Tier-B (separate from cascade; orthogonal lever; can be
  composed with Anchors 1-3).
- HARD-PASS / HARD-FAIL: incremental lift on comprehension-heavy
  subset over baseline-with-all-sentences-bundled >= half the
  comprehension-heavy minus shallow-adversarial gap.
- Why now: targets the specific comprehension-heavy weakness, not the
  family-distribution weakness.

### Anchor 5 (refutation): schema slot-filling alone (no gate)
- Pointer: source note Prediction 4.
- Substrate-product reading: role-filler binding for ("unknown",
  "given1", "given2", "operation", "unit") slots without the type-gate
  routing. Tests whether comprehension/schema is the dominant lever
  vs routing.
- Tier hint: Tier-B; structural alternative-hypothesis test.
- HARD-PASS for "not dominant": slot-filling alone lifts mixed-regime
  by <= 25% of the cascade total lift.
- HARD-FAIL (i.e. for the "routing is dominant" hypothesis): slot-
  filling alone matches or exceeds gate + per-family head, in which
  case the dominant lever is comprehension/schema not routing and
  Anchors 1-3 prioritization is wrong.
- Why now: structural falsifier for the cascade hypothesis. Cheap
  alternative-hypothesis test. Should run in parallel with Anchor 1
  if possible.
