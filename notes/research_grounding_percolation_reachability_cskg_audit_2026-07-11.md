## HEADLINE (4-line)

1. **Yes -- grounding-as-reachability-from-an-anchored-seed-set is a coherent, non-novel-invented, actively-published formalism, not a metaphor we'd be stretching.** Percolation theory (Erdos-Renyi giant component, Molloy-Reed criterion, Dorogovtsev k-core hybrid transitions, Coja-Oghlan-Feige-Krivelevich-Reichman "contagious sets in expanders") gives exact, computable machinery for "does a small seed set reach a giant/spanning component," and a small, real, cross-referenced literature (Vincent-Lamarre/Blondin-Masse/Harnad's grounding-kernel dictionary graphs, extended into 2025-2026 by two follow-on papers) has ALREADY formalized symbol-grounding itself as exactly this reachability property: a symbol is groundable iff its definitional-closure intersects an exogenous anchor set. We are not inventing the framing; we are applying an existing, cross-domain-validated formalism to CSKG specifically.
2. **CSKG is directly, cheaply auditable for this property right now, with no new data acquisition**: the cross-cutting commonsense core (501k nodes / 1.18M edges, 12-core = 23,632 nodes @ avg-deg 38.4, already downloaded and k-core-decomposed off-disk per `cskg_commonsense_core_kcore_density_gate_2026-07-10.md`) is the exact graph substrate a seeded-reachability audit needs, and Brysbaert concreteness / Lancaster sensorimotor norms (public, ~40k-word CSVs, already identified as the grounding-channel source in `research_deliberate_ingest_spec_spanning_grounded_core_2026-07-10.md`) supply the exogenous anchor-set labels via a simple string join on CSKG's existing node-label columns -- no crawl, no new corpus, pure graph computation.
3. **The literature surfaces one sharp, non-obvious risk that MUST be built into the test as a must-fail control, or the audit is vacuous**: for scale-free/power-law graphs (degree exponent <=3, which commonsense KGs typically are), the percolation threshold -> 0 and k-cores emerge almost trivially -- meaning "does the grounded seed set reach the abstract targets at all" is likely to PASS by construction, for ANY reasonably-sized seed set, grounded or not. The discriminating question is not raw reachability but whether concreteness-selected seeds reach abstract targets FASTER / at SHORTER hop-distance / with FEWER seeds than (a) a same-size RANDOM seed set on the SAME real graph, and (b) the SAME grounded seed set on a degree-preserving-RANDOMIZED (scrambled) version of the graph. No prior work was found applying this specific must-fail-control pairing to a grounding-reachability metric -- this is the drill's own novel-synthesis contribution (P-capped accordingly), not an established test lifted from the literature.
4. **A newly-surfaced, independently-verified 2025 preprint (arXiv:2509.20409, Liu, "A Unified Formal Theory on the Logical Limits of Symbol Grounding") gives a Gödelian argument that STATIC reachability audits, however cleanly they pass, are necessary but not sufficient for "true" grounding** -- it argues meaningful grounding requires an external, dynamic, non-fixed-algorithmic process (framed via oracle machines / physical transduction), and that no finite static structure can consistently certify its own full groundability. This is independent theoretical corroboration (single-author, unreviewed preprint, so treated as suggestive not settled) of the ALREADY-LOCKED project finding that grounding needs an actively-sampled exogenous channel, not just borrowed reachability (`project_grounding_needs_active_intervention_exogenous_referent_3source_synthesis_2026-07-09.md`) -- the percolation/reachability audit answers "is the graph STRUCTURALLY capable of carrying grounding," which is the prerequisite the active-intervention channel then has to actually populate; it does not replace that channel.

## Cheap decisive test (pre-registered, REMOTE-runnable, no training, pure graph computation)

**Data already on disk / cheaply fetchable, no new acquisition:**
- CSKG cross-cutting subgraph: already downloaded (`cskg.tsv.gz`, 112,312,195 bytes, Zenodo 4331372) and k-core-decomposed (script `scratchpad/kcore.py` per the 2026-07-10 gate note). Reuse the same simple-undirected cross-cutting graph (501,391 nodes / 1,184,796 edges).
- Brysbaert et al. concreteness norms (~40k English words, freely downloadable CSV) and/or Lancaster sensorimotor norms (Lynott & Connell, ~40k words, freely downloadable CSV) -- join on `node1;label` / `node2;label` columns already present in `cskg.tsv.gz`. No crawling, no LLM calls, a string-match join.

**Procedure:**
1. **Define the grounded seed set S**: CSKG nodes whose label matches a Brysbaert-norm word with concreteness >= a pre-registered threshold (e.g. top quartile, or >=4.5/5) AND/OR Lancaster max-perceptual-strength above a pre-registered threshold. This is an EXOGENOUS selection criterion (measured human ratings), deliberately NOT a graph-topology criterion (see risk #3 below for why this distinction is load-bearing).
2. **Define the abstract target set A**: CSKG nodes whose label matches a Brysbaert-norm word with concreteness <= a pre-registered low threshold (e.g. bottom quartile, or <=2.5/5) -- e.g. "justice," "multiplication," "honesty," "probability." Exclude function/grammatical words from both S and A (the Vincent-Lamarre finding below shows these behave differently and would confound the concrete/abstract contrast).
3. **Multi-source BFS from S**, restricted to the cross-cutting subgraph (reuse the already-validated dense-core region, k=12-14 band, plus its periphery for hop-count headroom): for each node in A, record shortest hop-distance to the nearest node in S, and the cumulative fraction of A reached within k=1,2,3,4,5 hops. This is the percolation/reachability curve -- same shape as the already-run grounding-cascade decay-curve measurement (`research_grounding_cascade_depth_multihop_mechanism_2026-07-09.md`), but here it is a pure, trainable-parameter-free graph BFS, not a learned-readout accuracy curve, so it is strictly cheaper and has zero confound from encoder/readout quality.
4. **Control A -- random-seed-same-graph**: repeat step 3 with a same-size RANDOM seed set (uniform over all cross-cutting nodes, matched |S|), on the SAME real graph. Repeat over >=20 random draws for a distribution, not a point estimate.
5. **Control B -- grounded-seed-scrambled-graph**: repeat step 3 with the SAME real seed set S and target set A, but on a degree-preserving-RANDOMIZED (configuration-model / double-edge-swap) rewiring of the SAME graph. Repeat over >=20 rewirings.
6. **Control C (bonus, cheap, directly tests the Vincent-Lamarre finding)**: repeat step 3 using the graph-theoretic KERNEL/hub nodes (highest-degree or highest-k-core-membership nodes) as the seed set instead of the concreteness-selected set, to test whether "most reachable/connective" and "most concrete/exogenously-anchored" are the same node population or (per the literature below) systematically DIFFERENT ones.

## Falsifiable predictions (HARD-PASS / HARD-FAIL)

**Prediction 1 -- percolation/reachability framing is real and CSKG passes where a thin/islanded graph fails.**
HARD-PASS: on the real cross-cutting CSKG graph, >=70% of abstract targets A are reached within k<=4 hops from the concreteness-selected seed set S (a bar chosen to match the already-used 70% grounding-reach threshold in `research_deliberate_ingest_spec_spanning_grounded_core_2026-07-10.md`, not invented fresh here), AND this reach is NOT matched by Control B (scrambled-topology) at the same k -- i.e. the real edge structure, not just the degree sequence, is carrying the reach.
HARD-FAIL: reach under 70% at any reasonable k (graph genuinely does not connect grounded and abstract vocabulary -- would reproduce, on CSKG, the same closed-relational-island failure mode already found on the thinner ConceptNet-slice/prior graphs), OR reach is statistically indistinguishable from Control B at matched k (real structure adds nothing beyond degree sequence -- the Bender-Koller "octopus"/form-without-content failure mode, operationalized empirically for the first time found in this lit-scan).

**Prediction 2 -- grounded-seed selection matters beyond generic seed-set-size (Control A).**
HARD-PASS: concreteness-selected S reaches A at meaningfully shorter median hop-distance (or higher k=2/k=3 coverage) than size-matched random seed sets, with a non-overlapping or barely-overlapping confidence interval across the >=20 random draws.
HARD-FAIL: concreteness-selected S is statistically indistinguishable from random-seed reach at the same size -- would mean CSKG's cross-cutting core is so densely connected (consistent with sub-agent A's finding that scale-free graphs percolate almost trivially) that "being grounded" confers no reachability advantage over "being an arbitrary node" -- an important, cheap-to-detect negative that would redirect effort away from seed-selection-by-concreteness and toward a different mechanism (e.g. Control C's kernel-based seeding, or accept that reachability is generically free at this density and the real bottleneck lies elsewhere, consistent with the prior convergence-architecture note's "grounding = verifier not geometry" conclusion).

**Prediction 3 -- kernel-hub nodes (Control C) are NOT the same population as concreteness-anchored nodes, and seeding from the wrong one degrades the audit.**
Per Vincent-Lamarre et al. 2016 (verified quote below): dictionary Core/kernel words are **less** concrete than Satellite words, with concreteness rising with distance from the graph-theoretic core through the Satellite shell. HARD-PASS (this drill's prediction): CSKG's highest-degree/highest-k-core hub nodes show LOW average Brysbaert concreteness (mirrors the dictionary-graph finding on a different, larger commonsense graph), confirming that "most topologically central" and "most exogenously grounded" are systematically different, sometimes inversely related, node populations -- meaning any future map-builder or reasoning-map construction that seeds or weights by graph centrality alone (a common, cheap default) is NOT automatically also selecting a grounded core, and the two selection criteria must be kept explicitly decoupled (directly parallel to the already-locked `reference_correlation_hurts_associative_store_capacity` discipline: decouple store/structural-selection criteria from semantic/retrieval criteria). HARD-FAIL: CSKG's hubs show high concreteness (would mean the dictionary-graph finding does not transfer to a commonsense-relation graph, and centrality-based seeding is an acceptable proxy for grounding-seed selection after all -- a genuinely useful simplification if true, but not the way to bet a design on without checking).

## Cover, answered in order

**1. Percolation framing -- coherent and testable?** Yes. Confirmed by an independent lit-scan: Erdos-Renyi giant-component threshold, Molloy-Reed criterion for arbitrary degree sequences, Newman-Strogatz-Watts generating-function machinery, Dorogovtsev-Goltsev-Mendes k-core hybrid-transition theory, and (for the seeded/targeted case specifically, not just random dilution) Coja-Oghlan/Feige/Krivelevich/Reichman's spectral-gap bounds on minimum "contagious set" size in expanders, plus the classical Kempe-Kleinberg-Tardos influence-maximization formalism. All of this is mature, decades-to-a-decade old, off-the-shelf math -- percolation-as-a-framing is not novel-synthesis risk; only its APPLICATION to a typed-relation grounding-reachability question on a specific KG is new (deflated accordingly below).

**2. The grounded floor on CSKG -- auditable?** Yes, cheaply. CSKG's node labels are common lexical items overlapping Brysbaert/Lancaster norm vocabularies directly (already established in the spanning-grounded-core note); the cross-cutting core is already downloaded and k-core-decomposed. No new acquisition needed, only a join + BFS, both cheap remote CPU jobs.

**3. Brain check -- does the brain's abstract grounding actually require reachability-to-concrete, or is there real zero-anchor abstract grounding?** The independent brain/cognitive-science lit-scan found NO credible published account of abstract concepts being grounded with a fully closed, self-referential symbolic structure and zero traceable path to something concrete/perceptual/interoceptive/social. Even the strongest counter-position found (Dove's "dis-embodied cognition") still roots language in an embodied substrate rather than dispensing with an anchor; even mathematical formalism's own founding program (Hilbert) concedes an irreducible "intuitive" (non-formal) layer for elementary number theory (Stanford Encyclopedia of Philosophy, "Hilbert's Program"). Reinboth & Farkas (2022) give the sharpest formal statement: grounding is graded by DISTANCE to a sensorimotor/experiential anchor via direct and indirect (linguistic/social) pathways, asymptotically approaching but never severing the anchor -- directly consistent with, and independently corroborating, this drill's percolation/reachability framing (graded reach = hop-distance; genuine severing = HARD-FAIL). Confidence: the "reachability-to-anchor is necessary" claim is high-confidence (this is the dominant/near-unanimous position, not merely majority); "no zero-anchor abstract grounding exists" is a negative finding (absence of a counter-account), medium-high confidence given a real but not exhaustive search.

**4. Non-circularity -- does the floor bottom out in something exogenous?** Yes, and this is where the "how" gets a name: the closest-matching prior-art formalism (Vincent-Lamarre/Blondin-Masse/Harnad's dictionary-graph "Grounding Kernel"/"Minimal Grounding Set," and two 2025-2026 follow-on papers extending the same graph-reduction logic to AMR graphs and to a general "Lexical Groundability" definition) is explicit that a symbol is groundable ONLY if its definitional/relational closure intersects an EXOGENOUS anchor set (Harnad's sensorimotor/causal-coupling requirement, Taddeo-Floridi's zero-semantic-commitment condition, Bender-Koller's octopus argument) -- a purely symbolic, however dense or well-connected, closed graph does NOT count, by the field's own near-unanimous definition, not merely by our own house discipline. This is directly consistent with, and gives external theoretical backing to, the prior drill's parasitic-grounding conclusion.
