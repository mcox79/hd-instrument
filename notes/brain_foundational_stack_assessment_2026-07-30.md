## 1. THE BRAIN'S COMPREHENSION NETWORK — functional decomposition (biology-grounded)

Language comprehension is not one organ; converging neuroscience (Hagoort's Memory-Unification-Control model; Friederici's neurocognitive model; Fedorenko's language-network fMRI work) decomposes it into components that are dissociable by lesion/fMRI/ERP:

1. **Lexical-semantic access** — retrieving word meaning from a distributed conceptual store. ATL as amodal semantic hub (Lambon-Ralph hub-and-spoke; semantic dementia lesion evidence); posterior MTG/STG for lexical retrieval (Hickok-Poeppel dual-stream; Binder et al. meta-analysis).
2. **Syntactic structure-building** — assembling hierarchical constituent structure from the linear word stream. LIFG/Broca's BA44/45, Merge (Friederici's "syntax network"; Broca's aphasia agrammatism).
3. **Thematic-role assignment** (syntax→semantics interface) — mapping structural positions to agent/patient/etc., INVARIANT to surface word order (voice, passivization). Grodzinsky's Trace-Deletion Hypothesis; Bornkessel-Schlesewsky's actor-centered eADM; Caramazza-Zurif's canonical-order-default finding in Broca's aphasics.
4. **Working memory / active maintenance** — holding partially-built structure and entity states online across a clause/sentence. Persistent-activity attractor WM (Wang) or activity-silent synaptic WM (Mongillo, Stokes); gated by PFC-basal-ganglia loops (O'Reilly-Frank PBWM) — the gate decides what enters/updates WM, which is also the situation-model UPDATE mechanism.
5. **Situation-model / event-model construction and update** — integrating propositions into an evolving mental model of who/what/where, not just a "textbase" (Kintsch's Construction-Integration); indexed along space/time/causation/entity dimensions (Zwaan's event-indexing model); segmented into discrete events at prediction-error spikes (Zacks & Franklin's SEM — this is the closest existing literature to our own "comprehension = update a world model" framing, independently arrived at).
6. **Coreference / entity tracking** — resolving which entity a later mention (pronoun, definite NP) refers to, often COMPETITIVELY among candidates, not just single-antecedent lookup. Discourse-level integration studied via N400/coreference-ERP (Van Berkum et al.); overlaps WM (entity slots) but is a distinct competitive-resolution process.
7. **Discourse-level / bridging inference** — connecting clauses/sentences via causal, elaborative, or bridging inferences not explicit in the text (Graesser's constructionist theory; coherence-driven inference generation).
8. **Binding** (cross-cutting, not sequential) — how role and filler get glued together in the neural code so "dog bit man" ≠ "man bit dog." Contested at the neural-mechanism level: synchrony/phase-coding (theta-gamma; Lisman-Jensen, Fries) vs. mixed-selectivity/conjunctive coding (Rigotti-Fusi) vs. tensor-product/structured representations (Smolensky).

This differs slightly from the USER's suggested list only in making #8 (binding) explicitly cross-cutting rather than a pipeline stage, and in keeping #3 separate from #2 (structure-building gets you a tree; role-assignment is reading roles OFF that tree against surface order — these dissociate in Broca's aphasia, where structure is partially built but the canonical-order default still wins).

## 3. THE ASSESSMENT — ranked highest-leverage next levers

**Named blocker, precisely:** conversational comprehension is blocked by an **assembly gap**, not primarily by an unsolved-mechanism gap. We have TWO independently VET-confirmed, brain-motivated organs that have never been run together:
- a working situation-model UPDATE/maintenance mechanism (content-gated overwrite, #4/#5), and
- a working composition/binding mechanism (native FHRR, #8),
plus an entirely-untouched component (competitive coreference, #6) and an entirely-untried component (discourse inference, #7). Meanwhile the voice-invariant-role sub-arc (#2/#3) — which has consumed the majority of recent multi-night effort — has just been recalibrated as PARTLY A MEASUREMENT ARTIFACT (the "wall" was a cross-voice geometry-transfer probe issue, not a demonstrated incapacity of the organ; the genuinely falsifiable regime hasn't been built yet).

**Ranked next levers (by what BLOCKS conversational comprehension, not by ease):**

1. **HIGHEST LEVERAGE — ASSEMBLE, don't refine further in isolation.** Build ONE end-to-end cell that chains: encoder → EXPLICIT-role-word slot-filling extraction (the regime we already have proven, #8) → the content-gated WM (#4/#5, already proven) → multi-sentence entity-state update → query. This is cheap (every piece exists and is VET-confirmed), directly tests the actual north-star operation ("comprehension = update a world model"), and — critically — will surface the REAL next bottleneck empirically (very likely coreference, since #6 is the first untested thing a multi-sentence passage forces) instead of us guessing at it from isolated single-mechanism probes. This has never been attempted despite both prerequisites being bankable for over a night's worth of work.
2. **SECOND — competitive coreference / entity tracking at scale (#6).** This is a genuinely untouched, textbook-necessary SEM/Kintsch component (you cannot maintain an updated entity state if you can't resolve which entity a later mention refers to among 2+ candidates). It is more clearly "foundational and unaddressed" than the voice-role sub-arc — zero prior work exists to build on, versus the voice arc's several nights of (recalibrated, still partially informative) work. Sequence this right after / alongside #1, since #1's assembly will likely hit it as the first real wall.
3. **THIRD, RE-SCOPED (not abandoned) — the syntactic thematic-role arc (#2/#3).** It is a real prerequisite for reading role-from-syntax on NON-templated, real-world text (you can't lean on explicit role words forever), so it is not wasted or wrong-headed — but it should stop being the primary nightly frontier. Concretely: (a) finish the one falsifiable test in flight (a regime where the positional-template control actually floors) to get a clean verdict either way, cheaply; (b) do not open new structure-building objective variants beyond that until #1/#2 have been attempted, since those will tell us how much naturalistic comprehension we can already get away with using explicit-role/structured extraction as an interim front-end.

**Discourse-level bridging inference (#7)** is real but appropriately deferred — it presupposes #1's assembly and #6's coreference are in place; naming it here so it isn't forgotten, not because it's next.

**One-line verdict:** the voice-invariant-role arc is a legitimate but currently over-weighted sub-problem — after several nights it produced a recalibration (the "wall" was partly a probe artifact) rather than a clean capability or a clean kill, while two already-proven organs (native binding composition + content-gated WM) have never been assembled end-to-end and coreference sits completely untouched; the highest-leverage move now is to ASSEMBLE what's already proven into one naturalistic-ish situation-model pipeline (surfacing the real next wall empirically), pursue competitive coreference as the next clearly-foundational gap, and let the syntax/voice work continue at reduced priority until its one remaining falsifiable test resolves.
