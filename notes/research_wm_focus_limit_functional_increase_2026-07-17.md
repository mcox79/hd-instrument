# Research note: the ~4-item FOCUS limit -- why it's an interference/binding problem, not a storage problem, and how to functionally raise it

**Date:** 2026-07-17. **Filed by:** research (3 parallel Sonnet lit-scans + Sonnet synthesis).
**Trigger:** direct Director task -- explain intuitively why the substrate's resonator/factorization "focus" (how many bound things it can hold and jointly reason over AT ONCE) sits at ~4 and does NOT grow with vector dimension N (unlike raw storage), then rank functional ways to raise it.
**Cross-thread status:** this drill goes DEEPER than, and independently cross-validates, `notes/research_working_memory_integration_upper_limit_2026-07-16.md` (which first identified F=3-4 resonator factors as the Cowan-analog and N/16-32 bundle crosstalk as the separate storage-analog) and `notes/research_wm_barrier_glassbox_parsing_2026-07-17.md` (WM-as-incremental-structure, not raw capacity). This note adds the missing biological MECHANISM (interference/binding, theta-gamma), independently confirms the resonator literature treats "storage capacity" and "simultaneous-factor capacity" as genuinely different things (not just our own analogy), and adds one NEW lever not previously covered: multiple decoupled parallel foci.

## HEADLINE

**The ~4 limit is a CONFUSION problem, not a SPACE problem -- and that's true in both the brain and the resonator.** In the brain, the dominant account (Oberauer's interference model) is that items don't get lost, they get MISBOUND -- the wrong feature gets attached to the wrong object ("swap errors"), which is mechanistically different from running out of room. In the resonator/VSA literature, the same shape shows up: increasing vector dimension N raises how much data you can STORE (a superposition/crosstalk problem, fixed by cleanup memory and sparse codes), but does NOT raise how many factors you can JOINTLY resolve in one factorization query (a combinatorial-search/spurious-fixed-point problem, empirically peaking at F=3-4 in the primary resonator-network literature, independent of N). These are confirmed in the literature to be two separate mechanisms, not one -- which means "just make N bigger" was never going to fix focus, and this drill's job is to find the levers that actually do.

The single most useful, substrate-available NEW lever from this drill (beyond what's already built) is **multiple decoupled parallel foci**: the brain gets exactly 2 (verbal + spatial, per Baddeley's dissociation), because it only evolved two specialized non-interfering systems. The substrate is not limited to 2 -- it can allocate as many non-interfering orthogonal channels as its content genuinely separates into, each running its own independent ~F=3-4 resonator. This is flagged, per calibration discipline, as an ENGINEERING extrapolation with no direct literature precedent (no paper tests "N decoupled VSA channels" against Cowan's number) -- promising, cheap to test, but unverified.

P_deflated (novel-synthesis substrate-mapping claims, capped per lit-scan calibration): **0.42** for the mechanism mapping; **0.30** for the multiple-decoupled-foci lever specifically (weaker precedent, more extrapolative).

## (a) What the focus limit really is, and why

### The plain-English version

Picture a small whiteboard where you can write down 3-4 "who owns what" pairs -- like "Alice owns the red hat," "Bob owns the blue coat." You have PLENTY of physical whiteboard space (you could write 50 pairs). The problem isn't space. The problem is that once you've got more than about 4 pairs up there, when you look back at "the red hat," you start to lose track of whether it goes with Alice or with someone else -- the pairings start to blur into each other. That is the actual failure mode: not "ran out of room," but "who-goes-with-what got confused." Psychologists call this a BINDING problem, and the leading account (Oberauer's interference model, 2016/2017) shows this directly: memory gets worse faster when the held items are SIMILAR to each other (more confusable) than when they're all different -- if it were a fixed-slot capacity problem, similarity shouldn't matter, but it does, a lot. The direct evidence that the failure is misbinding (not forgetting) comes from "swap errors": when people report the wrong pairing under memory load, they usually still remember A FEATURE and AN OBJECT -- they've just crossed the wires (Bays et al.'s swap-error models; Oberauer 2019 shows binding memory degrades with load while plain item memory is much more robust).

### Three analogies (own synthesis, illustrative not literature-sourced)

1. **Overlapping radio stations.** With 3-4 well-separated stations you hear each clearly. Cram in more on the same dial and you don't run out of "airtime" -- you get static, because the signals start to bleed into each other. That's crosstalk/interference, not exhausted space.
2. **Name tags at a crowded party.** With a few people, you know who's who. Add a dozen more and you start attaching the wrong name to the wrong face -- you haven't forgotten any names, you've mispaired them.
3. **A whiteboard with too many similar arrows.** The ink hasn't run out; the labels near each other start getting misread as pointing to the wrong box.

### The proposed neural clock: theta-gamma phase coding

The classic mechanistic proposal (Lisman & Idiart 1995, *Science*; extended Lisman & Jensen 2013, *Neuron*) is that each held item is a burst of neural firing riding on its own "time slot" -- a fast gamma-frequency cycle (~30-60 Hz) -- and several of these gamma cycles nest inside one slower theta-frequency cycle (~4-8 Hz), like several short songs playing back-to-back within one longer verse. The NUMBER of gamma slots that fit inside one theta cycle sets the item ceiling, and that ratio lands around 4-7. This is real and has real supporting evidence -- people whose brains show a stronger theta-gamma coupling measurably hold more items (a genuine individual-differences correlation, several independent studies). But it has been refined, not overturned: a widely-cited update (Roux & Uhlhaas 2014) reassigns the roles -- theta seems to set the ORDER items come in, gamma supports keeping each one alive, and a separate frequency band (alpha) actively suppresses irrelevant clutter. So the "4-7 slots on a clock" picture is directionally right and empirically grounded, but the modern view is less "a fixed number of time-slots" and more "a layered rhythm that organizes and protects a small set of simultaneously active representations from interfering with each other" -- which is the same interference-based story as above, just with a proposed clock underneath it.

**Capacity vs. interference -- explicitly answered:** the evidence favors INTERFERENCE (confusability-dependent, misbinding-producing), not a hard slot-count. You can't "just hold more" because more co-active bound items means more mutual similarity-based interference and more opportunities for the wrong feature to get glued to the wrong object -- this gets WORSE, not just "full," as you add items.

### The resonator/VSA-side mechanism (independent literature)

The primary source for the substrate-relevant version of this (Frady, Kent, Olshausen & Sommer, "Resonator Networks" parts 1 & 2, *Neural Computation* 32(12), 2020) empirically finds that a resonator's ability to jointly factorize (unbind + identify) F simultaneous factors PEAKS around F=3-4 and falls off for F=2 (too few factors, unwieldy per-factor codebooks) and for F>=5 (a genuine peaked, non-monotonic curve, not a smooth tradeoff) -- and this is orthogonal to how the paper's "operational capacity" (a DIFFERENT number, how large the overall search space can be, which DOES scale with N) behaves. This confirms, from the ML/engineering side independently of the biology side, that "how much you can store" (N-dependent, a superposition/crosstalk-noise problem, per Plate 1995's HRR capacity formulas and Kanerva's sparse-coding capacity arguments) and "how many things you can jointly resolve in one query" (largely N-INDEPENDENT in the tested regime, a combinatorial spurious-fixed-point problem) are genuinely different mechanisms in the published literature -- not just an analogy invented for this project. No paper was found that explicitly connects the resonator F=3-4 finding to Cowan's psychological ~4 number; that cross-domain match is flagged as this drill's own (striking, but uncited) synthesis.

## (b) Ranked functional ways to raise the focus limit (with downsides)

Ranked by (transferable evidence strength) x (cheapness) x (how well the downside is avoided):

**1. Hierarchical / sequential factorization (chunk, then recurse).** Resolve a small group of factors (<=4), bind the result into a single placeholder, then resolve the NEXT group of factors against that placeholder, and so on. Brain analog: Miller's chunking + Gobet's template theory (an expert's single WM "slot" points to a whole pre-structured sub-object). Engineering analog: literature explicitly describes "Hierarchical Resonator Networks" doing exactly this staged factorization (e.g. resolving translation, then rotation/scale, as separate stages rather than one giant joint search). **Downside:** each stage adds a real decode step (latency) and each level compounds cleanup noise -- both the brain's evidence (Yngve's depth hypothesis; Christiansen & Chater's "Now-or-Never" chunk-and-pass account) and the resonator literature converge on the same qualitative shape: benefits are real for ~2-3 nested levels, then error compounding dominates. It also requires the factor GROUPING to be sensible (a schema/template that groups the right sub-factors together) -- chunking that groups arbitrarily doesn't help, exactly mirroring the human finding that chess-expert chunking evaporates on random (non-schema-matching) board positions.

**2. Multiple decoupled parallel foci (new lever from this drill).** Run separate, mutually non-interfering resonator instances on content that's been correctly routed into orthogonal channels -- e.g. one channel for role-structure, one for entity-identity, one for temporal/ordering facts -- each independently running its own ~F=3-4. Brain analog: Baddeley's dissociation between the phonological loop (verbal) and visuospatial sketchpad -- dual-task studies show concurrent verbal+verbal or spatial+spatial tasks interfere heavily, but verbal+spatial interferes much less, because they're substantially separate resource pools. **Downside:** the brain only ever built 2 of these (verbal, spatial) -- evidence for a 3rd truly independent channel is weak/contested (Fougnie & Marois show cross-modal storage still draws on some shared central-executive/attentional resource). The lever ONLY helps for content that genuinely separates a priori; if two channels' contents need to be jointly reasoned about later, you're back to paying the full joint-factor cost across both (no free lunch on cross-channel binding), and a ROUTING/allocation error becomes a new failure mode one level up (misrouted content creates cross-channel interference exactly like the binding problem it was meant to avoid).

**3. Exact external paging / offloading (keep only <=4 "in focus," park everything else verbatim).** Brain analog: the extended-mind / offloading literature (Clark & Chalmers 1998; Hutchins' distributed cognition) -- experts routinely offload to a reliable external scaffold (checklists, mise en place, notes) rather than holding everything internally. **Downside for the brain:** this only works if the external store is trustworthy and available, and reading/writing it costs real time (a context-switch overhead) -- Clark & Chalmers' own criteria require reliability and easy access, and if the environment is unstable the offload fails outright with no graceful fallback. **This is the one lever where the substrate's version of the downside is nearly eliminated**: an exact, addressable external store (unlike a notebook or a shaky memory palace) has no reliability problem and near-zero effective "context-switch" cost if the paging interface is cheap (already the substrate's Frontier-2 argument from the 07-16 note).

**4. Fast serial swapping through a larger activated set.** Keep a bigger pool of items "warm" and cycle attention/re-decode through different <=4-sized subsets over time, rather than trying to hold everything jointly at once. Brain analog: Barrouillet & Camos's Time-Based Resource-Sharing model (maintenance requires periodic attentional refresh, which competes with active processing for the same resource). **Downside:** switching has a measurable, persistent cost (Monsell 2003's task-switching review: reaction-time/error costs after a switch are only reduced ~50% even with generous preparation time -- a "residual cost" that never fully disappears), and if refresh can't keep pace with decay, items are simply lost. **Substrate-specific mitigation:** because the substrate can CACHE a previously-resolved factorization exactly (no biological decay to race against), re-visiting a previously-decoded subset should be far cheaper than a fresh resonator decode -- this is the other place the human downside can be substantially, not just partially, avoided (see Prediction 4 below; unverified until tested).

**5. Sparse / decorrelated codes -- a genuine capacity fix, but for the WRONG axis if used to target focus.** Sparse coding and pattern-decorrelation (SDM-style, Kanerva) measurably reduce superposition crosstalk and raise how much can be STORED and later cleanly retrieved (already validated on this substrate: decorrelation recovers ~85x absolute capacity on the bundle/storage axis, per prior work). **This is flagged here specifically as a common conflation to avoid**: the resonator literature treats storage capacity and simultaneous-factor capacity as different mechanisms with no cross-reference found connecting them; sparse/decorrelated coding is the right fix for "how much can I hold," not (per current evidence) for "how many things can I jointly reason over in one step." Using it as a proposed fix for the FOCUS ceiling specifically would be applying the wrong lever to the wrong axis -- worth testing explicitly (Prediction 3) rather than assumed.

**What does NOT work -- naive over-stuffing.** Just trying to hold more raw bound items without any of the above produces two documented failure modes simultaneously, not one: graceful precision loss (continuous-resource models, Bays & Husain 2008; Ma, Husain & Bays 2014 -- each item gets a little blurrier) AND a rising rate of outright misbinding/swap errors (Bays et al. 2009) -- confusion and dilution both get worse together as load increases. There is no "it just gets a bit worse" ceiling-free zone; both effects show up together.

## (c) What the substrate can already do glass-box, and the recommendation

Already validated/construction-proof per current program state: hierarchical chunking (nested clause-into-filler encoding), exact external paging (Frontier-2 exact-record store), a situation-model-style overlay (CI-analog discourse tracking), and sparse/decorrelated coding (DG-analog pattern separation, 85x bundle-capacity recovery already banked). Lever 1 (hierarchical/sequential factorization) and lever 3 (exact paging) are therefore ALREADY substantially built; this drill's contribution is confirming, from an independent literature angle, that lever 1 is also the mechanism the field itself uses to functionally raise resonator factor counts (not just bundle/storage), and that lever 5 (sparse/decorrelated codes) should NOT be assumed to also fix the focus/F axis without a direct test (Prediction 3) -- it fixes a different, already-solved problem.

**Recommended #1 way to functionally raise the substrate's ~4 focus, right now:** extend the already-proven hierarchical/chunking machinery from "compresses more into storage" (its validated 07-16 use) to explicitly target the RESONATOR'S joint-factor count -- i.e., when a query would require jointly resolving more than ~4 factors, deliberately stage the factorization (resolve a natural sub-group of <=4, bind the result as one placeholder factor, resolve the remainder against it), rather than attempting one large joint resonator call. This reuses proven primitives, has direct literature precedent (Hierarchical Resonator Networks) and direct biological precedent (chunking/template theory), and is falsifiable cheaply (Prediction 1 below).

**Recommended #2 (new, higher-risk, higher-payoff if it lands):** build a small experiment testing whether the substrate can run genuinely-independent decoupled parallel foci (more than the brain's 2), since nothing in biology caps the substrate at exactly 2 channels the way evolution capped humans -- if content genuinely routes into non-overlapping subspaces, this could multiply total simultaneously-reasoned-over content without paying the interference cost the brain pays for a 3rd channel.

## Cheap decisive test

Reuse existing resonator/factorization harnesses (no new build required for a first pass): take a factorization task currently run at F=4 (at the known sweet spot) and re-run it at F=6 and F=8 under three conditions, on the SAME codebooks/data:
(i) **flat** -- attempt the full F-way joint factorization in one resonator call (expected to degrade sharply per the literature's peaked-capacity curve);
(ii) **hierarchical** -- split into 2 stages of <=4 factors each, binding the first stage's result as a placeholder factor for the second stage;
(iii) **decorrelated/sparse-only** -- flat joint call, but under the already-validated decorrelated/sparse coding regime, to test whether that alone shifts the F=3-4 peak (Prediction 3).

**HARD-PASS (hierarchy is the right lever for focus, not just storage):** (ii) recovers >=90% of the F=4 baseline's held-out accuracy at total F=6-8, while (i) drops sharply (matching the literature's peaked, non-monotonic capacity curve), and (iii) shows NO meaningful shift in the F=3-4 peak location (confirming the two-axis distinction).

**HARD-FAIL:** (ii) degrades as sharply as (i) at F=6-8 (hierarchy doesn't rescue joint-factor capacity, contradicting both the Hierarchical Resonator Network precedent and the chunking analogy) -- would mean the focus ceiling is a harder structural wall than chunking-style fixes can address, and the recommended #1 lever above should be deprioritized in favor of #2 (decoupled channels) or #3 (paging, which sidesteps focus by never requiring >4 factors jointly in the first place).

## Falsifiable predictions (HARD-PASS / HARD-FAIL)

**Prediction 1 -- hierarchical/sequential factorization raises effective F beyond 4 with the same brain-matched depth ceiling (~2-3 stages) seen elsewhere in this program.**
P estimate: **0.45** (deflated; strong biological AND engineering precedent for the mechanism, but the specific compounding-noise rate at this substrate's cleanup fidelity is unmeasured).
HARD-PASS: 2-stage hierarchical factorization (F_eff=6-8) achieves held-out accuracy within 10 points of a native F=4 single-stage baseline, with accuracy dropping to <=50% of the 2-stage result by a 3rd nesting stage (matching the brain's 2-3 depth wall already found elsewhere in this program).
HARD-FAIL: 2-stage hierarchical factorization is statistically indistinguishable from attempting the full F=6-8 joint factorization directly (no benefit from staging) -- would mean the resonator's spurious-fixed-point problem is not rescued by hierarchy the way chunking rescues bundle/storage capacity.

**Prediction 2 -- multiple decoupled parallel foci scale total simultaneously-resolved factors roughly linearly with channel count, PROVIDED content is correctly pre-routed.**
P estimate: **0.30** (deflated; no direct literature precedent for this specific engineering claim -- the brain evidence only establishes 2 channels exist and interfere weakly with each other, not that N channels would remain independent).
HARD-PASS: 2 independent resonator channels operating on orthogonal/pre-separated subspaces each maintain within 5% of their solo-channel F=4 accuracy when run concurrently.
HARD-FAIL: per-channel accuracy degrades by >=15% relative when a second channel is made concurrently active -- would mean channels are not actually resource-independent in this implementation (some shared dimension/resource is bleeding across them), and the lever requires literally separate, non-shared N-allocations (expensive) rather than shared-space orthogonal coding (cheap) to work at all.

**Prediction 3 -- sparse/decorrelated coding does NOT shift the resonator's F=3-4 joint-factor sweet spot, confirming storage-capacity and focus-capacity are independent axes.**
P estimate: **0.40** (deflated; directly supported by the literature finding no cross-reference between these two capacity concepts, but this substrate's specific decorrelation implementation has not been tested against F directly).
HARD-PASS: F_max-accuracy peak location is unchanged (within +/-0.5 factor) between the substrate's dense/correlated and sparse/decorrelated coding regimes, even though the bundle/storage ceiling differs by the already-measured ~85x between these regimes.
HARD-FAIL: sparse/decorrelated coding ALSO measurably raises F_max (e.g. peak moves from F=4 to F=6) -- this would be a genuinely useful positive surprise (a single fix improving both axes) and should immediately update the #1 recommendation above.

**Prediction 4 -- exact caching of previously-resolved factorizations makes "swapping" among activated items far cheaper for the substrate than the brain's Monsell-style residual switch cost.**
P estimate: **0.50** (capped at the novel-synthesis ceiling; the mechanism argument -- exact deterministic caching vs. biological decay-under-time-pressure -- is clean, but untested for THIS substrate's specific caching/addressing implementation).
HARD-PASS: re-accessing a previously-resolved factor subset via cache lookup is >=10x faster than a fresh resonator decode of the same subset, with zero accuracy loss.
HARD-FAIL: cache-based re-access shows accuracy loss or a cost comparable to a fresh decode -- would mean the brain's switch-cost downside transfers largely unchanged to this substrate, and "swap through a larger activated set" should not be marketed as a cheap lever here.

## Substrate-product implications

- Do not market "bigger N" as a fix for reasoning/focus capacity -- N raises storage, not joint-reasoning breadth; conflating the two would overclaim (directly analogous to the caution already logged against conflating N/16-32 with F=3-4 in the 07-16 note, now literature-confirmed as a real distinction in the field, not just an internal one).
- The nearest-term, cheapest lever is extending already-built hierarchical chunking machinery to explicitly target resonator joint-factor count (not just bundle storage) -- this reuses proven code and has both biological and engineering precedent.
- If Prediction 2 (multiple decoupled foci) HARD-PASSes, the product story becomes: "reasons over more independent threads at once than a human can, because it isn't limited to evolution's 2 sensory-modality channels" -- an honest, brain-exceeding claim, but ONLY if the routing/allocation mechanism is also validated (a misrouted-content failure mode is real and must be tested, not assumed away).
- If Prediction 4 lands, market caching/paging-based "swap" as a genuine advantage over the brain's decay-bound refresh -- this is a retrieval-precision/engineering claim (does the cache correctly restore the exact prior state), not a capacity claim, and should be reported as such.
- Explicitly do NOT sell sparse/decorrelated coding as a fix for the focus/reasoning-breadth ceiling (Prediction 3 test needed first) -- it is already a validated fix for a different, already-solved problem (bundle/storage crosstalk), and misapplying it here would be citing a real result for the wrong claim.
