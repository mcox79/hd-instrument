## Q1 — WHERE does an explicit WM/situation-model beat whole-sequence attention? (non-redundancy regimes)
CITED@ (Cowan 2001 BBS ~4-chunk focus-of-attention; Hasson 2008 J.Neurosci temporal-receptive-window hierarchy; Liu 2023 TACL "lost in the middle" + BABILong/NoLiMa long-context degradation; Graves DNC/NTM, Dai Transformer-XL, Bulatov RMT, Wu Memorizing-Transformers, Gu/Dao Mamba). Explicit state is NON-redundant ONLY in:
1. **Stream length exceeds the attention/compute budget** (unbounded / tens-of-thousands+ tokens; degradation empirically well before nominal limits).
2. **ONLINE / incremental — can't-see-the-future** — ORTHOGONAL TO LENGTH: even a SHORT passage, if the system must commit before later input arrives (causal/streaming; human real-time reading, garden-path effects), structurally requires maintained state. (CITED@ causal-masking-forces-commitment; Merkx&Frank 2020.)
3. **Concurrent hold-AND-manipulate under the ~4-chunk cap** (Cowan) — operate on multiple items at once, not passive re-scan.
**Where state adds NOTHING:** short, fully-visible, OFFLINE passages needing only lookup/random-access — whole-sequence attention wins (= our current MES; explains reservoir 0.80). 
**OUR REACHABLE, brain-faithful regime = #2 (online/incremental) + #3 (content-selective gating under a slot cap)** — achievable in-window (no giant sequences needed), brain-faithful, and it makes the WM genuinely non-redundant.

## Q2a — Contextual-stream fix (repair the clause-blind bug; keep the 2-stage architecture)
CITED@ (Kintsch 1988 Construction-Integration cycles; van den Broek Landscape/Resonance; Zacks 2007 EST continuously-running event model; Henaff 2017 Recurrent Entity Networks; chunk-wise streaming-ASR degradation without cross-chunk context). UNANIMOUS: the human system NEVER encodes a unit in isolation then contextualizes later — contextualization IS representation-formation. **DESIGN (fixes 0.50->~0.80 loss, preserves the WM's two-stage value):**
1. ONE shared encoder pass over the WHOLE passage (full attention if available-at-once; causal/prefix if incremental) -> a contextualized hidden-state sequence [B,L,d].
2. SLICE that sequence at clause/event boundaries (boundary-token or masked-mean per span) -> per-clause reps that EACH attended to the others (cross-clause order + coref survive in the slice). This is the ONE-LINE fix vs the failed pipeline (which encoded each clause independently, blind to the rest).
3. Feed slices SEQUENTIALLY into the entity/slot WM (EntNet-style gated memory blocks / PBWM PE-gated write / HRR role-binding) — the update at step N sees a rep already carrying clauses 1..N-1; the WM's own recurrence supplies further integration.

## Q2b — Reservoir-FAILING task = "Selective Overwrite Recall" (the mandatory can-fail; MES is reservoir-decodable so it can't prove the WM)
CITED@ (Gu/Dao 2023 Mamba Selective-Copying: non-selective S4 ~57% vs selective S6 ~99.8%; Olsson 2022 induction-heads = ACQUIRED not at-init; Saxe 2011 random-weights decode positional/frequency features but not content-conditioned routing; bAbI multi-supporting-fact ~20% naive vs ~90% trained). BOUNDARY: reservoir-decodable = fixed positional/order features suffice; reservoir-FAILING = requires CONTENT-DEPENDENT gating (write/overwrite/ignore based on WHICH token arrived, not WHERE) — must be LEARNED.
**Construction:** a stream of N `(slot_id, filler)` assignment events interleaved with D distractor slot-touches (D >> #slots, e.g. 6 target slots among 30+ distractor touches). (i) RANDOMIZE per-example ordering/spacing so no fixed position predicts the binding token; (ii) multiple slots touched multiple times; (iii) query one slot_id at the end and require its MOST-RECENTLY-OVERWRITTEN filler (not the first) => requires OVERWRITE-WITH-SUPPRESSION of earlier writes — a passive reservoir superimposes/averages all writes and CANNOT select the last; a trained content-gated write CAN. (iv) high distractor count so no fixed attention window covers all relevant touches.
**Can-fail controls + bar:** random-init encoder (frozen) + trained probe MUST land near chance (chance = 1/|filler vocab|); a trained stateful/gated WM should clear >=~70-80% (>=2-3x chance). That gap CERTIFIES the WM/gating does real work (not reservoir). Known-reader headroom: Mamba/S6-class selective mechanism ~99.8% establishes the ceiling exists.

## THE NEXT BUILD (single, coherent, evidence-grounded, brain-faithful)
**Task = Selective-Overwrite-Recall (reservoir-failing).** **Architecture = shared contextual encoder pass -> slice by event -> sequential content-gated entity WM (PBWM/EntNet-style overwrite-with-suppression + HRR role-binding).** **Measurement = the hardened trustworthy gate, with the random-init-MUST-fail control as the primary can-fail (margin over random-init distribution + significance).** Run on our from-scratch encoder (adequate). This tests LEARNED comprehension via the exact WM capability (content-selective gated overwrite) on a task the reservoir provably fails — the first construction that can actually PROVE the WM.

## HONEST VERDICT (adversarial, as asked)
The explicit WM IS worth building — BUT its value is PROVABLE ONLY on a reservoir-failing (content-gating / online) task, NOT on offline short-passage MES (where whole-sequence attention already wins, reservoir 0.80). This is not a retreat: it re-frames the capability to where the brain's WM actually earns its keep (Cowan manipulate-under-cap; online commitment; PBWM content-selective gating) and gives the first can-fail that separates learned maintenance from structure-alone. If a properly-built content-gated WM STILL can't beat random-init on Selective-Overwrite-Recall, THAT is the honest refutation of the WM bet for our reachable regime — and it is a clean, decisive test.
