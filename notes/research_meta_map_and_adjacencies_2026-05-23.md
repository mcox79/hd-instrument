## Part 2 -- Fruit-bearing pattern analysis (what works)

Cross-cutting analysis of the 16 load-bearing + 15 strong rows vs the 28 closed rows yields the following meta-patterns:

### Pattern 1 -- METRIC re-axiomatization (Bayesian / info-theoretic bounds) is the highest-leverage cheap intervention

Sagawa-Ueda noise-corrected bound, Polyak-Juditsky iterate averaging, Conformal prediction wrapper, R11 rank-vs-location diagnosis -- all of these are **changes to the audit metric / readout calibration**, not changes to the substrate. Each one either rescued a noise envelope (Sagawa-Ueda flipped v157→v158 Cap 1 narrative), demonstrated a Gap closure (Conformal Gap C), or shipped as the substrate's calibration solution (R11→Bet G TEMPSCALE). Cost: hours of theory + zero hardware. This is the dominant "win shape" of the project.

### Pattern 2 -- ENGINEERING-borrowed readout primitives (AMP family / EP / smoothers) are load-bearing capability anchors

AMP/VAMP (cycle 127 multi-hop rescue), Backward-smoother EP (Bet Z.4 d=500 universal), Bayes-AMP for cued holistic readout -- all of these came from engineering / signal-processing literature, not from spin-glass / pure-physics literature. Drift-diffusion ≡ BP theorem provides the umbrella that ties them all together. Substrate IS a posterior-inference primitive; the substrate-novel framing was applying it as memory primitive rather than as channel decoder.

### Pattern 3 -- Information-theoretic FLUCTUATION-theorem framings ARE the commercial-wedge drivers

Crooks FT drove Cap 1 (verifiable forensic erase) -- the strongest substrate-product capability. Sagawa-Ueda noise-correction widened Cap 1's envelope. Hatano-Sasa NESS-Crooks anchors Cap 3 streaming. Landauer erasure is implicit in the entropy-production-as-erase-certificate framing. **None of the closed pure-physics frameworks (Connes-Kreimer / T-T / Steenrod / Drinfeld) produced a commercial wedge; every commercial wedge produced so far has come from a non-equilibrium thermodynamics + Markov-chain bound.**

### Pattern 4 -- FINITE-DIMENSIONAL classical RS-phase frameworks are durable; INFINITE-DIM / quantum / continuous frameworks trivialize

Three Wave-class advanced-math frameworks (Connes-Kreimer / Tomita-Takesaki / Steenrod) were all honest-closed at cycles 26-28 because the substrate is finite-dim discrete and the machinery requires infinite-dim continuous structure. Drinfeld closed for the same reason. **Only Wave 15 free probability (Bet I ✅) survived because it explicitly assumes finite-dim sample-covariance.** The lesson: pull toward Marchenko-Pastur / free-probability / replica-symmetric / cavity / message-passing / coding-theory frameworks; deflate any framework that requires continuous / quantum / spatial / unbounded structure by 0.40 before drilling.

### Pattern 5 -- ADJACENT engineering methods (per [[feedback-dont-dismiss-adjacent-methods]]) dominate the load-bearing tier when actually invoked

User-driven push to drill AMP (after I'd dismissed it as "adjacent but not where this lives") produced the single most substrate-novel finding of the RS-phase capacity arc. Conformal prediction (Vovk-Shafer; Venn-Abers) was the same shape: adjacent to calibration, dispatched, became Gap C load-bearing. Sagawa-Ueda was adjacent to Crooks; dispatched, became v158 envelope-widening. **The adjacency-principle is empirically validated as the dominant fruit-source; dismissing without dispatch is the dominant failure mode.**

### Pattern 6 -- MECHANISM-specific quantitative predictions in uncharted regime have ~80% refutation rate

Five multi-hop mechanism diagnosis attempts (eigenvalue near-degeneracy / Hubness×DPI / BCJR / cluster trapping / retraction) plus 2 K-resonance attempts (Arnold tongue / Kerdock algebraic) plus the RM(1,16) 25% prediction = 7 of 9 specific quantitative diagnoses REFUTED. Only the retraction framework (5th multi-hop attempt) and "marginal stability" hypothesis (Q3) survived as durable framings. **Mechanism-specific quantitative predictions in regimes without published precedent should be deflated by 0.20 baseline; structural framings (forward-lossy + reverse-invertible; retraction; non-self-averaging) are more durable than specific numerical predictions.**

### Pattern 7 -- OBSERVABILITY probes converge to the same Parisi q(x) at different angles

The 4-family observability deep-drill (Parisi P(q) + C_ij eigenvalues + chi_3 + 1/f + FDT-violation + TAP Σ(f) + Fisher κ(F)) -- ALL FOUR families encode the same Parisi q(x) function from different angles. The cap_map row that landed (observability_suite_v1+v2) used the 3 cheapest probes (P(q) + chi_4 + Kovacs) and gated on **cross-family consistency**, not single-probe pass. This is the meta-pattern: when 2+ independent angles converge on the same quantity, that quantity is the right anchor.

### Summary (bulleted) -- the "what works" meta-pattern

- Re-axiomatize the audit metric (cheap, theorem-anchored) before re-engineering the substrate
- Adjacent engineering readouts (AMP/VAMP/EP/conformal) > pure-physics frameworks
- Non-equilibrium thermodynamics + Markov-chain bounds = commercial-wedge drivers
- Finite-dim classical RS frameworks (free probability, replica, cavity, M-P) are durable; deflate quantum / infinite-dim / continuous by 0.40
- Dispatch any mathematically-adjacent method; dismissing without lit-scan is the dominant failure mode
- Specific quantitative mechanism predictions in uncharted regimes refute ~80% of the time; structural framings dominate the durable tier
- Cross-family consistency is the right gate, not single-probe pass
