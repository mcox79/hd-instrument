## 3. FLOOR DETECTION BY SHAPE -- and what the shape pass recovered over vocabulary

Detection is **structural first, vocabulary second**, per the standing correction that `scramble`
appears zero times in June while 33 of 60 June cells have a genuine control arm.

- **SHAPE**: any dict with >= 2 numeric sibling values containing a reference/control/chance arm
  key (`_raw`, `_base`, `hebb`, `argmax`, `plain`, `single`, `frozen`, `chance`, `iid`, `oracle`,
  `flat`, `freq`, `memo`, `null`, `no_*`, `lesion`, ...), or an `arms` / `by_arm` / `per_arm`
  container, or an arm=value table inside `verdict_msg` prose.
- **VOCABULARY**: a control word in a **KEY NAME**. Scoped to key names deliberately: run over the
  raw file text the vocabulary test fires on **100% of cells** and is worthless as a discriminator.

Measured over the **324 brain-family stems carrying a PASS verdict, unfiltered by any prior floor
flag**:

| detector | cells it finds a floor in |
|---|---|
| a `scramble`-keyed test alone | **25 / 324 (7.7%)** |
| vocabulary (any control word in a key name) | 228 |
| **+ SHAPE (multi-arm dict / arm container)** | **+21** |
| **+ PROSE (arm table inside `verdict_msg`)** | **+5** |
| total floored | **254 / 324** |
| genuinely no floor of any kind | 70 |

**The structural pass recovered 26 cells that a lexical pass misses -- and a `scramble`-keyed test
would have declared 299 of 324 unfloored when 229 of those have a real control.** Recovered
examples, with the arm names that carry the floor and contain no control word:
`exp_substrate_iterative_cleanup_cue_clamped_v1` (`acc_single_step`),
`exp_a1_hebbian_vs_gradient_identity_v1` (`hebb_acc`),
`exp_substrate_decomposition_resonator_alpha05_cpu_v1` (`precision1_plain`),
`exp_sparse_hopfield_v1` (`dense`), `exp_substrate_multimodal_binding_text_kg_v1`
(`single_modality`), `exp_markov_binding_sharpening_cpu_v1` (`plain`),
`exp_cortex_hippo_handoff_sparse_DG_dense_cortex_v1` (PROSE `NO_REPLAY`),
`exp_cls_distributed_protection_heldout_replay_v1` (`arm_digests` container).

Floor column values: `A` = shape AND a control word; `ARM` = multi-arm shape whose arm names carry
no control word; `PROSE` = floor lives only inside `verdict_msg`; `NO FLOOR` = none found;
`UNPINNED` = no directory resolved so nothing was opened. **An unfloored or unopened pass is not
evidence and its row carries **FOUND**, never `VERIFIED`.**

Totals: tier 1 = 163 `A`, 1 `ARM`, 2 `NO FLOOR`, 5 `UNPINNED`. Tier 2 = 212 `A`, 4 `ARM`,
1 `PROSE`, 15 `NO FLOOR`.

**Honest limit, unchanged from S1.** Even key-scoped, vocabulary detection over-fires: a cell that
merely names a `baseline` key scores `A`. The floor column says a control arm is PRESENT in the
shape, not that it was well chosen or that the margin over it was large. Only the cells hand-read
in secs 4-6 have their actual arm values quoted; the rest are machine-read and are weaker evidence.
