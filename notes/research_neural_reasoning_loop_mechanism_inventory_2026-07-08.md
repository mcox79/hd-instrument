# Research: neural mechanism inventory for a glass-box reasoning loop (2026-07-08)

Deep neuroscience drill (5 parallel Sonnet lit-scans, HIGH effort) feeding a Director-authored architecture design for the substrate's glass-box reasoning loop: encoder + attention-routing gate + BG-style value-gate + multi-hop composition + self-manager, composed into a loop that reasons over stored knowledge with self-audit at each step.

**Framing discipline (per USER directive):** brain mechanism leads throughout; ML/LLM framings (chain-of-thought, RAG, agent tool-use, option-critic HRL) are treated as weak secondary references only, and are explicitly flagged where the brain literature diverges from them. No substrate cell designs are proposed here — this is the mechanism inventory + minimal-loop synthesis; cell design is Director's next step.

## HEADLINE

Five independent lit-scans converge on a single circuit-level picture that is **not** an ML System-2/agent-loop analog: a rostro-caudal cascade of PFC "stripes," each protected by its own cortico-BG-thalamic Go/NoGo gate (not one central controller), issues content-specifying biasing signals that steer hippocampal CA3 pattern completion (routed indirectly via entorhinal cortex / nucleus reuniens, never a direct PFC->hippocampus link); the hippocampus answers with both a completed pattern AND a match/mismatch signal that is the actual "continue vs re-query" evaluator; working memory itself is bimodal (active attractor for the one prioritized item, activity-silent synaptic trace for everything else held in reserve); and multi-hop composition over the stored relational structure is done **offline, before commitment**, by hippocampal replay running compressed forward/backward sequence generation and Bellman-style backward value propagation over the same CA3 weights used for completion. Critically for this substrate: the subgoal-hierarchy literature has moved away from "learn a small fixed library of discrete options selected by a meta-controller" (Botvinick et al. 2009 is the citable pro-options account, but it is now a minority position) toward continuously-parameterized, compositional task geometry (Yang et al. 2019; Bernardi et al. 2020) that is assembled fresh per task and gated by degree, not selected from a menu. That is a structurally different claim than the option-critic framing that already HARD_FAILed on this substrate across 4 mechanism classes — the brain's alternative is not "more options," it is "no discrete option library at all."

Per lit-scan calibration penalty: all P-estimates below are deflated 0.15-0.25 from what a single-thread lit-scan would naively report, because every one of these five circuit-level claims rests on a mix of computational modeling + indirect (fMRI functional-connectivity, EEG/MEG decoding, lesion, closed-loop-disruption) evidence rather than direct multi-site causal recording of the whole loop operating in real time. No thread here has that gold-standard evidence; treat this note as a mechanism inventory with real but bounded confidence, not settled fact.

## Thread-by-thread mechanism inventory

**1. PFC->hippocampus retrieval-in-service-of-inference.** Preston & Eichenbaum's model (2013) casts (v)mPFC not as a retriever but as a **bias signal on the hippocampal completion gradient**: it reshapes which CA3 attractor gets reached (boost target-congruent units, diffusely suppress competitors) rather than selecting cue features. Anatomically the bias signal is NOT direct — there is no PFC->hippocampus projection; hippocampus projects to PFC directly via CA1/subiculum, but PFC's return influence is routed indirectly via entorhinal cortex and the thalamic nucleus reuniens. vmPFC does fast, low-effort schema-consistency evaluation (rapid schema-linked completion, trading fidelity for generalization — Van Kesteren, Gilboa lines of work); dlPFC/VLPFC does effortful, constructed retrieval when no schema fits, split further into anterior VLPFC (cue-specification / controlled access, Badre & Wagner 2007) and mid-VLPFC (post-retrieval competitive selection among active representations). The loop-closing "stop vs re-query" signal is proposed to be a hippocampal/entorhinal **match-mismatch** response (novelty/expectancy-violation, Kumaran & Maguire) propagating back to PFC monitoring circuits — this is the single weakest-evidenced link in the whole inventory: no study shows one unambiguous real-time "stop" signal; it is stitched together from separate mismatch-detection, confidence-connectivity, and monitoring-lesion literatures. P(this specific loop, as stated, is the actual circuit) ~0.35 deflated.

**2. Working memory: attractor vs activity-silent.** Goldman-Rakic delay cells sustain location-tuned firing through a blank delay via local recurrent excitation (NMDA-dependent slow time constant) balanced by surround inhibition. Wang (2001)/Compte et al. formalize this as a bump attractor: stable, but with real failure modes — bump drift (no restoring force along a ring, so noise causes precision loss over time), bump-bump interference limiting capacity to ~3-4 items, and difficulty encoding a new item while holding an old one because both compete for the same shared inhibitory budget. This is a genuinely hard problem for a homogeneous attractor circuit, not an incidental detail. The competing account (Mongillo, Barak & Tsodyks 2008) stores content in short-term synaptic facilitation with NO sustained firing required — spiking loads a calcium-mediated facilitation trace that decays over seconds; a nonspecific "ping" input reactivates whichever assembly currently holds elevated release probability. Wolff et al. (2017) and Rose et al. (2016, TMS reactivation of latent items) support this being real, though a direct counter-finding (PLOS Biology, "Pinging the brain... reveals electrically active, not activity-silent, working memories") argues some "silent" periods still carry low-amplitude persistent firing below typical decoding thresholds — this is an active, unresolved dispute. Best-supported synthesis: the two are complementary, not exclusive — the one prioritized/attended item runs as an active attractor; everything else retained-but-backgrounded is carried activity-silently, with attention switching format (LaRocque/Lewis-Peacock; Rose et al. 2016). P(complementary two-format account) ~0.45 deflated; P(pure single-mechanism account, either direction) ~0.15.

**3. Cortico-BG-thalamic gating of WHAT ENTERS working memory.** Loop topology (Alexander, DeLong & Strick 1986): cortex -> striatum -> pallidum/SNr -> thalamus -> cortex, replicated in parallel for motor, oculomotor, dlPFC, orbitofrontal circuits, each with its own thalamic relay. Direct ("Go", D1) pathway disinhibits thalamus (gate opens, cortical loop updates); indirect ("NoGo", D2) pathway increases thalamic inhibition (gate closes, current content protected). PBWM (O'Reilly & Frank 2006) applies this per independent PFC "stripe": Go lets superficial-layer content overwrite the deep-layer sustained-firing store for that stripe; NoGo protects deep-layer content from being overwritten by whatever else is on the superficial layer. Per-stripe independence is the proposed solution to the stability-plasticity dilemma — some items update while others stay protected, same instant. The gating decision is **value-based**: Go vs NoGo striatal activity is a learned expected-value comparison, trained by dopaminergic reward-prediction-error (a temporal-credit-assignment problem PBWM addresses with an adaptive-critic-like signal), not a raw salience/novelty trigger (though novelty can indirectly shape the learned value). Chatham & Badre (2015) argue input-gating (what gets encoded) and output-gating (what already-held content drives behavior) are **separable gates with partially separable loci** — this maps directly onto the substrate's existing v8 attention-routing gate (input side) vs cfrpe BG value-gate (output/action side), which prior research already flagged as never-yet-composed. Recent optogenetic/thalamic work (Halassa lab, mediodorsal thalamus supporting flexible switching between cortical representations) supports the general gating motif and load-dependent D1/D2 involvement, but stops short of confirming the exact per-stripe overwrite mechanism at causal circuit resolution. P(PBWM's per-stripe value-gated overwrite account, as the operative WM-gating mechanism) ~0.40 deflated.

**4. Hippocampal replay as offline multi-hop inference.** A sharp-wave ripple (150-250Hz, CA1, driven by synchronous CA3 recurrent discharge) reactivates the place-cell sequence chain laid down in CA3 auto-associative weights, compressed ~10-20x, forward or reverse. Pfeiffer & Foster (2013) is the strongest single piece of evidence for this being prospective and decision-relevant: at a choice point, decoded sequences depict a full path to a remembered goal, including start-goal combinations never directly traversed together — meaning the hippocampus **composes** a route from independently-learned local segments before the animal commits to moving, and the composed sequence correlates with the path actually taken next. Mattar & Daw (2018) model replay content as a one-step Bellman backup applied to a stored transition, with replay priority = gain (how much would updating this transition change behavior) x need (how likely is this state to be visited soon) — this reproduces known replay-content biases (reward-location over-representation, reverse replay after reward, forward pre-run replay, shortcut replay) but the "value propagation" read is inferential, fit to firing statistics rather than directly observed as a value-update signal. Preplay (Dragoi & Tonegawa) — replay of never-experienced sequences from a pre-existing template repertoire, which would imply true compositional generation over untraversed relational structure — is heavily contested: Silva, Feng & Foster (2015), with larger cell populations, found pre-experience trajectory-like events at chance level, abolished by NMDA blockade during actual experience, arguing genuine sequence-coding is experience-dependent. Causal disruption evidence (Jadhav et al. 2012; Girardeau et al. 2009: closed-loop awake-SWR disruption impairs learning-dependent decision performance without touching place-field stability) is the strongest support that replay is doing real online decision-support work, not just consolidation. P(replay = literal offline multi-hop search substrate, path-composition claim) ~0.40 deflated; P(preplay specifically, i.e. compositional generation of wholly novel sequences) ~0.20, explicitly contested.

**5. PFC subgoaling — and the option-critic contrast that matters most here.** Badre & D'Esposito's rostro-caudal abstraction gradient (posterior = concrete motor selection, rostral = abstract/episodic rule selection) is implemented, per Koechlin's cascade model (2003, 2007, extended 2022), as a **cascade of top-down gain modulation into local winner-take-all competition** at each level — not literal nested subroutine calls. Badre & Frank (2012) give the corticostriatal mechanism: each abstraction level is an independent BG-gated PFC stripe (same PBWM Go/NoGo machinery from thread 3, reused recursively); a rostral loop holds a superordinate context in a protected, slower-updating store while gating input to a faster-updating caudal loop underneath it via a biasing (not literal call/return) connection. Subgoal-completion detection is best supported by **subgoal-scoped reward-prediction-error signals in mPFC** (Ribas-Fernandes et al.; distinct RPEs for subgoal-impediment vs subgoal-advancement, separate from the outer-goal RPE) and hierarchical error-representation models (Alexander & Brown's ACC "HER" model) — not a clean evidence-accumulation threshold-crossing; Koechlin's branching-task work (Charron & Koechlin 2010) shows frontopolar cortex holding a pending goal in a protected non-interfering state while a second task runs, then reactivating it, which is parallel-holding evidence rather than accumulator-based popping. This is the least-settled item in the whole inventory (P ~0.30 deflated on any single completion-detection mechanism).

**The option-critic contrast, stated directly per USER instruction:** Botvinick, Niv & Barto (2009) is a real, citable neuroscience proposal mapping options onto PFC (option-identifying populations + corticostriatal option-specific policies + anteriority = nesting depth) — so "brain does discrete options" is not a strawman, it existed as a serious hypothesis. But subsequent work has moved the field's center of mass away from it: Yang et al. (2019) show multitask-trained PFC-model networks develop **compositional** task representations letting novel tasks be assembled from recombined components of known tasks, not selected from a fixed library; Bernardi et al. (2020) show PFC/hippocampal ensembles encode task variables in a factorized, high-dimensional ("abstract but shattering") geometry supporting generalization via linear recombination, again inconsistent with a small discrete option set; Badre's own group (2010) shows frontal rule representations built compositionally from sub-rule components across the rostro-caudal axis rather than retrieved whole. The functional distinction that matters: an option-critic primitive needs (i) a fixed small discrete option inventory, (ii) each option bundled with its own policy AND its own learned termination function, (iii) discrete meta-selection. The brain-favored alternative needs a continuously-parameterized context vector built fresh per task, biasing lower-level competition by degree (not discrete gating of a stored sub-policy), with completion inferred from the RPE/mismatch signal in thread 5 rather than a per-option termination unit. **This is the single most decision-relevant finding for this substrate**: the prior option-critic HARD_FAIL was of the Botvinick-style discrete-inventory framing; the brain-favored continuous/compositional framing is a structurally different mechanism, not a retry of the same one — deflated P ~0.35 that a continuous/compositional gating primitive is meaningfully distinguishable in outcome from the already-failed discrete-option framing (i.e., real but not certain that this reopens a closed path; capped at 0.50 per novel-synthesis rule regardless).

## Minimal neurally-plausible reasoning loop (cross-thread synthesis)

Collapsing all five threads into one loop, by functional role:

- **Cue generator:** anterior VLPFC/dlPFC (thread 1) — constructs a content-specifying query, itself biased by whichever rostral-level subgoal context is currently held (thread 5's cascade). Not a fixed retrieval template; constructed per-query.
- **Storage/retrieval:** hippocampal CA3 autoassociative pattern completion (thread 1), reached only via an indirect route (entorhinal cortex / nucleus reuniens) — never a direct read of a PFC-held query into the hippocampal attractor.
- **Offline multi-hop composition (the "search before committing" stage):** hippocampal SWR replay (thread 4) — composes candidate multi-step paths over the same CA3 relational weights, prioritized by a gain x need schedule, before the cue-generator/evaluator loop above ever commits to an action. This is the piece with no direct ML analog worth trusting (it is not MCTS, not beam search over a token sequence — it's offline reactivation of the same associative weights used for single-step completion, run at compressed speed).
- **Gate (what enters/updates/persists in working memory):** cortico-BG-thalamic Go/NoGo loops, one per PFC "stripe" (thread 3), value-trained by dopaminergic RPE, with separate input-gate and output-gate loci (Chatham & Badre) — and reused recursively at each abstraction level for subgoal holding (thread 5).
- **Working memory holder:** bimodal (thread 2) — the one currently-prioritized item as an active PFC attractor (Goldman-Rakic/Wang/Compte), everything else retained-but-backgrounded as an activity-silent synaptic trace (Mongillo-Barak), with the BG gate arbitrating which format an item is in.
- **Evaluate-and-decide-to-continue:** hippocampal/entorhinal match-mismatch signal (thread 1) for "was this retrieval good enough," plus subgoal-scoped RPE / ACC hierarchical-error signals (thread 5) for "was this subgoal completed, pop the stack." These are two related but distinct evaluators — one gates re-querying within a step, the other gates popping between nested levels — and neither is a clean accumulator-threshold; both are mismatch/prediction-error style computations.

The structurally important departure from any ML agent-loop framing: there is no single central controller issuing a query, waiting, and deciding — it is a set of parallel, per-stripe, per-abstraction-level gated loops, each independently value-trained, with the "search" component (replay) happening offline over the same storage weights used for single-shot retrieval rather than as a separate planning module.

## Cheap decisive test (mechanism-inventory level, not a cell design)

Since cell design is out of scope here, the decisive test is at the level of "does the brain-favored distinction actually matter functionally," which Director can operationalize: on any substrate task requiring nested subgoal holding + completion detection, compare (a) a continuously-parameterized/compositional gating signal (built fresh per subgoal context, degree-biased) against (b) a fixed small discrete-option-inventory gating signal (the already-HARD_FAILed framing), matched for total learnable parameters and training budget.

**HARD-PASS threshold:** the compositional/continuous framing shows a statistically significant (paired, matched-seed) improvement in nested-subgoal task accuracy or in generalization to held-out subgoal combinations never seen during training — the latter being the compositional account's specific, falsifiable prediction (Yang et al./Bernardi et al.'s claim only has teeth if it predicts held-out recombination, not just in-distribution performance).
**HARD-FAIL threshold:** performance is statistically indistinguishable from the discrete-option baseline (already known to HARD_FAIL), OR held-out subgoal-combination generalization is at floor — either result means the brain-motivated continuous/compositional distinction is not functionally consequential for this substrate's failure mode, and the option-critic closure should be treated as closed for BOTH framings, not reopened.

## Substrate-product implications

- The existing v8 attention-routing gate (input-side) and cfrpe BG value-gate (output/action-side) composition, already flagged by prior research as the real gap, is directly supported here as biologically separable-but-parallel gates (Chatham & Badre) — this is now supported from two independent threads (this drill's thread 3, and the 2026-07-08 value-based-action-selection drill), raising confidence modestly.
- Any multi-hop/composition primitive should be designed as reactivation-over-stored-weights at compressed "replay speed," prioritized by a gain x need schedule, run BEFORE the gate commits — not as a separate discrete planning module bolted onto the retrieval path. This reframes multi-hop composition as "the same storage/retrieval primitive run offline, several times, prioritized," not a distinct architecture.
- Working memory holding should not be designed as a single homogeneous mechanism — a substrate primitive needs both an actively-maintained slot (for the one item currently in focus, subject to drift/capacity limits) and a passively-retained trace (for backgrounded items), with an explicit arbitration signal moving items between the two, rather than one uniform buffer.
- The subgoal-stack primitive should NOT be built as a discrete option library with per-option termination functions (that path is closed both by the substrate's own prior HARD_FAIL and, per this drill, by the field's own move away from that account) — it should be built as a continuously-parameterized context signal that biases lower-level competition by degree, with completion detected via a mismatch/prediction-error signal rather than a per-option termination unit.
