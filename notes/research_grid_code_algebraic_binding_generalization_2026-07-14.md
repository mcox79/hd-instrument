# Research: grid-code algebraic binding — closing the 0.11(learned)->1.0(hand-designed) conjunction gap

**Filed:** 2026-07-14 | **Dispatch:** direct topic statement (no routing file) | **Model:** Sonnet, 3 parallel lit-scan sub-agents (Sonnet) + this synthesis

## HEADLINE

The brain's grid/entorhinal code is NOT a single universal algebra copy-pasted onto every relation — it is a **shared factorization architecture** (structure-basis separated from content, instantiated as a compressed error-correcting modular/spectral code) that gets **re-derived per relation-class** from a **predictive learning signal** (successor representation = TD-learned eigenbasis of the relation's transition graph). This reframes our gap: we don't need to find "the one true VSA algebra" for arbitrary relations — we need the **predictive/spectral code-construction step** that the brain also has to run once per relation-class, then bind on top of it with the (already-proven) FHRR elementwise-product operator. Top-ranked fix: replace SGD-learned-from-task-loss entity codes with **Laplacian-eigenvector (successor-representation-style) codes** derived from the relation's own co-occurrence/transition structure, feed those into the UNCHANGED FHRR bind, and measure novel-combination accuracy.

## Cheap decisive test

On the existing R=(A+B) mod L conjunction task (the one that gives 1.0 with hand-designed FHRR phase codes and 0.11 with SGD-learned codes): **do not change the bind operator.** Instead:
1. Build the relation's transition/co-occurrence graph over the L residue values (edges = which (A,B) pairs were seen during training, or simply the cyclic adjacency structure if using the natural task graph).
2. Compute the graph Laplacian's low-frequency eigenvectors (or approximate via TD-learned successor representation over the same graph) and use these as the per-entity codes instead of an SGD-trained embedding table.
3. Plug these codes, unmodified, into the existing FHRR elementwise-product bind + cleanup pipeline.
4. Measure recall/accuracy on held-out (A,B) pairs never seen combined during training (the same generalization slice that gave 0.11 for the SGD baseline and 1.0 for the hand-designed baseline).

This isolates the CODE-CONSTRUCTION variable while holding the bind mechanism fixed — directly testing whether "predictive/spectral code, not the bind op, was the missing ingredient."

## Falsifiable predictions

**HARD-PASS:** novel-(A,B)-pair accuracy with spectral/SR-derived codes >= 0.70 (a >=6x lift over the 0.11 SGD baseline, closing most but not necessarily all of the gap to 1.0 — some residual gap vs. the hand-designed ceiling is expected because the algebraic phase-code baseline is a "cheating" upper bound that knows the group is exactly Z_L in advance).

**HARD-FAIL:** novel-pair accuracy <= 0.20 (statistically indistinguishable from the 0.11 SGD baseline within noise) — meaning the spectral/eigenvector code, even though theoretically well-motivated, does not survive the elementwise-product bind (e.g. because raw Laplacian eigenvectors are real-valued and not phase-structured the way FHRR needs, so the bind operator scrambles them the same way it scrambles arbitrary SGD-learned codes). This would falsify "code-construction alone closes the gap" and point back to needing an explicit group-representation construction step (rank-4 candidate below), not just any spectral embedding.

**Secondary falsifiable prediction (homomorphism-regularization candidate):** adding an auxiliary "homomorphism-error" loss term during ordinary SGD training (penalizing `bind(code(A),code(B))` deviating from `code(f(A,B))` for the known composite label) should lift novel-pair accuracy by >= 3x over the pure-task-loss 0.11 baseline (HARD-PASS >= 0.33) if the mechanism in Rank 3 below is real; HARD-FAIL if lift < 1.5x (< 0.17).

## Part 1 — Grid/entorhinal algebraic codes: mechanism + does it generalize to arbitrary relations?

**(a) Brain mechanism (well-established).** Grid-cell hexagonal firing arises from continuous-attractor dynamics on a neural sheet (local excitation + surround inhibition, driven by velocity input) that self-organizes into a periodic lattice and performs path integration as vector addition (Burak & Fiete, PLOS Comp Bio 2009). Multiple discrete-scale modules jointly encode position the way a **residue number system (RNS)** encodes an integer via remainders modulo several periods — a modular, error-correcting, combinatorial code (Fiete et al., Neuron 2008; Khona & Fiete, eLife 2019). Gardner, Hermansen, Moser & Moser (Nature 2022) directly confirmed via topological data analysis that grid-cell population activity literally lies on a **torus** — this is not a modeling metaphor, it's measured population geometry. The algebra is: translation group acting on a 2-torus, jointly composed across modules via CRT-like modular arithmetic.

**(b) Does the SAME algebra generalize to non-spatial relations? Contested / more nuanced than press coverage suggests.** Constantinescu, O'Reilly & Behrens (Science 2016) found hexagonal-symmetric BOLD modulation in entorhinal cortex during navigation of an abstract 2D "bird morph" conceptual space; Bellmund/Gärdenfors/Doeller/Behrens (Science 2018) and Behrens et al. (Neuron 2018, "What Is a Cognitive Map?") extend this programmatically. But the **mechanistic model that actually generalizes across relation types** — the Tolman-Eichenbaum Machine (Whittington et al., Cell 2020) — reveals the real claim is narrower and more useful for us: TEM **factorizes structure (entorhinal "basis") from content (hippocampal conjunctive code)** and reuses that FACTORIZATION ARCHITECTURE across tasks that share the same underlying transition/graph structure, but **a new structural code must still be learned per distinct relation-type** (tree vs. open-2D vs. hierarchy vs. social-rank). Grid/band/border-like units emerge spontaneously in TEM as a byproduct of ANY periodic/graph-Laplacian-like structure — they are not proof of one hardwired hexagon reused verbatim. Aronov, Nevers & Tank (Nature 2017) give direct single-unit evidence entorhinal/hippocampal cells remap to code a purely non-spatial (auditory frequency) axis — the circuitry is domain-general, but each axis still gets its own learned code. Caveats: human fMRI grid-signal replication has recently failed in at least one large study (2024); Ekstrom et al. warn against assuming isomorphism between neural pattern and cognitive representation; Dileep George's clone-structured cognitive graphs (Nat Commun 2021) explain the same phenomenology via a structurally different (HMM/graph, not vector-algebra) account, meaning the data are not uniquely diagnostic of "literal grid geometry for everything."

**(c) Glass-box realization.** Treat "one algebra for everything" as the wrong target. The correct target-per-relation is: (i) build the relation's own transition/co-occurrence graph from observed instances, (ii) derive a low-rank spectral/successor-representation basis for THAT graph specifically (see Part 2), (iii) bind entities coded in that basis with the existing, unchanged FHRR/HRR elementwise-product operator. Different relation types (modular arithmetic, part-whole, causal chains, social rank) get DIFFERENT learned bases, all consumed by the SAME bind primitive — this mirrors TEM's structure/content factorization and is directly buildable in VSA.

**(d) What to measure to prove generalization**: novel-combination accuracy on a HELD-OUT relation instance (never-seen (A,B) pair) for each of several distinct relation types (not just the mod-L task), using per-relation spectral bases with a shared bind op, vs. a from-scratch SGD baseline per relation. If accuracy approaches the hand-designed ceiling across MULTIPLE distinct relation types (not just the one we already know is secretly modular arithmetic), that is direct evidence the "spectral-basis-per-relation + shared bind" principle is the general fix, not a fluke of the mod-L task's convenient group structure.

Precedented: the biology (attractor -> torus -> RNS) and the TEM factorization architecture are both well-established/published. Novel for us: applying the "learn one spectral basis per relation, bind with shared FHRR op" recipe explicitly inside a VSA substrate — not published as such.

## Part 2 — Learning signal that yields algebraic codes instead of memorization

**(a)/(b) Mechanism + principle (well-established, strongest candidate).** Stachenfeld, Botvinick & Gershman (Nat Neurosci 2017) show the hippocampal **successor representation** M=(I-γT)^-1, learned via ordinary TD learning to predict long-horizon future occupancy (not just the present state), is mathematically a Neumann-series expansion of the transition matrix — its eigendecomposition IS the transition graph's (Laplacian-related) eigenbasis. Predicting FAR-future occupancy specifically privileges the **low-frequency eigenvectors** (slow-mixing, global modes) because the (I-γT)^-1 operator damps high-frequency components as γ->1. These eigenvectors reproduce grid-cell-like (open, symmetric graphs) and place-cell-like (bottlenecked graphs) tuning **as a direct mathematical consequence**, not a coincidence. Crucially, this basis is compositional: any value/occupancy function is a linear combination of a small SHARED set of global basis functions, so novel goals/paths recombine additively — the opposite of a lookup table.

Why does plain SGD (single-task reconstruction/classification loss) fail to find this? Locatello et al. (ICML 2019) proved, with a 12,000-model sweep, that unsupervised disentanglement is **impossible without inductive bias on model or objective** — infinitely many equal-loss solutions exist that are not algebraic, and a generic loss has zero pressure toward the compositional one. The successor-representation objective is different in kind: predicting MULTI-STEP FUTURE OCCUPANCY (not single-step reconstruction) is exactly the inductive-bias-bearing objective that forces the low-frequency/spectral solution, because that solution is provably what minimizes long-horizon predictive error on a graph-structured domain.

**(c) Glass-box realization.** Do NOT train entity codes with the current task's direct SGD loss. Instead: (i) construct the empirical transition/co-occurrence graph implied by the relation (nodes = entities, edges = observed relation instances), (ii) either explicitly eigendecompose its Laplacian, OR run a TD-style successor-representation update over it, (iii) use the resulting low-frequency eigenvector loadings (converted to FHRR-compatible phase/complex form) as the entity codes, (iv) bind with the existing unchanged FHRR elementwise product. This is a genuinely different learning signal from the current SGD-on-task-loss pipeline, not a variant of it — that is exactly why it is the top-ranked candidate for closing the gap.

**(d) What to measure**: as in the Cheap Decisive Test above — novel-pair accuracy with spectral/SR codes vs. the 0.11 SGD baseline vs. the 1.0 hand-designed ceiling, bind operator held fixed. Also worth measuring: does the SPECTRAL code recover (up to rotation/relabeling) the SAME phase structure as the hand-designed FHRR code for the mod-L task specifically (since we know the ground truth there) — if yes, that's strong internal validation that the eigenvector basis IS literally rediscovering the group representation, not just a loosely-correlated proxy.

Precedented: the neuro/RL result is extremely well-established (Stachenfeld et al. 2017, hundreds of citations, canonical). Novel for us: plugging the resulting basis directly into an FHRR bind rather than using it as a standalone value-function feature (as in the RL literature) — this specific combination is not published.

## Part 3 — Compositional generalization / group representation theory for arbitrary relations

**(a) Cognitive-science framing (contested, still-open).** Fodor & Pylyshyn's (1988) systematicity challenge is still debated as unresolved even for modern deep nets (2026 arXiv still argues the challenge "stands"). Comparative-cognition evidence (corvids, primates) shows combinatorial/relational reasoning but the literature is thinner and less cleanly matched to "novel combination of two independently-known relations" than the ML benchmarks — low-medium confidence here, this branch is more suggestive than decisive.

**(b) Formal principle — tensor-product/HRR binding, and the crucial split between structure-preserving vs. arbitrary filler codes.** Smolensky (1990) formally solves systematicity via tensor-product role⊗filler sums; Plate's HRR/circular-convolution (1995) keeps this fixed-dimensional. The literature draws a clean, well-established distinction we should treat as load-bearing:
- **Arbitrary/i.i.d.-random filler codes** (current SGD-learned embeddings, or plain random VSA atoms): the BIND OPERATOR itself generalizes to any never-seen role-filler pair algebraically (it's just elementwise/convolution math), but since the FILLER SPACE carries no exploitable structure, nothing beyond "was this exact bound pair seen before" (cleanup-memory lookup) works — this is precisely our 0.11 regime.
- **Structure-preserving continuous codes (Fractional Power Encoding / Spatial Semantic Pointers** — Komer et al. 2019, building on Plate; resonator networks, Frady/Kent/Olshausen/Sommer 2020**)**: binding a base vector raised to continuous fractional exponents in the Fourier domain preserves algebraic relationships (order, distance, interpolation) among fillers THROUGH the bind — this is precisely the mechanism behind the 1.0 hand-designed result, and it is well-established, precedented VSA machinery, not novel.

**Group representation theory framing (medium confidence, partly novel synthesis).** FHRR's phase-vector binding is literally the regular representation of **U(1)^n**; circular convolution is the regular representation of a cyclic group via the DFT. This is stated in VSA surveys but usually in passing. The GENERALIZING PRINCIPLE we need — "construct filler codes as an equivariant/homomorphic image of whatever group or graph-automorphism structure matches the target relation, for ARBITRARY (non-numeric, non-spatial) relations" — is a well-motivated composition of established pieces (FHRR-as-group-representation + Cohen & Welling equivariant-network theory) but **is not itself an explicitly published result** for non-numeric relations. The closest empirical validation found is very recent and unreplicated: a 2026 arXiv result ("Representational Homomorphism Predicts and Improves Compositional Generalization in Transformer Language Models") that directly measures a "Homomorphism Error" (deviation from algebra-homomorphism between relation-space composition and hidden-state composition) and shows it predicts AND — when used as an auxiliary training signal — IMPROVES out-of-distribution compositional generalization (R^2=0.73). This gives a concrete, cheap, novel-but-precedented-in-spirit third candidate: train the SGD encoder as today, but add a homomorphism-error auxiliary loss.

**(c) Glass-box realization, ranked.** Given the eigenvector/spectral basis from Part 2 is essentially "discovering what the effective group/graph-automorphism structure of the relation is" (eigenvectors of an abelian Cayley graph ARE its group characters), the natural next step after Rank-2 succeeds is: convert the discovered spectral structure into an EXPLICIT finite/discrete group representation (clean phase codes matching the discovered periodicity/symmetry), rather than using the raw noisy eigenvectors directly — this is the Quessard-et-al-style move (explicit group-structured latent + regularizer) generalized from "known dynamical-environment group" to "empirically-discovered relation group."

**(d) What to measure**: whether EXPLICIT group-representation construction (post-spectral-discovery) beats RAW spectral/eigenvector codes on novel-pair accuracy — i.e., does "cleaning up" the discovered basis into an exact algebraic phase code recover the remaining gap to 1.0 that raw eigenvectors leave open. Also measure homomorphism-error as an auxiliary SGD loss (Rank-3, independently testable without needing the spectral pipeline at all) per the secondary falsifiable prediction above.

## Ranked candidates for closing 0.11 -> 1.0 (impact-ranked, precedented vs. novel flagged)

1. **Successor-representation / Laplacian-eigenvector code construction, fed into unchanged FHRR bind.** Highest expected impact for the GENERAL (non-modular) case — doesn't require knowing the relation's group in advance, discovers it from co-occurrence structure. Precedented (neuro+RL, very well-established); the specific "feed into FHRR bind" combination is a novel-but-low-risk synthesis. **P_deflated = 0.40** for HARD-PASS on the cheap decisive test (raw prior ~0.60, deflated 0.20 per lit-scan calibration penalty, and independently capped at 0.50 for novel synthesis).
2. **FPE/fractional-power-encoding on a KNOWN group structure** (e.g. cyclic Z_L for literally-modular relations). Zero-risk / already-validated — this IS the mechanism behind the existing 1.0 hand-designed result. Not a new candidate so much as confirmation that whenever the relation's group is already known, skip learning entirely and construct the code. Precedented, essentially certain (P~0.95) but narrow in scope (only helps when the group is already known, which is the boring case, not the arbitrary-relation frontier).
3. **Homomorphism-error auxiliary loss during ordinary SGD training** (regularize the learned code toward bind-algebra-preserving structure without hand-designing it). Cheapest to implement (bolt onto existing training loop), most novel/least precedented (single 2026 unreplicated paper), independently testable. P_deflated = 0.30 for the secondary falsifiable prediction (>=3x lift).
4. **Explicit group-equivariant code construction post-spectral-discovery** (clean up raw eigenvectors into an exact finite-group phase representation once the effective group is empirically identified). Powerful but depends on candidate 1 succeeding first — treat as a follow-on refinement, not an independent first move. P_deflated = 0.30, conditional on candidate 1's HARD-PASS.
5. **Meta-learning curriculum for compositionality (Lake & Baroni MLC-style)** — strongest and most-replicated ML result of the entire scan (Nature 2023, human-level systematicity), but it is a TRAINING-REGIME fix (curriculum across many compositional tasks) rather than a code-construction principle, and doesn't tell us WHAT structure to aim for. Complementary wrapper around candidates 1/3, not competing with them. Rank lowest for THIS specific gap because it doesn't answer the mechanistic question, though it may be the most reliable practical fallback if 1/3/4 all HARD-FAIL. P_deflated = 0.35 as a standalone fallback (well-precedented, but a different mechanism than what the question asked for).

## Substrate-product implications

If candidate 1 (successor-representation/spectral code construction feeding the existing FHRR bind) HARD-PASSes, this converts "arbitrary-relation compositional generalization" from an open capability gap into a **two-stage pipeline we already mostly have the parts for**: (stage A) build a co-occurrence graph per relation-class and derive its spectral basis — cheap, CPU-only, no new bind mechanism; (stage B) unchanged FHRR bind/unbind/cleanup. This would mean the product doesn't need a fundamentally new binding primitive for relational reasoning generalization — it needs a **code-construction preprocessing stage**, which is a much smaller build than a new algebra per relation type. If it HARD-FAILs, the fallback (candidate 5, meta-learning curriculum) is a training-regime change to the existing encoder, not a new inference-time mechanism — also compatible with staying glass-box at runtime (the meta-learning happens at training time only).
