## (a) The biology — what is held, and how it updates

### A1. Three representational levels, one integration cycle (Kintsch's Construction-Integration model)

Kintsch (1988, *Psychological Review* 95:163-182; van Dijk & Kintsch 1983) distinguishes **surface form** (decays fastest), **textbase** (a propositional network — microstructure of local clause-propositions, macrostructure of superordinate gist propositions via deletion/generalization/construction), and **situation model** (textbase fused with world knowledge into a referential model of what the text is about, independent of wording; persists longest — verified via a triple dissociation in recognition/verification paradigms, Fletcher & Chrysler 1990; Schmalhofer & Glavanov 1986). The per-sentence cycle has two phases: **construction** is loose and over-inclusive — the incoming clause is propositionalized and spreads activation to associatively related nodes including irrelevant/wrong senses; **integration** is a connectionist constraint-satisfaction pass — activation propagates iteratively across a weighted proposition-to-proposition matrix (argument overlap, connectives) until the network settles, with well-connected/coherent propositions gaining activation and unconnected/contradictory ones dropping toward zero. This settling IS the suppression mechanism — no separate inhibitory operator, an emergent property of the activation dynamics. Only a small subset of highest-activation propositions (the most recent clause's propositions plus 1-2 macro-propositions needed for global coherence) survive into the buffer seeding the next cycle; if a new sentence needs an antecedent that has dropped out, the model must search the growing episodic representation to **reinstate** it — the proposed source of the extra reading-time cost documented for long-distance reference. Flag: the informal "1-2 sentence buffer" figure is a gloss on a variable, task-dependent capacity in Kintsch's own formalism, not a fixed parameter.

### A2. Five monitored dimensions, and a competing unified-monitor account (Zwaan & Radvansky's event-indexing model)

Zwaan, Langston & Graesser (1995, *Psychological Science* 6:292-297); Zwaan & Radvansky (1998, *Psychological Bulletin* 123:162-185): readers index **protagonist, time, space, causation, intentionality/goals**, updating whichever dimension's value changes clause-to-clause. Reading-time cost is largely **additive across simultaneous discontinuities** — the key evidence for independent, dimension-specific monitoring rather than one global coherence check. Support is uneven: temporal-shift cost scales with shift magnitude (Zwaan 1996), causal relatedness facilitates RT (Myers, Shinjo & Duffy 1987), protagonist/goal tracking is well-evidenced (Suh & Trabasso 1993) — but the **spatial dimension is the weakest and least replicable**, and whether this is truly five independent indices vs. one global coherence-monitor correlating with these dimensions is a live, unresolved theoretical fault line (Sanford & Garrod's scenario-mapping is a rival unified account).

### A3. Structure-building: foundation, mapping, shift (Gernsbacher's Structure Building Framework)

Gernsbacher (1990, *Language Comprehension as Structure Building*; Gernsbacher & Faust 1991, *JEP:LMC* 17:245-262): three processes — **laying a foundation** (initial substructure for a new topic/episode), **mapping** (attaching coherent incoming material to the current substructure via node enhancement), and **shifting** (abandoning the current substructure and laying a new one when incoming information is incoherent — triggered by changes in time/space/character/causation/topic, closely paralleling Zwaan's discontinuity dimensions). Suppression is measured directly via homograph/anaphor priming: less-skilled comprehenders show *sustained* facilitation for a contextually-rejected meaning at SOAs where skilled comprehenders' priming has already decayed (Gernsbacher & Faust 1991), and separately shift too often, building excessive numbers of substructures (Gernsbacher, Varner & Faust 1990). Flag: shift's RT evidence substantially overlaps with the same paradigms used for Zwaan's discontinuity effects — SBF is better described as a descriptive meta-framework than an independently-computational model.

### A4. Bridging inference and the given-new contract — an unresolved automaticity debate

Haviland & Clark (1974, *JVLB* 13:512-521); Clark & Haviland (1977): each sentence parses into **given** (locatable in the existing model) and **new** (asserted) information; comprehension requires attaching the given portion to an antecedent, and reading slows measurably when the antecedent is only implicit, forcing a **bridging inference** (Clark 1975 distinguishes conventional/"authorized" bridges — part-whole relations — from less direct ones). Whether such inferences are drawn automatically online or only strategically is a genuinely **open, paradigm-dependent debate**: McKoon & Ratcliff's minimalist hypothesis (1992, *Psychological Review* 99:440-466) says only locally-required, readily-available inferences are automatic; Graesser, Singer & Trabasso's constructionist view (1994, *Psychological Review* 101:371-395) says readers automatically build maximally globally-coherent representations ("search after meaning"); Singer's work (1980; Singer & Ferreira 1983) shows many simple bridges ARE drawn online, suggesting a graded middle ground rather than a strict binary. Not resolved either direction.

### A5. Event boundaries = consolidation triggers (Event Segmentation Theory)

Zacks & Tversky (2001, *Psychological Bulletin* 127:3-21); Zacks, Speer, Swallow, Braver & Reynolds (2007, *Psychological Bulletin* 133:273-293): an ongoing event model in working memory continuously predicts what happens next; when **prediction error spikes**, an event boundary is perceived, the current model closes and passes to durable storage, and a new model initiates. Neural evidence: hippocampal activity at event boundaries scales with boundary salience and predicts subsequent recall (Ben-Yakov & Henson 2018, *J. Neurosci.*); Baldassano et al. (2017, *Neuron*) show HMM-derived neural event boundaries in high-order cortex coincide with hippocampal encoding responses. Behaviorally, the **"event horizon"/doorway effect** (Radvansky, Krawietz & Altarriba 2011, *QJEP*) shows forgetting increases after crossing an event boundary relative to an equivalent distance within one event — content not carried forward becomes less accessible, i.e. boundary-triggered consolidation, not pure discard. This is well-replicated behaviorally and increasingly supported neurally, though the precise computational nature of the boundary-detection signal (prediction error vs. prediction uncertainty) remains actively contested in the most recent (2024-2025) literature.

### A6. The "now" is narrower than a 4-chunk focus: a single true focus, empirically distinct

**Centering Theory** (Grosz, Joshi & Weinstein 1995, *Computational Linguistics* 21(2):203-225; Brennan, Friedman & Pollard 1987, ACL — the BFP algorithm): each utterance has exactly one **Cb** (backward-looking center — the highest-ranked member of the PRIOR utterance's Cf list that is actually re-mentioned in the current utterance) and a ranked **Cf list** (all discourse entities in the utterance, ranked by grammatical role: subject > object > other). Four transitions from two binary tests: **CONTINUE** (same Cb, and it's the top-ranked/preferred Cf), **RETAIN** (same Cb, not preferred — predicts an upcoming shift), **SMOOTH-SHIFT** (new Cb, but it's the preferred Cf), **ROUGH-SHIFT** (new, non-preferred Cb) — the 4-way split canonized by BFP1987 and Walker, Joshi & Prince (1998, eds.). Rule 1: if anything is pronominalized, the Cb must be. Rule 2: prefer Continue > Retain > Smooth-Shift > Rough-Shift. **Direct cognitive evidence, not just an engineering convenience**: Gordon, Grosz & Gilliom (1993, *Cognitive Science* 17:311-347) found the **Repeated Name Penalty** — re-mentioning a Cb-antecedent with a full name is read SLOWER than a pronoun in that slot, direct evidence a pronoun is the cognitively expected/cheap form exactly when Centering predicts Continue. Contested: Kibble (2001, *Computational Linguistics* 27(4)) argues the preference ordering is theoretically unmotivated as stated; Poesio et al. (2004, *Computational Linguistics*) found substantial cross-linguistic/annotation disagreement on how to instantiate the theory's free parameters — a genuine operationalization problem, not settled engineering.

**McElree's direct-access evidence** (McElree 2000, 2003 w/ Foraker & Dyer, 2006) using Speed-Accuracy Tradeoff methodology shows a qualitative split: ONE item/proposition is retrieved with fast, distance-invariant dynamics ("direct access," genuinely zero extra cost) while everything else shows a real search signature (speed degrades with the number of competitors). This is the strongest direct evidence for a literal single-item, zero-cost focus — narrower than Cowan's ~4-chunk number — but it was demonstrated on sentence-internal filler-gap/ellipsis dependencies; extension to multi-sentence discourse-referent tracking is this note's own extrapolation (plausible given the Cb/Gordon-Grosz-Gilliom convergence, but not directly tested by McElree). Falling out of the Cb/Cf structure entirely means a referent typically requires a **full NP, not a pronoun**, to be reintroduced (Almor 1999, *Psychological Review*, Informational Load Hypothesis — referring expressions need just enough content to identify the referent AND out-compete current-focus rivals).

**Decay vs. interference (a genuinely unresolved debate, honestly flagged)**: Lewis & Vasishth's (2005, *Cognitive Science* 29(3)) ACT-R cue-based retrieval model contains BOTH a time-decay term and a fan/cue-overload interference term — it is not decay-free, contrary to how it is sometimes summarized. Van Dyke & McElree (2006, *JML* 55:157-166) localize interference specifically to retrieval, not encoding, but do not thereby refute decay. The decay-vs-interference fight is fought mainly in the general working-memory-span literature (Lewandowsky & Oberauer 2009 vs. Barrouillet & Camos's TBRS) — as applied specifically to discourse referents, no decisive dissociation study exists; this is an unresolved extrapolation, not a settled discourse-level finding. **Ariel's Accessibility Theory** (1990/2001) and **Gundel, Hedberg & Zacharski's Givenness Hierarchy** (1993, *Language* 69:274-307 — six nested cognitive statuses: in focus ⊃ activated ⊃ familiar ⊃ uniquely identifiable ⊃ referential ⊃ type identifiable) both independently converge with Centering's Cb/Cf structure (Cb ≈ "in focus," ranked Cf ≈ "activated," drop-out ≈ "familiar," requiring full-NP reintroduction) but this is a widely-noted parallel, NOT a proven identity — Centering is a sequence/coherence theory, Ariel/GHZ are synchronic form-choice theories; integration is an open question.

### A7. Common ground and the interactive layer conversation adds

Clark & Schaefer (1989, *Cognitive Science* 13:259-294): grounding decomposes into a **presentation phase** (speaker offers content) and an **acceptance phase** (partner provides evidence of understanding — backchannels, next-turn uptake, repair-initiation), against a **grounding criterion** that is purpose-relative, not a fixed perfection bar (Clark & Brennan 1991). This is structurally, not incidentally, different from solitary reading: a silent reader's "acceptance" is self-monitored only (comprehension-monitoring, rereading) — there is no partner-confirming turn, no clarification-request option. The given-new contract itself (Haviland & Clark 1974; Clark & Haviland 1977) was established on **written, non-interactive** materials — the base integration mechanism is genuinely shared across reading and dialogue; what conversation adds is an additional repair/negotiation layer, not a different core mechanism (this "same core + additive repair layer" framing is this note's own synthesis of two literatures, not asserted in one place by Clark — flagged as inferential). Formal frameworks split the same way: **QUD** (Roberts 1996/2012) and **SDRT** (Asher & Lascarides 2003) build coherence structure applying to BOTH monologue and dialogue, with SDRT adding dialogue-specific relations (Question-Elaboration) for question-answer adjacency; **Ginzburg's KoS** (2012, *The Interactive Stance*) explicitly argues dialogue needs genuinely ADDITIONAL machinery — per-speaker Dialogue GameBoards (not one shared common-ground store), turn-taking, grounding acts, and clarification sub-dialogues as first-class objects, motivated by phenomena (self-repair, sluicing, split utterances) monologue theories don't need. **Engineering precedent for symbolic (non-neural) dialogue state**: Larsson & Traum's information-state update approach (2000, TRINDI/TrindiKit) modeled dialogue state as an explicit symbolic record (QUD stack, shared/private beliefs, obligations) updated by rule-based update rules — the field's later shift to neural belief trackers (Mrkšić et al. 2016) was capability-driven (ASR noise, open vocabulary), not a refutation that symbolic state-tracking is coherent in principle. **Neuro evidence for shared substrate is real but narrower than the question needs**: Regev, Honey, Simony & Hasson (2013, *J. Neurosci.*) show modality-invariant STG/IFG responses for reading vs. being read to (spoken monologue) of the same narrative — good evidence reading and one-way spoken narration share a discourse network — but no study directly pits silent solitary reading against live turn-taking conversation with grounding/repair; this specific comparison is thin/absent in the literature, reported honestly rather than papered over.

## (b) Verdict: shared substrate, with an honest additive layer

The situation-model/coherence core (construction-integration, given-new, QUD-style structuring, DMN-level discourse engagement) is defensibly SHARED between reading and conversation — building it once is the right design call. But the literature repeatedly and explicitly layers dialogue-specific machinery on top (Clark & Schaefer's presentation+acceptance grounding acts, Ginzburg's GameBoards, repair/clarification sub-dialogue) that reading structurally cannot exercise (no second party to confirm uptake). Treat this as **one shared core + one additive interactive wrapper**, not a single undifferentiated system — and do not claim conversation support "for free" once the core situation-model module exists; the wrapper is real, separately-buildable work.

## (c) Glass-box architecture proposal: the Working Situation Model (WSM)

The nested four-tier structure the biology lane converges on maps directly onto substrate components already scoped in two prior notes — **this is the connective tissue between them, correcting and sharpening both**:

| Tier | Brain mechanism | Substrate component (already scoped where noted) | What's NEW this note contributes |
|---|---|---|---|
| **0 — true focus** | Centering's Cb; McElree's single-item direct-access (zero-cost) | **A single pointer register** — no resonator decode, no bundle, just the current discourse "aboutness" vector (literally the last-bound subject-entity phasor, held by reference) | NEW tier — the prior WM note's F=3-4 mapping conflated this with Tier 1; McElree's evidence says the TRUE zero-cost item is narrower than Cowan's ~4, and it should be a cheap O(1) pointer, not a resonator-decoded item at all |
| **1 — attentional focus** | Cowan's ~4-chunk focus; Centering's ranked Cf list | **F=3-4 resonator joint-decode sweet spot** (already measured, `research_brain_capacity_efficient_language_mechanisms_vsa_analogs_2026-07-16.md`) | The RANKING FUNCTION over what occupies this tier was previously unprincipled ("whichever facts happen to be loaded"); Centering supplies one directly: grammatical-role salience (subject > object > other) — a free, already-computable feature the parser already assigns |
| **2 — activated situation model** | Zwaan's 5-dimension event index (protagonist/time/space/causation/intentionality); Kintsch's textbase-carrying-forward | **N/16-32 flat-bundle crosstalk ceiling** (already measured, same WM note) — a superposed bundle of the CURRENT event/scene's role-fillers | Gives the bundle a PRINCIPLED CONTENT SPEC (5 named dimensions, not an arbitrary bag of facts) and a PRINCIPLED UPDATE RULE (construction: bind+bundle new clause; integration: check the 5 dimensions for discontinuity via bound-vector overlap against the prior state — this is the substrate-native analog of Kintsch's spreading-activation settling) |
| **3 — durable foundation** | Consolidated long-term memory, entered at event boundaries (Gernsbacher SHIFT / Zacks-Tversky EST) | **Exact-record paging, Frontier-2** (already scoped, same WM note); fed by the **already-VET'd 3-signal ingest gate** (schema-fit + recurrence + unexpectedness) | **The load-bearing new finding**: EST's boundary-detection signal is a prediction-error spike — mechanistically the SAME kind of signal as the ingest gate's already-built unexpectedness axis (relation-conditioned directed community-transition PE). This gives the ingest gate a literature-grounded SECOND ROLE it did not previously have: firing the unexpectedness axis above a threshold on Tier-2's active bundle should BE the event-boundary/consolidation trigger, not merely a per-fact novelty filter. This is a real mechanism unification, not a coincidental reuse of the same three words — the brain's own account of "when does situation-model content get consolidated" IS "when prediction error spikes," and the substrate already has a validated prediction-error signal sitting unused for this specific role. |

**Update mechanism, per sentence (the incremental piece the task specifically asked for):**
1. Parse the incoming clause into role-fillers (existing parser stage).
2. **Construction**: bind role-fillers, bundle into the Tier-2 active event-bundle (existing bind/bundle primitives, no new machinery).
3. **Integration/discontinuity check**: compare the new clause's protagonist/time/space/causal/intentional fillers against Tier-2's current state via bound-vector overlap (cosine/dot-product against the previous fillers on each of the 5 dimensions — a cheap, already-available operation). If overlap stays high on all 5 dimensions: **CONTINUE** (Centering) — cheap update, Tier 0's Cb pointer stays put, Tier 1's Cf ranking re-sorts with the new clause's entities folded in.
4. If overlap drops on one or more dimensions past a threshold: **SHIFT** (Gernsbacher) / **event boundary** (Zacks-Tversky) fires — (i) route Tier 2's current bundle through the ingest gate for possible consolidation into Tier 3 (the unexpectedness axis IS this same discontinuity signal, so this is not a second computation, it is reading the same number for a second purpose), (ii) lay a new Tier-2 foundation for the new event/scene, (iii) reset Tier 0/1 to the new event's entities.
5. Pronoun/coreference resolution (the already-scoped `HOBBS_COREF` resolver): **check Tier 0 (Cb) FIRST** — per Centering's Rule 1, a pronoun should default to the current Cb with no search at all — and only fall back to the ranked Tier-1 Cf search (which is what the existing coref note's "recency + subject-role-preference" design already implements) when Tier 0 gives no match or a genuine ambiguity exists. This is a direct efficiency and correctness upgrade to the already-scoped resolver: most CONTINUE-sequence pronouns should resolve in O(1) against Tier 0, with the more expensive Cf search reserved for RETAIN/SHIFT cases — matching the literature's own claim that Continue sequences dominate ordinary text and are the cheap case.

**Conversation**: the SAME Tier 0-3 module, with a thin **grounding/acceptance wrapper** added on top — an explicit turn-based accept/repair state (did the listener's next turn confirm uptake, or trigger a clarification request) — not a rebuilt discourse engine. Per (b), this wrapper is real, separately-buildable work; it is not automatically free once Tiers 0-3 exist.
