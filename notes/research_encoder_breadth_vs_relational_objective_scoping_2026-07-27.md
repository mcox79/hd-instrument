## HEADLINE

**We do NOT have a real breadth corpus staged on disk** (only `text8`, 96MB/~17M tokens of circa-2006 lowercase Wikipedia, and a 500-article/~154k-token Wikipedia sample — together ~7% of the 237M-token ARC pool, too weak to power a clean breadth test; the real breadth candidate, Simple English Wikipedia, is scoped but NOT pulled, per `notes/breadth_corpus_expansion_plan_2026-07-27.md`). **The relational-OBJECTIVE lever is buildable tonight with zero new data acquisition** (the 482,588-node / 1,238,686-edge `cskg_foundation_v1`, HARD_PASS-gated, is on disk; a prior small-scale MLM+relational-objective architecture already exists at `experiments/exp_deep_text_encoder_self_teacher_heldout_new_v1.py`, config field `w_rel` shows the joint-loss machinery was already built once, just never run at the `exp_scale_meaning_learn_arc_heldout_v2` FULL_CFG scale). Two independent lit-scans converge on the same read: (1) MLM + graph/relational auxiliary-loss joint training is a well-precedented pattern with verified real gains at moderate scale (LinkBERT +5-7% absolute on multi-hop QA), but the fully self-contained "distill your own KG, no external teacher" version is an *extrapolation*, not directly demonstrated; (2) a near-chance probe (our relational-AUC 0.56 vs chance 0.51) that persists despite reasonable exposure (median 655, max 4345 mentions) is the literature's classic signature of an **objective/architecture ceiling, not a data-quantity problem** (per "Capability Ceilings in Autoregressive LMs," arXiv:2510.21866 — knowledge-probe accuracy stayed flat near-chance across 70M-30B params while loss fell 31%, and the authors explicitly could not close it by scaling data). **Recommendation: run the OBJECTIVE lever tonight (MLM + relational-edge-prediction self-teacher, reusing/upscaling the existing `w_rel` architecture), not breadth** — it is more decisive on the actual symptom, has zero data-acquisition dependency, and is the literal next milestone already named in `THE_PLAN` (R3/R4 internal self-teacher). Breadth is real and worth pursuing but is currently gated on a local-download-then-SCP step (Simple Wikipedia is not yet on disk) that does not obviously fit inside tonight's window if the objective run is also queued — sequence breadth as a follow-up night, not tonight's pick.

## 2. Breadth lever — can-fail design (for when a real breadth corpus is staged)

**Real baseline:** the banked `exp_scale_meaning_learn_arc_heldout_v2` ARC-only run (relational-AUC ceiling ~0.56 at max exposure, chance ~0.51; +0.071 relational / +0.050 semantic over grounding, both seeds).
**One variable:** training corpus composition (ARC-only vs ARC+breadth), same FULL_CFG architecture (`d_model=512, n_layers=6, n_heads=8, vocab=16000, max_len=128`), same `mlm_steps=60000`/`train_token_budget=130,000,000`, same concept-level leak-proof scrub methodology, same eval code (`encode_concept_text_reps`, SEMANTIC same-lexname AUC, RELATIONAL degree-matched-neighbor AUC).
**HARD-PASS:** held-out-to-NEW-concept relational-AUC ceiling rises **>+0.03** over the 0.56 ARC-only ceiling, on BOTH seeds, with the zero-overlap leak witness holding (0 leaked windows) on the FULL mixed+scrubbed stream.
**HARD-FAIL / deflate-null:** relational-AUC ceiling does not move (within noise of 0.56 +/- ~0.02) despite the corpus mix genuinely broadening (verified via the register/coverage-check script) => the ceiling is **objective-bound, not data-bound**; redirect fully to the relational-objective lever, drop breadth as a near-term lever (still valuable later for coverage/conversational breadth, just not for THIS ceiling).

## 3. Relational-objective lever — can-fail design (recommended for tonight)

**Prior art (verified on disk, not assumed):** `experiments/exp_deep_text_encoder_self_teacher_heldout_new_v1.py` already implements a joint MLM + relational-InfoNCE objective (`w_rel=0.5`, `w_geo=1.0`, landmark/anchor-batch InfoNCE against the foundation's induced-pair structure, `w_trigram_pred` char-trigram auxiliary, EMA self-distillation `w_ema=0.5`). Its `metrics.json` (`data/exp_deep_text_encoder_self_teacher_heldout_new_v1/metrics.json`, MIDDLE_BAND, `ts=2026-07-26`) shows `full_fusion - raw_grounding = -0.018` (a small NEGATIVE margin) — the combined objective did NOT beat grounding. **But this run is confounded with scale**: `cap_nodes=5000`, `total_tokens_used=265,273` (53 tokens/concept), `d_model=128`, `n_layers=2` — roughly 1/500th the token budget and 1/4 the depth of the FULL_CFG scale run that produced the +0.071 relational win via text-alone. This is genuine relevant prior work (do not repeat blind), but it tested the objective at a regime where the SCALE experiment independently showed text-alone signal is also weak — it cannot cleanly separate "objective doesn't help" from "everything is weak at 265k tokens." The clean test is the same joint objective at the 130M-token / 512d/6L scale that already proved text-alone gets real signal.

**Real baseline:** `exp_scale_meaning_learn_arc_heldout_v2` TEXT_ARM (text-alone, current 0.56 relational-AUC ceiling) at identical FULL_CFG scale — reuse the banked seed_7/seed_13 checkpoints' TEXT_ARM numbers directly rather than re-running (per store discipline, don't rebuild banked results).
**One variable:** training objective — add an auxiliary relational-edge-prediction loss (predict a masked/held-out edge's relation-type or neighbor-identity from the concept's own contextual text representation, sourced from `cskg_foundation_v1`'s TRAIN-split edges only) alongside the existing MLM loss, at the SAME architecture/steps/corpus as v2's FULL_CFG. Loss form: `L = L_mlm + lambda * L_rel`, `L_rel` = InfoNCE or margin loss ranking a concept's true foundation-neighbor above degree-matched non-neighbors (reuse the `exp_deep_text_encoder_self_teacher` InfoNCE machinery, upscaled), computed ONLY over the TRAIN-split half of `cskg_foundation_v1` (the held-out relational eval edges must never enter this loss — this is the leak gate, additional to and separate from the existing concept-level text leak-scrub).
**HARD-PASS:** held-out-to-NEW-concept relational-AUC ceiling rises **>+0.03** over 0.56 (i.e. clears ~0.59+), on BOTH seeds, AND the semantic-AUC arm does not regress by more than 0.02 (objective-conflict check — per the lit-scan's gradient-interference warning, a relational loss that helps relational-AUC but tanks semantic-AUC is a partial, not clean, win).
**HARD-FAIL:** relational-AUC ceiling stays within +/-0.02 of 0.56 despite `L_rel` training loss visibly decreasing (i.e., the auxiliary loss IS learning something, just not something that transfers to held-out-NEW placement) => the ceiling is genuinely architecture-bound (representation capacity, pooling, or the eval's own compression, not objective absence) — redirect to the readout/pooling mechanism (the same order-blind-mean-pool class of defect already found and fixed once this session in the reader loop, `notes/v4_negative_brain_fidelity_audit_readout_is_order_blind_next_lever_2026-07-27.md` — check whether the ENCODER's own concept-aggregation (mean-pool over mention windows, `encode_concept_text_reps`) has the same order/structure-blindness bug already diagnosed in the reader).
**Risk flag (objective conflict):** per lit-scan A, naive static loss-weighting between MLM and a structure loss is the most commonly cited failure mode (GradNorm/PCGrad exist as mitigations in the literature but add build complexity) — start with a SMALL `lambda` (e.g. 0.1-0.3, informed by the prior run's `w_rel=0.5` which may have been too aggressive at that tiny scale) and log both loss curves separately in metrics, don't just log the summed loss, so a conflict is diagnosable post-hoc rather than invisible.

## 5. Brain-difference + risks

- **Brain-difference (breadth):** the brain's "breadth" is multi-modal, embodied, socially-interactive experience accrued over years, not a bigger text corpus — Wikipedia/OpenSubtitles/Gutenberg is a text-only proxy for register diversity, useful but categorically narrower than what the brain uses to build grounded meaning. This project already has a partial answer to that gap (Lancaster sensorimotor grounding norms, per `THE_PLAN`), so breadth-in-text is explicitly a supplement to, not a replacement for, the grounding layer.
- **Brain-difference (objective):** the brain does not have an explicit "predict the masked word" loss OR an explicit "predict the graph edge" loss — it learns via prediction-error across continuous, multi-timescale, embodied prediction (perception, action-outcome, social feedback). MLM+relational-distillation is a coarse proxy for "predict structure from context + predict relations from co-occurring structure," not a claim of brain-identity. This is consistent with the project's own framing (R3/R4 = "reuses the Stage-2 spokes," i.e. explicitly an approximation of predictive-coding/temporal-contiguity mechanisms already built, not a new brain claim).
- **Risk — compute cost:** each FULL_CFG-scale seed is a real multi-hour GPU commitment on an 8GB card; a failed/misconfigured objective run costs a full night, same as any FULL run — checkpoint-ALWAYS discipline (already a named process fix in `WHERE_WE_ARE_NOW`) applies doubly here.
- **Risk — leakage:** the relational loss introduces a SECOND leak surface beyond the existing text/concept scrub — the foundation's held-out relational eval edges (`data/cskg_foundation_v1/heldout_edges.jsonl`) must be excluded from `L_rel`'s training signal, not just from the text corpus. This is a new gate, not a reuse of the existing text-leak witness; get it wrong and the HARD-PASS is worthless (measuring memorization of the eval edges, not generalization).
- **Risk — catastrophic forgetting of ARC/MLM signal:** if `lambda` on `L_rel` is too large, the encoder could sacrifice the token-prediction signal that already produced the +0.071 relational win via text-alone (the prior small-scale run's `w_rel=0.5` producing a NEGATIVE margin is a soft warning sign here, even though confounded by scale) — the semantic-AUC non-regression check in Section 3's HARD-PASS criteria is the guard against this.

## Substrate-product implications

If the objective lever clears HARD-PASS, this is the piece that turns "the encoder learned SOME relational structure from raw text" into "the encoder was explicitly taught to reproduce the foundation's typed-relational structure" — directly strengthening every downstream consumer of the encoder (reader comprehension, sleep-consolidation quality, reasoning-over-representation) without touching any of those components, because it raises the ceiling they all inherit.
