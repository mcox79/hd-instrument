## Candidate assessment (a/b/c/d per prompt)

### 1. Implicative/factive-verb polarity x negation interaction (event-factuality entailment) -- RANK 1

- **(a) Genuinely beyond-linear:** Karttunen's (1971) implicative-verb classification is a real formal-semantics result: verbs like *manage, get to, bother to* are **positive implicatives** (V(X) entails X; NOT-V(X) entails NOT-X), while *fail, forget to, neglect, avoid* are **negative implicatives** (V(X) entails NOT-X; NOT-V(X) entails X). Entailed-event-polarity = XOR(verb-polarity-class, surface-negation-present) -- a 2x2 truth table with no monotonic single-cue or additive combination that fits all four cells (this is exactly the classic "XOR is not linearly separable" case, Minsky & Papert 1969, applied to a real lexical-semantic fact rather than a toy). Neither cue alone predicts the label; the label is the *parity* of the two, not a weighted sum. Kiparsky & Kiparsky's (1970) factive/non-factive distinction is an adjacent, non-negation-dependent XOR-relevant class (factive complements are presupposed true regardless of matrix polarity; non-factives are not) -- a second, related interaction axis, lower priority than negation x implicative but worth noting as an extension.
- **(b) Real data, locally mineable, cheaply, verified this cycle:** direct-scanned the bundled UD-EWT (train+dev+test) for a closed implicative lexicon (`manage, get, happen, remember, forget, avoid, bother, hesitate, decline, neglect, refrain, dare`) as governing `VERB` tokens: **994 raw token hits, 258 co-occurring with a `Polarity=Neg` cue in the same sentence.** Excluding the two high-polysemy, low-precision verbs (`get`, `happen` -- both frequently non-implicative senses), the clean implicative-verb subset alone yields **~184 tokens, ~72 negated co-occurrences** -- a real, non-trivial incidence, no new annotation scheme needed. The project's own `tools/build_negation_factuality_gold.py` (used to build the 132-item / 4,815-candidate-pool `gold_negation_factuality_ewt_v1` set) is a directly reusable template: same UD-EWT source, same `Polarity=Neg` + dependency-attachment machinery, extended with an `xcomp`-governed-by-implicative-verb selection rule instead of the current `conj`/`want`/`try` rules. This is a bounded, mechanical data-pull, not a new build.
- **(c) Brain mechanism:** per the already-delivered 07-21 negation/brain review (Kaup et al. 2006/2007; Nieuwland & Kuperberg 2008; Kuperberg lab 2019 factive-presupposition P600 finding), the brain does **not** get factivity/implicature resolution for free from cue detection -- it is a real additional computation, itself failure-prone (misreadings toward pragmatically-plausible-but-wrong readings under multiple negation). The brain does not appear to linearize this: factive-vs-non-factive complement handling is a documented categorical gate (P600 elicited only for factive-complement violations), not a graded weighted blend -- consistent with a genuine nonlinear (threshold/parity-like) operation, not an additive shortcut.
- **(d) Construction-favorability risk, addressed directly:** the label is the interaction of TWO real, independently-observable cues (lexical implicative-class membership, a real closed-class linguistic fact; surface negation, a real UD `Polarity=Neg` feature) -- neither cue alone determines the label, and the gold is derived from an external, independently-published linguistic rule (Karttunen's classification), not invented for this test, and not read off the same feature the learner has to predict. Residual risk: if the model is handed verb-identity as a raw one-hot/embedding feature, distinguishing "this is one of 12 known verbs" from "genuinely inducing a semantic polarity class" is a real confound -- mitigate by holding out several implicative verbs from training (does the nonlinear learner generalize the CLASS, e.g. via shared distributional/WordNet-hypernym properties, to an unseen implicative verb, not just memorize the 12-verb lookup table). This holdout design also directly tests generalization, not just fit.

### 2. Reversible-role assignment via animacy x verb-class interaction (psych-verb Experiencer/Cause alternation) -- RANK 2

- **(a) Genuinely beyond-linear:** thematic-role assignment for psych-verbs (VerbNet `amuse-31.1` Cause-Experiencer class: *frighten, amuse, annoy* -- subject=Cause, object=Experiencer -- vs `admire-31.2-1`/`marvel-31.3-3` Experiencer-subject class: *admire, fear, marvel at* -- subject=Experiencer) is a real, well-studied psycholinguistic ambiguity site (McRae, Spivey-Knowlton & Tanenhaus 1998 thematic-fit; Trueswell, Tanenhaus & Garnsey 1994 verb-bias x plausibility ambiguity resolution). In the classic Competition Model framing (MacWhinney & Bates), role assignment is a weighted-cue combination MOST of the time, but the genuinely nonlinear cases are the **conflict cells**: when word-order/case cues point one way and animacy/plausibility point the other, resolution is not a smooth weighted average -- it shows threshold/override behavior (a highly-implausible-agent reading can be categorically rejected rather than down-weighted), i.e. cue x cue interaction, not sum.
- **(b) Real data:** PropBank (112,917 instances, ARG0/ARG1 gold) + VerbNet (verb-class membership, including the psych-verb classes above) + WordNet (animacy via hypernym-chain distance to `person.n.01`/`animal.n.01`) are all locally verified loadable. Real sentences with genuine cue conflict (implausible-subject psych-verb readings, passive-with-animate-by-agent) can be mined from PropBank/PTB directly.
- **(c) Brain mechanism:** the Competition Model / cue-validity literature is explicit that this is graded-but-genuinely-interactive, not purely additive -- English weights word-order heaviest but animacy still overrides in extreme-implausibility cases (a real, replicated interaction effect, not just noise).
- **(d) Construction-favorability risk:** HIGHER than Rank 1. In canonical unambiguous SVO English, word-order alone gets ~95%+ of role assignments right -- a strong near-linear positional baseline. A fair nonlinear test **requires deliberately curating the conflict subset** (cases where order and animacy/plausibility cues disagree), and that curation-by-cue-disagreement is a principled, non-label-based selection rule (not picking by the answer), but it is still a subset-selection step that a naive full-corpus average would wash out -- must be reported honestly as "tested on the conflict slice," not "tested on PropBank" unqualified, or it risks the same aggregate-linear-tie result PP-attach already hit.

### 3. PP-attachment cue-conflict subcases (verb-bias vs. plausibility disagreement) -- RANK 3 (cheapest, fastest, lowest novelty)

- **(a)** The aggregate PP-attach test already tied linear (per the task brief) -- but that could be an averaging artifact if a genuine-interaction subset (cases where lexical/verb attachment-bias and semantic plausibility of the two candidate attachments actively disagree) is cancelled out by the majority of cases where both cues agree (linearly-trivial). Classic PP-attachment literature (Ratnaparkhi, Reynar & Roukos 1994; Collins & Brooks 1995) already frames this as a 4-tuple (verb, noun1, prep, noun2) cue-combination problem -- worth re-mining specifically the disagreement cells.
- **(b)** Zero new data cost -- reuses the exact existing dataset/features from `exp_pivot_pp_attachment_rich_knowledge_v1.py` (already built on UD-EWT), just re-sliced by a cue-disagreement predicate.
- **(c)** Brain: attachment resolution is known to be use-immediately-integrate (garden-path literature), consistent with either account; not strongly informative either way.
- **(d)** Risk: this was ALREADY tested in aggregate and tied -- re-slicing the same data is the cheapest possible test but carries real risk of just reproducing the same null (diminishing-return flavor, not a fresh axis). Good as a **fast, cheap cross-check**, not the primary bet.

### 4. Double negation / negation-parity ("not unlikely," "isn't it not true") -- RANK 4 (clean but rare)

- **(a)** The cleanest possible case: parity of 2 negation cues is the textbook hardest linearly-inseparable function (perceptron degree = number of negation cues). Mathematically unambiguous.
- **(b)** Real but low-incidence in ordinary text -- double negation is a marked/rhetorical construction in English (unlike some other languages with negative concord), so natural UD-EWT incidence is likely thin; would need a dedicated scan (not yet done this cycle) or acceptance of a small n.
- **(c)** Brain: multiply-negated ("depth-charge") sentences are a documented FAILURE mode (misread toward pragmatically-plausible reading, per Frontiers in Psychology 2019, already cited in the 07-21 note) -- meaning even if we build this test, the brain's own ceiling on it is not high; informative as a hard-fail-expected control, not a "wins big" bet.
- **(d)** Low construction risk (genuinely rare, not artificially rare) but the low natural incidence itself is the practical blocker. Keep as a secondary/bonus slice folded into Rank-1's data pull (scan for negation-under-negation as a bonus construction type), not a standalone primary test.

### 5. Quantifier/operator scope ambiguity -- RANK 5 (deprioritize)

- Genuinely a real interaction phenomenon (downward-entailing operators reverse scope preferences; surface-scope is the default "minimal effort" reading per Ioup 1975 and the broader scope-preference literature), but real annotated scope-reading corpora are not available locally and are hard to mine cheaply (scope preference is a reading-time/off-line-judgment fact, not something recoverable from a treebank parse alone -- UD does not disambiguate scope). Would require new psycholinguistic-style annotation -- high cost, and any DIY minimal-pair construction reintroduces exactly the construction-favorability risk this whole drill is trying to avoid.

### 6. WSD via multi-cue interaction -- EXCLUDED / already-closed axis

- Per standing memory discipline, **WSD-frequency is a closed axis** ("don't re-chase closed axes: compgen-MM/FW-holdout/cross-sentence/WSD-frequency"). SemCor is locally available and would make this cheap to mine, but the frontier finding already on record is that WSD collapses toward a strong first-sense/frequency-dominated linear baseline on natural text -- i.e. this candidate is **flagged as "secretly linear"** by prior drilling, not a fresh opportunity. Not re-opened here; noted only to explain its absence from the ranking.

### 7. Garden-path sentences -- RANK last

- Real phenomenon, but naturally-occurring garden-path incidence in ordinary corpora (UD-EWT, WSJ) is very low -- classic examples ("The horse raced past the barn fell") are deliberately engineered, not naturally frequent. A fair test would need hand-built minimal pairs, which is exactly the construction-favorable trap the reversible-role test already fell into. Deprioritized.

## Cheap decisive test (Rank-1 pick)

**Target: implicative-verb x negation entailment (event-factuality), mined from real UD-EWT sentences, using Karttunen's published verb-polarity classification as the (externally-sourced, not-invented) gold-derivation rule.**

1. Extend `tools/build_negation_factuality_gold.py` with an `xcomp`-governed-by-closed-implicative-verb-lexicon selection rule (12-verb lexicon above, split into `pos_impl = {manage, get_to, bother_to, dare}` and `neg_impl = {fail, forget_to, neglect, avoid, hesitate, decline, refrain}` -- drop ambiguous bare `get`/`happen` senses or require the `xcomp` infinitival-complement pattern to disambiguate the implicative sense specifically). Scan the full bundled UD-EWT (train+dev+test, ~16-17k sentences; already-confirmed 4,815-candidate mining scale from the existing gold-build run) for real sentences containing one of these verbs governing an infinitival `xcomp`.
2. Gold label = entailed embedded-event polarity, computed via the fixed Karttunen truth table from (verb-polarity-class, sentence-level `Polarity=Neg` on the matrix verb) -- **independent of the reader/gate under test**, matching the existing gold set's "derived from gold parse only, no ground-by-X-grade-by-X" discipline.
3. Two model arms, **identical input features** (one-hot/embedding of matrix-verb identity + binary negation-present flag -- deliberately NOT handed the verb-polarity-class directly, so the model must recover it from lexical identity): (i) **linear readout** (logistic regression / single linear layer) over these two raw cues; (ii) the **nonlinear rule-inducer** (the same module banked at 29485).
4. **Held-out-verb generalization split** (mitigates the construction-risk residual flagged in candidate 1d): train on 8-9 of the 12 verbs, test entailment correctness on sentences containing the remaining 3-4 held-out implicative verbs. This directly tests whether the nonlinear learner induces the CLASS (positive- vs negative-implicative), not just a lookup table over 12 known lemmas.

## Falsifiable predictions

**HARD-PASS:** on the full-corpus mined implicative x negation slice (target n>=60 after excluding ambiguous `get`/`happen` senses, per the ~184-token / ~72-negated-cooccurrence scan already done this cycle): (a) linear readout accuracy on the SEEN-verb test split is <= 0.75 (bounded by the single-cue majority-class ceiling -- it can get main effects right but cannot resolve the interaction cells by construction of XOR); (b) nonlinear rule-inducer accuracy on the SEEN-verb split is >= 0.90; (c) on the HELD-OUT-verb split, nonlinear inducer accuracy is >= 0.70 (meaningfully above chance/majority-class, showing class-level generalization, not memorization); (d) the gap (nonlinear minus linear) on the interaction cells specifically (verb-class x negation combinations that disagree with the majority pattern) is >= 0.30 absolute.

**HARD-FAIL:** (i) linear readout already clears >= 0.85 on the full task -- meaning the "raw" verb-identity feature is leaking the polarity class near-losslessly and a monotonic combination suffices after all (the phenomenon is secretly linear at the feature level actually used, same failure mode as PP-attach); or (ii) after excluding ambiguous senses the clean-verb mined slice falls below n=40 scoreable items (a data failure, not a mechanism failure -- would require broadening the implicative lexicon, e.g. adding `succeed, chance to, get around to, take the trouble to`); or (iii) nonlinear inducer's held-out-verb accuracy is <= its seen-verb-shuffled-label control (i.e., it is only memorizing 12 verb identities, not the class, and the "genuinely beyond-linear" claim collapses to a disguised lookup table); or (iv) a scrambled verb<->polarity-class control (permute which verbs get which class label) achieves accuracy indistinguishable from the real-labeled run for EITHER arm -- a harness/leakage degeneracy, not a result.

**Must-fail control:** same discipline as the existing negation gate's scramble control -- randomly permute the matrix-verb-to-implicative-class assignment; both arms' accuracy must collapse toward chance, or the eval has a majority-class/leakage problem independent of linear-vs-nonlinear.

## Substrate-product implications

- Fully glass-box, build-time-cheap: reuses the already-built negation-gold-mining script and the already-existing UD-EWT parse/feature pipeline; no new parser, no LLM, no external annotation purchase.
- If HARD-PASS: gives the grow thrust its first REAL (non-synthetic-XOR, non-construction-determined) beyond-linear win, and directly de-risks phase-2 of the negation/factuality gate (the coverage-gated modal lookup) by replacing a fixed hand-lexicon rule with a learned, held-out-verb-generalizing component -- a genuine capability upgrade to an already-planned reader feature, not a standalone research curiosity.
- If HARD-FAIL via (i) (linear already wins): informative and cheap -- confirms verb-identity features alone leak the class, meaning the TRUE nonlinear test needs distributional/embedding features that do NOT trivially encode lexical identity (e.g. WordNet-hypernym-only features, forcing genuine class induction) -- a well-defined next iteration, not a dead end.
- If HARD-FAIL via (ii) (data too thin): bounded, mechanical fix (broaden the implicative lexicon per the note above), same as the negation gate's own prior data-gap resolution precedent.

## Recommendation (single best target)

**Rank 1 -- implicative-verb-class x negation entailment, mined from UD-EWT via a direct extension of `tools/build_negation_factuality_gold.py`, scored with a held-out-verb generalization split against the banked 29485 nonlinear rule-inducer vs. a linear readout, both fed identical (verb-identity, negation-flag) features.** This is the only candidate that is simultaneously (i) provably beyond-linear by a real, external, independently-published linguistic rule (Karttunen 1971) rather than a constructed label, (ii) cheaply mineable at real scale RIGHT NOW from data and code already in the repo (994 raw token hits / ~184 clean-verb tokens / ~72 negated co-occurrences independently verified this cycle), and (iii) structurally guarded against both known failure modes (single-injected-feature circularity via the held-out-verb split; aggregate-linear-capturability via the pre-registered HARD-FAIL condition (i)).
