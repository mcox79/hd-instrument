# Brain-faithful, glass-box DISCOVERY / ALLOCATION TRIGGER for new constructions (Drill B synthesis)

Director synthesis of 3 lit-scans (event-segmentation/predictive-coding; schema assimilation-vs-accommodation + construction-grammar acquisition; nonparametric-Bayes/MDL glass-box allocation). Governing constraint (USER 2026-07-31): brain-foundational first; better only if brain-COMPATIBLE; GLASS-BOX ALWAYS. Confidence deflated; no claim load-bearing without 2nd VET.

## The question
The auto-discovery engine: read a curriculum; for each incoming sentence/fragment, MATCH it against KNOWN construction competencies using POS/parse knowledge; if it does NOT match -> evaluate for a NEW type -> ALLOCATE a new competency. What is the brain's trigger for "this is a NEW type worth new capacity" vs "assimilate into an existing one," and what is the glass-box form?

## THE HEADLINE CONVERGENCE
**The brain's discovery/allocation mechanism and the glass-box grammar-induction formalism are the SAME math: a prediction-error / marginal-likelihood test.** "Do my existing competencies predict/parse this input well? If yes -> assimilate. If no (surprise/poor-fit) -> allocate a new competency." Formalized identically by (brain) event-segmentation + schema-accommodation and (glass-box) nonparametric-Bayes CRP == MDL two-part code, with direct precedent in construction-grammar induction. This satisfies the USER constraint cleanly: brain-compatible AND glass-box AND literature-proven-on-language.

## The brain (honestly deflated)
1. **Event segmentation (SEM/EST) = the closest analog.** Perceivers run an active event model predicting the next input; a transient PREDICTION-ERROR SPIKE above baseline triggers an event boundary + reset/allocate a new event model (Reynolds-Zacks-Braver 2007 = RNN next-frame-prediction loss, threshold/change-detection). SEM (Franklin 2020, Psych Review) makes schemas discrete and (per its metadata) uses a **CRP / nonparametric-Bayes prior to SPAWN a NEW schema when no existing one predicts well** — the exact "no match -> allocate" trigger. Confidence: HIGH the spike-triggers-boundary mechanism; MEDIUM the CRP-creation form (PDF unverified — a flagged follow-up).
2. **Hippocampal CA1 match/mismatch comparator.** CA1 compares CA3's prediction (pattern-completion over stored sequences) against direct cortical input; mismatch -> novelty signal -> VTA dopamine -> gates LTP / new-trace formation (Lisman-Grace 2005; Chen 2011). = novelty-gated encoding of NEW info. Graded/qualitative, not a numeric threshold. Confidence HIGH the circuit; LOW any stated threshold.
3. **Schema assimilate vs accommodate (route selection).** SLIMM (van Kesteren 2012): schema-CONGRUENT info -> mPFC fast-tracks into existing structure (assimilate); INCONGRUENT -> new hippocampal trace (accommodate/allocate). A GRADED prediction-error/congruence signal picks the route, with an inverted-U (moderate mismatch is the worst-remembered failure zone). Tse-Morris (2007/2011): schema-congruent facts consolidate in ~24-48h vs weeks. Confidence HIGH for the dissociation; no quantitative threshold documented (open in the literature).
4. **Predictive coding / free-energy (normative).** New-structure creation posed as Bayesian model selection: compare model evidence (variational free energy) of "with new latent cause" vs "without." Clean normative framing; weak on validated neural specifics.
5. **Language-specific acquisition (gradual, not a hard switch).** Tomasello usage-based: item-based verb-islands -> gradual distributional schematization into abstract constructions (NO threshold event, a continuous generalization). Goldberg: a construction is posited when a form-meaning pattern recurs with enough type-frequency AND is not predictable from its parts (frequency+predictability criterion). Syntactic bootstrapping (Fisher): children track novel argument-frame distributions as evidence for new structure. => in language the "new construction" decision is frequency/predictability-driven and gradual — an argument to make our allocation trigger accumulate evidence over multiple exposures, not fire on a single surprising sentence.

## The glass-box formalism (credit the authors)
- **CRP / Dirichlet-Process mixture:** P(join competency k) proportional to n_k; P(allocate NEW) proportional to alpha x (marginal likelihood of the input under a fresh competency's base measure). The "new" branch fires when the input fits NO existing competency's predictive distribution well. Fully glass-box, closed-form.
- **MDL two-part code:** adopt a new rule/competency only if the compression it buys on the data exceeds the bits to encode it. Mathematically EQUIVALENT to CRP/Bayes-Occam (prior ~ 2^-L(grammar), likelihood ~ 2^-L(data|grammar)). Maximally glass-box (bit-counting).
- **Direct language precedent:** Adaptor Grammars (Johnson-Griffiths-Goldwater) use CRP as the "adaptor" over a PCFG so a novel substructure is STORED as a new reusable fragment only when the CRP new-table branch fires; Fragment Grammars (O'Donnell) generalize to partial storage via Bayesian model selection (storage cost vs reuse savings). This IS "allocate a new competency," proven on grammar induction.
- OOD/novelty detection (one-class SVM, density thresholds) reduces to the same "unlikely under existing model" test; density/likelihood variants are the glass-box-compatible ones, kernel-SVM is an engineering proxy.

## The trigger recipe (glass-box, brain-faithful) for Phase 2
For each incoming construction (POS/parse-typed via pos_tagger/arc_parser/situation_reader):
1. **Predict/score under existing competencies.** Each seeded competency attempts to parse/predict the fragment; compute its fit (predictive likelihood / reconstruction). = the brain's "does my event model predict this."
2. **Allocate-vs-assimilate decision = CRP or equivalently MDL marginal-likelihood test.** If best-existing-competency fit is good -> assimilate (update that competency, gated). If NO competency fits (surprise/poor marginal likelihood, penalized by an alpha/description-length complexity cost) -> ALLOCATE a new competency in a fresh near-orthogonal subspace (per the Drill-A recipe). Reuse proginduction_plugin for the structural hypothesis.
3. **Accumulate evidence over exposures (from the language literature).** Don't fire on one surprising sentence; require the mismatch to recur (type-frequency + unpredictability, Goldberg) before committing a new competency — matches usage-based gradual abstraction and avoids spurious allocation. This is the ONE place we deliberately deviate from the single-spike event-segmentation trigger, in a brain-compatible way (language acquisition IS gradual).

## THE ONE TRIGGER to implement first (Phase 2 recommendation)
A **CRP/MDL marginal-likelihood "match-known-or-allocate-new" gate** driven by existing-competency predictive fit, with evidence accumulated over repeated exposures before allocation. Glass-box (closed-form score), brain-faithful (event-segmentation/SEM + schema-accommodation + CA1 mismatch), and literature-proven on language (Adaptor/Fragment Grammars). Reuse pos_tagger/arc_parser/proginduction for the parse + structural hypothesis.

**Fair can-fail test (Phase 2):** feed a stream containing a construction TYPE the seeded competencies were NOT built for (e.g. a relative clause when seed = {entity, roles}). PASS = the gate fires "no match," allocates a new competency, and that competency then learns the new construction (its held-ahead comprehension on that type climbs) WITHOUT degrading the seed competencies. FAIL modes to diagnose (never a ceiling): gate never fires (threshold/alpha miscalibrated), or fires spuriously on in-distribution variants (evidence-accumulation too weak), or allocates but the new competency can't learn (capacity/objective bug).

Note: Phase 2 is gated on Phase 1 first proving that MULTIPLE seeded competencies climb-further + no-interference. Discovery is worthless if adding competencies doesn't help.
