### Hadamard (exactly orthogonal) — Mattis-phase divergence predicted

**Setup**: Hadamard matrix H of size N×N satisfies H · H^T = N·I
(exactly). Patterns ξ_μ are columns/rows of H. With Hebbian J:
J_{ij} = (1/N) Σ_μ ξ_i^μ ξ_j^μ.

For all M patterns from Hadamard: J reduces to pseudo-inverse rule;
no frustration; ground states are exactly the stored patterns
(Mattis-like phase).

**Analytical derivation of Binder behavior**:
- Overlap with stored pattern μ: m_μ = (1/N) Σ_i s_i ξ_i^μ
- For random spin configuration: m_μ uniform random on [-1, 1] / √N
  (concentration)
- For pattern-aligned configuration (Mattis basin): m_μ ≈ 1 for one μ,
  ≈ 0 for others
- Two-replica overlap: q = (1/N) Σ_i s_i^(1) s_i^(2)
- If both replicas in same Mattis basin: q ≈ 1
- If different basins: q ≈ 0
- If random: q ≈ 0 with O(1/√N) fluctuations

**For substrate finite N=4096 with M Hadamard patterns**:
- Most random sampling → q ≈ 0 with small variance
- Occasional samples in Mattis basin → q ≈ 1
- **BIMODAL distribution** centered at 0 and 1

**Predicted moments**:
- ⟨q²⟩ ≈ f · 1 + (1-f) · O(1/N) ≈ f (where f = fraction of Mattis-basin
  samples)
- ⟨q²⟩² ≈ f²
- ⟨q⁴⟩ ≈ f · 1 + (1-f) · O(1/N²) ≈ f
- Ratio: ⟨q⁴⟩/⟨q²⟩² ≈ f / f² = 1/f → **DIVERGES as f → 0**
- Binder cumulant: B = 1 - (1/3)(1/f) → -∞ as f → 0

**For substrate empirical data**: B_inf = -8532 corresponds to f ≈ 1/25600.
Consistent with VERY RARE Mattis-basin sampling (almost all samples
have q ≈ 0).

**Slope = 8.78e6**: slope of B vs 1/N. Magnitude consistent with f
scaling as 1/N^α for α ≈ 2 (Mattis-basin fraction shrinks rapidly with N).

**CONCLUSION**: Hadamard B=-8532 divergence IS EXACTLY THE MATTIS-PHASE
FINGERPRINT predicted by Personnaz 1986 + Fan-Wu 2021 analytical
framework. NOT RSB signature. NOT spin-glass character.

### Kerdock (Welch-bound near-orthogonal) — clean RS behavior predicted

**Setup**: Kerdock codewords have IPs ∈ {0, ±1/√N} (approximately
Welch-bound saturating). Less orthogonal than Hadamard but more
structured than random.

**Analytical derivation of Binder behavior**:
- Inter-pattern overlap: ⟨ξ_μ · ξ_ν⟩ ≈ ±1/√N (uniform bounded)
- Hebbian J: structured-frustration regime (NOT no-frustration like
  Hadamard, NOT random like BSC)
- Per Fan-Wu 2021: orthogonally invariant J at high T → REPLICA

- P(q) → single peak at q_EA (RS prediction)
- ⟨q²⟩ well-defined; ⟨q⁴⟩ ≈ 3 ⟨q²⟩² (Gaussian moment relation for RS)
- Binder: B = 1 - (1/3)(⟨q⁴⟩/⟨q²⟩²) = 1 - (1/3)(3) = 0 + finite-N
  correction
- Finite-N correction is bounded; slope toward thermodynamic limit
  CLEAN

**For substrate empirical data**: B_inf=0.556, slope=0.167 is
**EXACTLY CONSISTENT WITH RS BEHAVIOR + FINITE-N CORRECTION**.

**CONCLUSION**: Kerdock clean Binder is consistent with REPLICA
SYMMETRY at this temperature/density per Fan-Wu 2021. NOT RSB
signature either.
