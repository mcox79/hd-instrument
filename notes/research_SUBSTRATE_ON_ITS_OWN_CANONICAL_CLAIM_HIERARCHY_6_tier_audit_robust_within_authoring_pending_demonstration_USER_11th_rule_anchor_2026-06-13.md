### When writing elevator pitch / tracking-doc / memory:
1. **Lead with Tier 1 + Tier 2 claims**. These are the substrate's identity.
2. **Use Tier 3 with explicit forward-path language** ("substrate projected to..." / "in current cycle...").
3. **Use Tier 4 with within-authoring qualifier**. Don't claim authoring-blind invariance.
4. **Mention Tier 5 only as "expected" or "pending demonstration"**.
5. **Skip Tier 6 entirely** unless USER signals revisit.

### When tracking-doc drift is detected:
- Claim asserted above its tier → file honest revision (per 10th rule)
- Claim untested at lower tier → either downgrade or schedule measurement
- New claim emerges → grade into appropriate tier before locking

### When new evidence arrives:
- Promotes claim's tier → file MOVE-UP commit (e.g. tier 5 → tier 2 via empirical anchor)
- Demotes claim's tier → file honest downgrade commit
- New claim → grade + file at correct tier
