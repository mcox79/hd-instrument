### 1.1 Steenrod operations — foundational

For topological space X, **Steenrod squares Sq^i: H^n(X; F_2) →
H^{n+i}(X; F_2)** for i ≥ 0, characterized by:
- Sq^0 = id
- Sq^n(x) = x ∪ x on H^n (cup-square in top degree)
- Sq^i(x) = 0 if i > deg(x)
- **Cartan formula**: Sq^k(x ∪ y) = Σ_{i+j=k} Sq^i(x) ∪ Sq^j(y)
- **Adem relations**: relations among Sq^a Sq^b when a < 2b

Foundational: **Steenrod 1947** *Ann. Math.* 48:290-320 (original);
**Cartan 1955**; **Serre 1953**; **Steenrod-Epstein 1962**
*Cohomology Operations* (Princeton textbook).

**What they detect**: distinguish spaces with isomorphic cohomology
rings (canonical example: CP² vs S² ∨ S⁴ have same H* but different
Sq²).

### 1.2 The Steenrod algebra A and Adams spectral sequence

**Milnor 1958** (*Ann. Math.* 67:150-171) proved dual Steenrod algebra
**A*** is polynomial Hopf algebra F_2[ξ_1, ξ_2, …]. **Adams 1958**
spectral sequence: E_2^{s,t} = Ext_A^{s,t}(F_2, F_2) ⟹ π_*^s(S^0)_2.

Recent computational work: **Bruner-Rognes 2021** (arXiv:2109.13117)
tabulate Ext through (s,t) ≤ (128, 200); **Isaksen-Wang-Xu** programme
through 2024 pushes stable stems past 90.

### 1.3 K-theory and Bott periodicity

**Bott 1959**: π_*(BU) period 2; π_*(BO) period 8.
**Atiyah-Hirzebruch spectral sequence**: E_2^{p,q} = H^p(X; K^q(pt))
⟹ K^{p+q}(X). **d_3 differential involves Sq^3** (in complex
K-theory) — this is where Steenrod operations enter
topological-phase classification, **as differentials between
cohomology and K-theory, NOT as primary invariants**.

### 1.4 Symmetry-protected topological phase classification

**Kitaev 2009** (arXiv:0901.2686): tenfold-way K-theory classification:

For **class AIII in d=1**: classification is **Z**, generated by integer
winding number ν. The K-theory entry is K^{-1}(pt) = Z (or π_1(U) = Z).
**The AHSS is degenerate at the level of the point — there are no
Steenrod differentials to compute because the relevant cohomology is
concentrated in one degree.**

Where Steenrod DOES contribute in condensed-matter classification
(per lit scan):
- **Gu-Wen 2012 supercohomology** (arXiv:1201.2648): Sq² is obstruction
  to lifting bosonic SPT cocycle to fermionic one (**d ≥ 2 only**).
- **Kapustin-Thorngren**: anomalies of finite-group symmetries via
  Sq^i on H*(BG; F_2) (**d ≥ 3 typically**).
- **AHSS differentials**: d_3 = Sq³ (Wu-twisted variant for KO).
- All require **d ≥ 2**.

**Decisively for class AIII / d=1**: nothing in the literature proposes
a Steenrod-derived secondary invariant beyond ν for this entry.

### 1.5 The substrate-decisive structural argument

The substrate's SSH-BSC system viewed as discrete 1D lattice:
- **Spatial CW complex is 1-dimensional** (vertices + edges)
- H^*(X; F_2) is concentrated in degrees 0 and 1
- **Sq^i for i ≥ 1 raises degree by i ≥ 1**
- Sq^i(α) for α ∈ H^1 lands in H^{1+i} for i ≥ 1
- **H^{1+i} = 0 for i ≥ 1** (1-complex has no higher cohomology)
- Therefore **all Sq^i with i ≥ 1 vanish identically on a 1-dim complex**

Confirmed in lit scan: "for moment-angle complexes built on a graph
(1-dim simplicial complex), there are no non-trivial Steenrod
operations" (arXiv:2401.07919, 2024).

### 1.6 Concrete substrate-applicable observation

For substrate's specific configuration:
- H^*(S^n; F_2) = F_2[x]/(x²) — Sq operations trivial on spheres
- H^*(RP^∞; F_2) = F_2[a] with Sq¹(a) = a² — rich example
- H^*(BO(n); F_2) = F_2[w_1,…,w_n] — detects Stiefel-Whitney via Wu

**For substrate's 1-complex**: cohomology is too small. Stiefel-
Whitney class w_1 exists in H^1; w_i for i ≥ 2 = 0 trivially.

### 1.7 Computer-aided computations

For substrate-scale N=4096:
- **Bruner's `ext`** (Wayne State) handles Ext_A through (s,t) ≤
  (128, 200) — well within reach
- **Medina-Mardones 2021** (arXiv:2105.08025) gave fast cup-i
  formulas; Steenrod-square computation O(N · k!) worst case, much
  less in practice
- **`steenroder`** (Lupo-Medina-Mardones-Tauzin 2018,
  arXiv:1812.05031): Sq^k-barcodes for TDA; published applications
  on cyclo-octane (≈10^4 simplices)

**Practical limit**: computation is feasible at substrate scale, but
**there is nothing meaningful to compute** in the relevant degrees
unless an auxiliary higher-dimensional complex is constructed.

### 1.8 The honest weak route (auxiliary complex)

The only possible substrate-relevant Steenrod application requires
moving beyond the 1D spatial complex:

1. **Vietoris-Rips filtration**: build a metric on substrate's
   state space, take VR complex. Could yield 2+ dimensional
   cohomology where Sq² might be non-trivial.
2. **Cross-product with parameter space**: substrate state × control
   parameter space. Persistent Steenrod (Medina-Mardones) could
   detect parameter-dependent transitions.
3. **Quotient by symmetry group**: BZ/2 = RP^∞ has H^* = F_2[a]
   with rich Sq-action. Could detect chiral-symmetry breaking
   subtleties.

**HONEST assessment**: none of these have been applied to class
AIII d=1 in the literature. Whether they would yield genuinely new
invariants (independent of winding number, Bott index, spectral
localizer) is **speculative**. They're not established programmes.

### 2.1 The decisive negative finding

R15's premise was: "do Steenrod operations give new invariants for
substrate's 1D class-AIII topology?" Answer: **NO**, by structural /
dimensional obstruction.

**The substrate's K-theory classification is exhausted by winding
number** (K^{-1}(pt) = Z = ν). Steenrod operations refine cohomology
that has more than one degree of non-trivial content; substrate's
1-complex has cohomology concentrated in degrees 0 and 1; therefore
**Sq^i with i ≥ 1 has no non-trivial target by construction**.

This is not "Steenrod doesn't help substrate" — it's "Steenrod
**cannot** help substrate's 1D class-AIII setup at all."

### 2.2 Where Steenrod WOULD bite if substrate were different

Per lit scan, Steenrod operations contribute when:
- **d ≥ 2** spatial dimension (most often d ≥ 3)
- **Symmetry group's BG has high-dim cohomology** (BZ/2 = RP^∞ has
  rich Sq-action)
- **K-theory or cobordism group has TORSION** (substrate's
  K^{-1}(pt) = Z is torsion-free → no Steenrod refinement)
- **AHSS differentials non-trivial** (substrate's spectral sequence
  collapses)

None of these apply to substrate's current architecture. If
substrate were extended to 2D (e.g., 2D SSH lattice) or had
non-trivial finite symmetry groups (Z/2 + crystallographic), some
of these might activate.
