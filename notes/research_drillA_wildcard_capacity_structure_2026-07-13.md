# Research drill A -- wildcard lens: cheap high-capacity codes + where exploitable structure comes from for arbitrary entities

Date: 2026-07-13
Lens: information/coding theory + linguistics + number theory + graph/spectral theory (deliberately OUTSIDE neuro/bio/quantum/ML)
Dispatch: 4 parallel Sonnet lit-scan sub-agents, generic-terms-only external queries (query-privacy respected -- no substrate-novel names/numbers left the sandbox)

## HEADLINE

Four independent fields converge on the SAME answer to "where does exploitable structure come from when the source (entity label) is arbitrary": **never in the label itself** -- Shannon source-coding + Kolmogorov incompressibility jointly PROVE that no bijective relabeling (residue/CRT, factorial, Zeckendorf, balanced-ternary, any positional system) can beat the log2(N) entropy floor for a max-entropy label set, which is the exact, principled reason the residue/grid-factoring trick failed. Structure that IS exploitable always comes from something **external to the label**: (a) the measurement/codebook OPERATOR's own statistical/algebraic properties (RIP, expander spectral gap, Welch-bound codebook geometry, sparse-superposition random dictionaries), (b) an **external usage/frequency signal** (Zipf/Huffman/water-filling: allocate budget by how often/how much an entity is used, not what it is), or (c) the **relation/co-occurrence graph** among entities (spectral/Laplacian embedding, node2vec-equivalent-to-matrix-factorization). All three are well-established, decades-deep literatures; none has been tried on the substrate's arbitrary-entity KG. This closes the "smarter deterministic label encoding" sub-branch permanently (do not re-attempt any positional/residue variant hoping for a different result) and opens two concrete, cheap, CPU-only next probes: usage-frequency-driven variable code-budget allocation, and usage-graph spectral basis discovery -- both locate the win in RELATIONS/USAGE, not identity, directly reinforcing the standing "relational capability is the core requirement" program thrust.

## Cheap decisive test

Before building anything: run a CPU-only analysis pass over the EXISTING ingested KG graph (the ~190k concept-relation edge set already on disk -- no new experiment, no GPU, just an analysis script against already-ingested data).

1. Compute the entity degree distribution over the co-occurrence/relation graph (edges = existing SYNONYM/IS_A/other relation types). Compute the Gini coefficient (or top-decile edge share).
2. Compute the graph Laplacian's leading eigenvalue spectrum on a subsample (or the full graph if tractable at ~190k edges) and measure what fraction of total spectral energy the top-20 eigenvalues capture (a proxy for real community/low-rank structure vs a near-random graph).

This single pass (a few minutes of CPU, existing data, no new pipeline) determines whether either promising avenue below has anything to grab onto BEFORE any implementation effort is spent.

- **HARD-PASS** (structure exists, worth prototyping): Gini coefficient > 0.5 (top ~10% of entities carry > 50% of edges) AND top-20 Laplacian eigenvalues capture > 30% of spectral energy.
- **HARD-FAIL** (no exploitable relational/frequency structure; close this whole lens): Gini < 0.2 (near-uniform degree) OR top-20 eigenvalues capture < 10% of energy (graph behaves like a random/Erdos-Renyi-ish graph with no community structure). If HARD-FAIL, fall back to brute-force near-orthogonal packing (Welch-bound-limited) as the only viable option and do not spend cycles on frequency/spectral hybrid schemes.

## Falsifiable predictions (HARD-PASS / HARD-FAIL)

**P1 -- Residue/positional-encoding closure (already at HARD-FAIL by theorem, stated for completeness).** Any future deterministic bijective re-encoding of a single arbitrary entity label (residue/CRT, factorial, Zeckendorf, mixed-radix, balanced ternary, or any novel positional variant) will show **no measurable capacity gain** over a size-matched random baseline code at matched dimension/entity-count, because entropy is invariant under bijections (Shannon) and generic labels are individually incompressible (Kolmogorov). HARD-FAIL is the theoretical default; this branch is closed. The only legitimate place positional/residue systems earn value is structuring the COMPOSITION/BINDING operator across multiple entities (independent-channel parallel arithmetic a la RNS, or bijective compact encoding of a genuinely combinatorial object a la factorial-number-system permutation ranking) -- never label compression.

**P2 -- Frequency/usage-allocation hypothesis (Huffman/water-filling analogy).** If code budget (dimensions / redundancy / cleanup-slot allocation) is allocated inversely-to-rarity by empirical entity access-frequency (a Huffman/reverse-water-filling rule) instead of uniformly across all entities: HARD-PASS = top-quartile-frequency entities show >=10 percentage-point improvement in top-1 retrieval accuracy at MATCHED total dimension budget vs. a uniform-allocation baseline. HARD-FAIL = improvement <3pp, or accuracy degrades uniformly across all frequency quartiles (would mean the allocation rule isn't actually trading off correctly -- theory/implementation mismatch).

**P3 -- Usage-graph spectral basis hypothesis.** If entities are embedded via Laplacian-eigenmap / NetMF-equivalent factorization of the co-occurrence graph (rather than assigned random/JL codes) at MATCHED dimension: HARD-PASS = >=15% relative reduction in retrieval error for above-median-degree entities vs. random-code baseline. HARD-FAIL = graph-derived codes perform equal-or-worse than the random baseline (closes this avenue -- would mean the graph's apparent community structure isn't actually exploitable for retrieval).

**P4 -- Sparse-superposition-code + AMP replication (label-agnostic efficient-brute-force fallback, independent of P2/P3).** If entities are encoded as sparse patterns over a shared random dictionary and decoded via AMP-style iterative denoising: HARD-PASS = measured recovery error within 2x of the theoretical Donoho-Tanner phase-transition prediction for the chosen sparsity/dimension ratio. HARD-FAIL = recovery error >5x worse than theoretical prediction (implementation/assumption mismatch -- e.g. entity codes don't actually satisfy near-Gaussian-dictionary statistics AMP needs).

## Cross-thread synthesis

Four disparate fields, dispatched with zero cross-talk (separate sub-agents, generic-terms-only queries), independently converged on the identical structural claim:

- **Coding theory (Sonnet A):** RIP/compressed sensing recovery guarantees are a property of the random MEASUREMENT MATRIX (concentration of measure over the ensemble), not of the signal beyond bare sparsity. Expander-graph LDPC codes' correction guarantees come from the Tanner graph's spectral gap, a property of the CODE's graph, not the message. Sparse-superposition codes (Barron-Joseph) + AMP decoding achieve AWGN capacity by exploiting statistical properties of a random DICTIONARY, again independent of message identity. Welch-bound/ETF/Kerdock codebooks are engineered for near-orthogonality as a codebook-geometry property, arbitrary labels assigned post-hoc. Common thread: **structure lives in the operator/codebook, never the entity.**

- **Linguistics/economics (Sonnet B):** Zipf's law (Ferrer-i-Cancho & Sole 2003; Piantadosi 2014) and Huffman/arithmetic coding both show that when vocabulary identity is arbitrary/conventional, the ONLY exploitable regularity for cheap efficient allocation is an EXTERNAL usage-frequency distribution -- code cost allocated inversely to frequency, with zero appeal to what the symbol "is." Rate-distortion water-filling and unequal-error-protection generalize the same allocation logic to continuous fidelity/redundancy budgets. ABC inventory analysis in operations management confirms the identical principle governs allocation to arbitrary/interchangeable goods generally. Common thread: **usage/frequency, external to the label, is the exploitable structure.**

- **Number theory (Sonnet C):** Shannon's source-coding theorem (entropy invariant under bijection) plus Kolmogorov-complexity incompressibility of generic strings jointly and rigorously explain why the residue/CRT/factorial/positional-encoding trick was DOOMED PRIOR TO ANY IMPLEMENTATION CHOICE -- this is a closure result, not a "try a different residue scheme" invitation (per the standing 80%-refutation-rate-on-redrilling-closed-fields pattern). The one place positional/residue decomposition legitimately earns value is structuring the COMPOSITION operator (RNS parallel arithmetic channels; factorial-number-system/Lehmer-code optimal ranking of combinatorial, not statistical, structure) -- source coding (compression, needs redundancy) and channel/algebraic coding (composition/parallelism/error-correction, works on arbitrary data because it isn't trying to compress) are a recognized taxonomic split in the literature.

- **Graph/spectral theory (Sonnet D):** Dictionary learning (K-SVD/Olshausen-Field) discovers a basis from data statistics rather than assuming one a priori, but needs the underlying signal population to have real regularity (fails for genuinely i.i.d. arbitrary labels). Laplacian eigenmaps / spectral embedding derive a basis purely from the RELATION graph -- entities relationally close end up numerically close, with zero appeal to identity. node2vec/DeepWalk are provably equivalent to factorizing a shifted log co-occurrence matrix (NetMF), i.e. spectral embedding by another name, consistent down to stochastic-block-model detectability limits. JL random projections preserve distances with zero basis-discovery needed at all, but only pay off when you don't need compression below log N or generalization to unseen relations. Common thread: **when identity is arbitrary but relations/usage have real structure, the basis lives in the graph's spectrum, not the nodes.**

All four threads independently forbid "compress the label" and independently point at three non-overlapping-but-stackable levers: operator/codebook engineering, usage-frequency allocation, and relation-graph spectral structure. This is a strong convergent signal (four fields "designed for very different things," per the wildcard-lens brief) rather than four restatements of one idea -- each has distinct, decades-old formal machinery (RIP/AMP proofs, Huffman optimality proofs, Shannon/Kolmogorov theorems, Laplacian-eigenmap/NetMF equivalence proofs) that can be pulled in independently or combined.

## Substrate-product implications (per [[feedback-no-papers-product-only]])

- **Closes a cycle-wasting branch:** stop attempting any further residue/grid/positional-factoring variant on raw arbitrary entity IDs -- the negative result is a hard theorem (Shannon + Kolmogorov), not an implementation defect, so no amount of cleverness in the specific factoring scheme will reverse it. Redirect any remaining appetite for positional/residue tricks toward the BINDING/COMPOSITION operator (how multiple entity-codes combine), not single-entity encoding -- this is consistent with, and reinforces, the already-locked "relational capability is the core requirement" program direction.
- **Opens two concrete, cheap, CPU-only next probes**, both gated by the decisive test above before any build effort:
  1. **Frequency-driven variable code-budget allocation** -- give frequently-accessed/frequently-queried concepts more of the shared representational budget (more dimensions / more cleanup-memory slots / higher redundancy), rare concepts less, following a Huffman/water-filling-style optimal-allocation rule. Product framing: cheaper overall footprint for the same aggregate fidelity, because most of the KG's access mass concentrates on a small head (if the decisive test confirms Zipfian/skewed usage, which is expected for any real KG).
  2. **Usage/relation-graph spectral basis for code assignment** -- derive entity codes (or a shared subspace) from the co-occurrence/relation graph's spectral structure (Laplacian eigenmaps / NetMF-equivalent factorization) rather than from entity identity; relationally-clustered entities share a compressed code subspace, isolated/novel entities fall back to a near-orthogonal random/JL/expander backstop code at the Welch-bound packing limit. Product framing: this is fully glass-box -- eigenvectors/communities are literally readable/inspectable, unlike an opaque learned embedding -- and directly targets "make the relational aspect of substrate real."
- **Independent fallback worth a cheap prototype regardless of (1)/(2):** sparse-superposition-code + AMP decoding is a proven, capacity-achieving, label-agnostic scheme (works even with zero relational/frequency structure -- i.e., survives a HARD-FAIL on the decisive test above). It raises the ceiling of "brute-force high dimension is expensive" by using a smarter DECODE algorithm (AMP, near-linear time) over a smarter but still identity-agnostic ENCODE (sparse random dictionary), and is worth testing independently of whether either relational avenue pans out.
- **Standing caution:** per the already-filed "correlation hurts capacity" finding, any relational/spectral compression layer MUST be kept in the retrieval-semantics subspace, explicitly decoupled from the store-code/collision-prone subspace -- otherwise this reintroduces the documented associative-capacity collision problem rather than fixing it.
