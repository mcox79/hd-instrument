# scratch/

Throwaway probes, one-off analysis scripts, and temp output.

**Nothing here is durable.** This directory is gitignored and is periodically cleared
(`python tools/clear_scratch.py --yes`). Assume anything you leave here will disappear.

If a script is worth keeping, move it out:

- `experiments/` -- experiment cells
- `tools/` -- durable tooling
- `notes/` -- write-ups and analysis

Do not put throwaway scripts at the repo root or in `tools/`.
