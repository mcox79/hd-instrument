# Pre-registrations

One file per experiment. Required sections defined in
[`../notes/research_playbook.md`](../notes/research_playbook.md), section 1.

Naming: `YYYY-MM-DD_short-slug.md`

A pre-reg is **immutable once the experiment launches**. If the experiment
plan changes after launch, write a follow-up pre-reg referencing the
original; do not edit history.

Purpose: closes the garden-of-forking-paths trap (Gelman-Loken 2013) by
committing the hypothesis and falsification criterion before seeing results.
