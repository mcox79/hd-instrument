## Hypothesis

TCFT var_ratio < 0.10 deletion certificate holds at N=4096 across M in {128, 512, 2048, 4096}.

NOTE: User requested M in {20K, 45K, 80K, 200K} for C3. At N=4096, those M values
are infeasible: compute_cumulative_works is O(M * N^2), giving ~5000s+ per seed at M=20K.
This script uses the feasible range M in {128, 512, 2048, 4096} to test N-scaling of TCFT.
The large-M TCFT (corpus size > 4K tokens at N=4096) remains deferred.

Prior anchor: tcft_m_sweep_v3 N=8192 5-seed HARD_PASS (var_ratio < 0.01 at all M).
This extends to N=4096 to confirm the N-scaling behavior.

## Pre-registered bands

**HARD_PASS:** var_ratio < 0.10 at ALL M values AND >= 4/5 seeds.
  AND Spearman r(M, var_ratio) < -0.5 (1/sqrt(M) trend).
**HARD_FAIL:** var_ratio >= 0.10 at M=4096 AND N=4096 in >= 3 seeds.
**MIDDLE_BAND:** Some M values pass but not all 4 with >= 4/5 seeds.

## Timeout estimate

Safety: ceil(1.5 * 3725) = 5588s.
